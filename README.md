小驴闪卡的长期目标，是成为**思源生态最全面的闪卡学习平台**：从笔记中发现值得记的内容，理解后整理成卡片，通过主动回忆巩固，再用于课程、考试和真实任务，持续修订和维护。AI 将贯穿各环节，全卡型、多种练习、目标与课程、统计诊断、迁移互通和小驴系列联动按阶段交付。

当前开发基线为 **v0.185.0**（本页按该版本功能面撰写），已提供笔记制卡、复习、管理、统计、考试计划、材料收件箱、学习目标与旅程、AI 制卡全链安全（前置检查/注入围栏/紧急停用/上下文预算）等能力。下文分别说明当前功能与后续方向；界面原型展示的是目标设计。

## 它适合怎样的学习

| 你的需求 | 从这里开始 | 后续希望连起来的过程 |
|---|---|---|
| 把自己的笔记变成长期知识 | 从思源块、挖空或快速问答建卡 | 回源查证、内容修订、应用与长期维护 |
| 记术语、词义和概念 | 主动回忆，或使用打字、朗读等辅助方式 | 词义与语境、原音听力、输出练习 |
| 为课程和考试准备 | 按卡组复习，建立考试计划 | 章节目标、前置知识、投入预演、应用证据 |
| 减少重复整理卡片的工作 | AI 生成问答/挖空候选，人工编辑后入组 | 来源审核、定向改写、冲突识别、思源智能体协作 |

小驴持续围绕六个结果设计：**记得住、用得上、找得到、改得动、负担得起、带得走**。卡片数量、连续天数和 AI 生成量只是过程数据；是否学会，还需要看真实回忆、解释和应用。

## 当前功能

以下按 v0.185.0 的代码与版本记录整理，具体使用还受宿主能力、设置和设备影响。

| 能力 | 当前提供 |
|---|---|
| **笔记制卡** | 块菜单添加到卡组、多选批量、选中文字挖空、快速问答、扫描 `术语:: 定义` 和 `？` 结尾标记 |
| **主动回忆与复习** | 题面与答案、三档/四档自评、内核提供的下次间隔预览、来源上下文、跳过、今天不学、回看、忘记卡本批重现 |
| **辅助练习** | 打字对照（LCS diff）、TTS 朗读/听写、选择题（本地采样干扰项）、配对练习、图片遮挡、**混合题型轮换**（翻面/打字/选择按本场张数轮换，展示层不动调度） |
| **本场控制** | 本场偏好弹层（评分制/倒序/超时即时覆盖）、**时间预算**（5/15/30/60 分钟或自定义，预算到≠失败）、混合轮换开关 |
| **学习旅程（BI 系列）** | 材料收件箱→一键送去制卡、学习目标（目的/截止/每日分钟/优先级/自定义完成标准）、内容状态面板（十态流转+下一动作建议+为什么解释）、入口上下文（文档/试卷/卡片入口记录与返回）、收工原因、中断恢复横幅、长期返场检查与减负选择、进度叙事（阶段计数非百分比） |
| **卡片管理** | 分页浏览、文本/状态/遗忘筛选（返回时恢复上次视图）、按遗忘次数排序、批量重置/移除、卡片详情（知识对象/关系图/内容状态）、选中卡导出 CSV、**维护债务队列**（重复/泄漏/过长/待审核检测+可逆暂停） |
| **考试计划** | 截止日期与范围、每日建议量、进度、cram 冲刺入口、考试复盘 |
| **统计与记录** | 热力图、连击、本地日志保持率与间隔分桶曲线、能力分布、错误原因分布、AI 批次记录；日志 JSON/CSV 导出与导入合并、多设备分叉检测与合并预览 |
| **AI 制卡（全链安全）** | 思源 AI 服务或自定义端点（主备自动回退）、12 个内置提示词模板注册表、生成→预览→逐卡采用→入组、断点续传；**前置检查**（材料/配置/网络阻断+替代建议）、**注入隔离**（数据围栏+隔离条款+离线攻击 fixture）、**紧急停用**（目标粒度停用/撤销同意/清理待发队列）、**上下文预算器**（分层裁剪+分批建议，截断不静默） |
| **偏好与帮助** | 模块开关、画像预设、界面模式（简单/熟练）、字号和密度、提醒/免打扰、朗读/音效、内置帮助与示例工作区、中英界面 |

本地统计主要来自插件记录的日志。曲线中的固定理论参考、样本保持率和内核数据有不同口径，不能据此直接宣称掌握或学习效果。日志导入与选中卡 CSV 导出也不等于完整学习包迁移。

**正在完善的部分**：BI 系列的界面接线仍在按批次补齐（BI-10/19/27 的横幅 UI、来源健康探测）；Anki 互通、字段模板与思源 Agent 接入在规划中。最新范围见[能力状态与待办](./docs/17-待办清单.md)和[版本记录](./CHANGELOG.md)。

## AI 如何参与学习

**AI 是产品的核心方向。** 它将参与材料筛选、概念解释、卡型选择、题面与提示设计、应用反馈、内容维护和学习报告。每个任务都配合来源、人工判断与无需 AI 的操作路径。

当前的 AI 制卡可使用**思源设置中的 AI 服务**或**自定义兼容端点**，生成问答/挖空候选，再预览、编辑、选择并创建到卡组。内置 **12 个提示词模板注册表**（通用/考试/语言/材料扫描/目标澄清/卡型路由/原子拆解/反泄漏/干扰项/烂卡改写/答案 rubric/列表表格双向卡），支持自定义模板；答案仍需你结合原文核对。

**AI 安全四道门**（请求前到落盘全链）：

- **前置检查**：材料为空、AI 未配置、离线时在组装提示词前阻断，并给出手工/本地替代建议（零 token 消耗）；
- **注入隔离**：来源材料以不可信数据围栏包裹，系统侧声明「无工具调用、不外发、产物只写制卡向导」，离线攻击 fixture 持续回归；
- **上下文预算**：超长材料按优先级分层裁剪并给出分批建议，截断处有可见标记，不静默截断关键证据；
- **紧急停用**：设置页一键停用当前配置或撤销全部同意（按 provider/model 粒度），同时清理待发队列；已有卡片与正式复习完全不受影响。

所有 AI 请求经统一流水线入口（模板解析→围栏→预算→审计），扩展任务必须经任务注册表登记。锁字段的定向局部改写已提供人工编辑+写前差异预览（W2）；AI 改写面（W3）与思源 Agent 接入仍在规划中。

### AI 与数据范围

核心制卡、复习、管理和导出可以在不配置 AI 的情况下使用。卡片和笔记由思源保存，插件设置、计划与本地日志保存在思源工作空间内，并随你配置的同步渠道处理。

AI 制卡会把材料发送到你配置的服务商。**配置了备用端点时，当前主请求失败后会自动尝试备用端点**，请先确认两个端点都适合处理这些材料。来源健康探测、成本账本和密钥存储增强仍在规划中，详见[隐私说明](./docs/PRIVACY.md)。

## 安装

最低声明为 **思源 3.8.0**。桌面、移动和浏览器的具体功能差异仍需按设备验证，建议先在桌面体验核心路径。

1. 到 [GitHub Releases](https://github.com/ai68298100/siyuan-lv-cards/releases/latest) 下载 `package.zip`。
2. 在思源 **设置 → 集市 → 下载** 中使用“导入安装包”，选择该 ZIP，无需解压。
3. 在已下载插件中启用“小驴闪卡”。

当前以 GitHub Release 安装包分发，思源集市上架暂缓；不要把路线图理解为已能在集市搜索安装。没有安装包导入入口的设备，请按该宿主提供的插件安装方式操作，相关平台兼容性见[验收清单](./docs/18-已定决策与真机测试清单.md)。

## 开始使用

1. 在思源文档中点击块左侧图标，选择**添加到卡组**，选一个卡组或新建卡组。
2. 点击顶栏的**小驴闪卡图标**：有到期卡时进入复习，无到期卡时打开闪卡中心；也可用命令面板搜索“小驴闪卡”。
3. 在问题态按**空格显示答案**，再按 **1—4** 自评：遗忘、困难、良好、简单。三档设置使用 1—3。
4. 到闪卡中心查看总览或管理卡片；不清楚操作时，在复习面板按 `?` 查看帮助。

开始时可保留默认关闭的超时模式。若启用“超时判遗忘”，当前版本会自动提交遗忘评分；希望每张都由自己确认时请关闭该选项。

## 产品如何继续扩展

后续交付先补齐当前可靠性和一条完整手工学习旅程，再逐任务融入可信 AI，并按价值拓展领域与互通能力。

| 方向 | 计划中的用户体验 |
|---|---|
| **学习旅程收口** | 返场分流/影响模拟横幅接线、来源健康探测 UI、多目标入口联动；按真机走查反馈排期 |
| **更深的内容能力** | 字段级改写的字段↔块映射设计、数值单位/容差、步骤分支、开放回答、知识适用条件与版本 |
| **语言、课程与应用** | 词义语境、多媒体、章节计划、投入预演、迁移练习和应用证据 |
| **可控的学习偏好** | 范围预设（全局/目标/本场三层）、设置搜索与本地效果预览、负载展望视图 |
| **思源与小驴系列联动** | 拾遗材料→闪卡、考试错题→闪卡、学习→打卡/复盘、雷切专注→学习回顾；外部插件缺失时仍可本地使用 |
| **迁移与长期生态** | Anki 与学习包互通、内容分享和维护；云同步增强、多人协作、市场、完整增量阅读与独立端后置探索 |

以上属于规划，需按宿主接口、用户验证和数据边界逐步交付。暂时做不到的能力保留依赖与复评条件。完整方向见[产品使命](./docs/27-产品使命与全功能战略.md)和[分层路线图](./docs/04-路线图.md)。

[UI 原型](./docs/13-UI原型图.md)按十个任务面梳理目标体验，涵盖[材料整理](./docs/13-UI原型图.md#task-materials)、[制卡审核](./docs/13-UI原型图.md#task-authoring)、[专注复习](./docs/13-UI原型图.md#task-review)和[结果与下一步](./docs/13-UI原型图.md#task-results)等。这些是低保真目标设计，实际界面以安装版本为准，真实截图将在对应能力验收后补充。也可以打开[Starline R52 交互目标原型](./docs/prototypes/starline-r52.html)评审页面节奏、主题和状态；原型使用固定虚构数据，不连接思源、不调用模型，也不会写入卡片或评分。

<details>
<summary>开发环境与检查命令</summary>

使用 Node.js ≥ 24、pnpm 12；项目基于 TypeScript、Svelte 5 和 Vite。

```bash
pnpm install
pnpm make-link    # 将 dev/ 链接到本机思源工作区，具体配置见 CONTRIBUTING
pnpm dev          # 监听构建，开发环境需运行思源
pnpm check        # 类型、Svelte 与版本检查
pnpm test         # 单元测试（500+）
pnpm build        # 生产构建（含 hub/review/dialogs 三个 UI chunk）
node scripts/e2e-isolated.mjs   # 隔离式后台 e2e（临时工作区+无头内核，16 项断言）
pnpm release      # 交互式同步版本并运行检查；不等于发布到外部平台
```

启动体积按 chunk 分治：主包 gzip ≈42KB（≤55KB CI 门禁），闪卡中心/复习/对话框三个重组件按需加载。正式调度以思源内核为准；V2 相关接口按实际能力探测与验收，不因版本号推断全套支持。工程细节见[架构决策](./docs/24-架构决策记录.md)与[扩展契约](./docs/14-扩展架构与数据契约.md)。
