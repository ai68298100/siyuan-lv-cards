# v0.210.0 发布前验证

日期：2026-10-16。用户明确要求发版，沿用仓库 main → 版本标签 → GitHub Actions Release 的流程。

## 范围

统一制卡/导入/编辑/维护结构检查；旧坏卡本场隔离；AI 候选质量与安全导入；维护媒体、近似重复、编辑回扫、批修预览确认；来源指纹持久化和独立健康历史；按需模块加载恢复。包含 main 上尚未发布的服务抽取、本地模型端点预设和复习手势/视口改进。

发布前审查发现批修失败补偿曾受正常编辑门禁阻挡，无法恢复原本无效的旧卡。已增加当前事务精确原始快照恢复通道，继续使用内容版本串行队列，任意恢复内容会被拒绝，普通编辑不豁免质量校验。

## 本地验证

- `pnpm release`：先运行仓库版本脚本选择 minor 同步版本，再实际运行 release 链选择 0 保持 v0.210.0，类型/Svelte/版本校验通过。
- `pnpm check`：TypeScript 双配置通过；Svelte 0 错误、0 警告；版本三处一致。
- `pnpm test`：157 个文件、1070 项测试通过。
- 新的宿主集成回归直接使用真实 `saveBlockContentVersion`，仅模拟内核 I/O 和持久化，覆盖无效旧值、第二张写后失败、版本保存失败、快照篡改及恢复后继续编辑。
- `node scripts/check-i18n.mjs`：1679 个键对齐，856 处源代码引用全部命中。
- `pnpm check:docs-facts`、`git diff --check`：通过。
- `pnpm build`：从清理生成目录开始，生产三分包、主包、kernel 与发布 zip 全部生成，包内 smoke 通过。
- 生产 smoke 实际运行 IIFE 注册表，并验证批修预览/确认/写入、坏卡失败补偿、近似重复、双语帮助、复盘报告及诊断。
- `node scripts/check-governance.mjs`：通过，935 条待办和 38 个工作包一致；主包低于 55 KiB gzip 预算，未调整门槛。

## 仍未完成的验收与边界

- 真实思源 Chrome 普通/挖空/遮挡/导入/旧坏卡五路径、Android 宿主及真实模型异常矩阵没有通过证据，不以自动化代替。
- 门禁只验证结构及高置信质量信号，不能证明知识事实准确。
- 批修快照用于当前事务失败补偿，不是长期备份；界面没有成功批次的撤销入口。
- 来源历史记录问题发现和处理，不记录每次来源编辑；旧卡无指纹/历史不代表已验证健康。
- 部分标点占位及无效媒体题面仍待后续收紧。

## 发布链路

- 远端 main 已只读刷新，本地历史包含尚未推送的 6 个既有提交；本次发布不重写历史。
- 新标签 v0.210.0 发布前确认远端不存在。旧 v0.209.5 标签存在本地/远端差异，保持原样，不强制覆盖。
- 远端发布由 `.github/workflows/release.yml` 校验 tag/main、版本、源码、测试、文档、构建、治理与 zip，再上传 `package.zip` 及 `package.zip.sha256`。
- 集市接入 PR 为 `siyuan-note/bazaar#2329`，2026-10-10 已合并，2026-10-16 经 GitHub 实时核验；无需新开接入 PR，版本索引更新另按官方周期部署。
