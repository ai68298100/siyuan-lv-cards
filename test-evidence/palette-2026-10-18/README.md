# 命令面板生产组件隔离走查 · 2026-10-18

本目录保存本轮 Chrome 走查的夹具、服务脚本与截图。夹具直接挂载生产构建 `dist/chunks/dialogs.js` 导出的 `LvPalette`，载入正式 `dist/index.css` 与 `dist/chunks/dialogs.css`；注入合成的 14 项命令及宿主 CSS 变量，不连接思源或其他 API，不读写工作区数据。

## 复现

从仓库根目录执行：

```powershell
pnpm build
node test-evidence/palette-2026-10-18/server.mjs
```

在 Chrome 打开 `http://127.0.0.1:19067/`。服务仅监听本机 `127.0.0.1:19067`，路由限定为本页及上述三个构建资源。`?dark=1` 启用合成深色宿主变量，`?dark=1&long=1` 为末项增加无空格长文本。

打开后在空查询中按 End 定位真实末项“维护中心”，按 Home 或上下键检验首尾导航；输入关键词检验筛选，输入不匹配文本检验空结果。Enter 执行只更新夹具结果文字；Escape 销毁组件并由夹具的 `onClose` 回调把焦点放回“打开命令面板”。
