## 二、其他闪卡格式兼容性

| 格式 | 口径 | 实测 |
|---|---|---|
| 思源原生 `==挖空==` | 完整支持：问题态遮罩、翻面解除、打字判分以挖空文本为准、配对游戏以挖空出题 | ✓（A-3 修复后四链路验证） |
| 同块多挖空 | 整块复习（全部遮罩→全部解除），非 Anki 逐洞 | ✓ 与原生一致 |
| Obsidian SR（`问 :: 答`、`?` 多行块、`==挖空==`、`#flashcards`） | 导入支持（obsidian-import，指纹幂等） | 离线单测覆盖；本轮未做文件导入 UI 驱动（headless 文件选择限制） |
| Anki `.apkg` | 导入支持（桌面宿主 node:sqlite 门禁） | 本轮未驱动（同上） |
| **Anki `{{c1::挖空}}` 语法** | **不支持**：复习/配对中按纯文本原样显示 `{{c1::线粒体}}` | ✓ 实测确认；用户需改写为 `==挖空==` 或用 Anki 导入（导入器负责语法转换） |

## 三、卡型显示矩阵（15/15 逐卡实测，问题态 → 答案态）

| 卡型 | 问题态 | 答案态 | 结论 |
|---|---|---|---|
| 单挖空卡 | mark 文字透明、底色保留（遮罩生效） | 全文可见 | ✓ |
| 多挖空卡 | 双 mark 同时遮罩 | 同时解除 | ✓ |
| 普通段落卡 | 整块显示 | 同 | ✓ |
| 多行块（问题\n答案） | 整块显示（无切分语义，与原生一致） | 同 | ✓ 口径正确 |
| 公式卡 | 文档内 KaTeX 渲染正常（E=mc² 两个公式元素）；卡面与文档同源（getBlockDOM） | 同 | ✓（面板检测器误报，视觉正常） |
| 代码卡（块粒度） | 代码块为独立块，未入组时其宿主段落只含问题行 | — | ✓ 块粒度语义 |
| 列表子项/表格单元格 | 独立成卡、独立复习 | — | ✓ |
| Anki 语法卡 | `{{c1::…}}` 原样显示 | 同 | ✓（不支持的明确口径） |
| 引用块卡 | 整块显示 | 同 | ✓ |

遮罩实现注意项：遮罩=文字透明+底色保留（非删除），且同时覆盖 `<mark>` 与 `<span data-type="mark">` 两态（A-3）。
