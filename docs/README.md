# docs 目录导览

> 阅读顺序建议：**新用户**只看 20/21；**想了解终局定位**看 27→28→29→04；**想评审产品体验**看 32→12→13→15；**想参与开发**按 30→32→31→10→11→16→17；**想对接生态**看 14。

> 本项目目标是打造思源生态最全面的闪卡学习平台。文档明确区分当前已实现、可做待办、宿主/外部依赖和长期后置探索；后置不等于取消。
> 当前代码基线为 **v0.185.0**；开发排期以 docs/30 v1.2 为事实源，docs/31 记录完整主归属和体验验收引用，docs/17 保留研究与验收明细。当前治理统计为 **935 条、194 已勾选、738 普通未完成、3 特殊、38 个规范工作包**；docs/36 的 open 445 是“当前可动工池”，不是全量 backlog。路线图中的旧版本窗口属于历史规划，不代表当前状态。最新综合评审见 [38-当前状态评审与精品化待办](./38-当前状态评审与精品化待办.md)。
> R51 依据上述定位重写 [中文介绍](../README.md) 与 UI 原型 v1.1；R52 在其上加入 [Starline R52 交互目标原型](./prototypes/starline-r52.html) 和 BY-1 跨任务视觉场景与状态夹具评审器。原型使用固定虚构数据，不连接思源、不调用模型、不写入卡片或评分；本轮只做文档与原型评审，未修改业务代码。
