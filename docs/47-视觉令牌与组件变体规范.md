# 47-视觉令牌与组件变体规范

> 本文记录 R54 原型中的视觉语义、令牌职责和生产迁移边界。原型的浅色/深色数值是用于截图与交互评审的静态夹具；生产颜色继续映射思源宿主主题，不代表插件提供独立主题切换。定义变量或写下规范不等于生产样式已全部引用，落地比例须按源码扫描单独验收。

## 1. 令牌职责与主题边界

令牌按用途分为语义色、排版、间距、形状、层级和动效。业务组件应引用语义令牌；组件的内容几何、响应式和光学校准可以保留有说明的局部值。

生产色彩基于思源主题变量：

| 语义 | 生产来源或派生 | 用途 |
|---|---|---|
| `--lv-color-brand` | `--b3-theme-primary` | 主动作、选中态、图表主色 |
| `--lv-color-on-brand` | `--b3-theme-on-primary` | 主色实底上的文字；使用前核对实际配对 |
| `--lv-color-text` / `--lv-color-text-muted` | `--b3-theme-on-background` / `--b3-theme-on-surface` | 正文 / 辅助信息 |
| `--lv-color-canvas` / `--lv-color-surface` | `--b3-theme-background` / `--b3-theme-surface` | 页面底 / 内容表面 |
| `--lv-color-danger` / `--lv-color-warning` / `--lv-color-success` | `--b3-theme-error` / `--b3-theme-warning` / `--b3-theme-success`（success 缺省回退 primary） | 状态文本与图形 |
| `--lv-primary-soft` / `--lv-danger-soft` / `--lv-warn-soft` / `--lv-good-soft` | 对应状态色以 `color-mix()` 派生 | 状态弱底；不能代替高对比正文色 |
| `--lv-border` / `--lv-border-strong` | 文字色与透明度混合 | 分隔线 / 强调轮廓 |

`docs/prototypes/lv-cards-r54.html` 使用同一套 `--lv-color-*` 语义名，但在 `:root` 和 `[data-theme="dark"]` 分别提供静态浅/深色值，方便同一原型切换截图。该页不是生产构建入口；生产 `src/index.scss` 将颜色映射到 `--b3-theme-*`，并依赖宿主更新主题变量。第三方思源主题、宿主切换瞬间以及生产色彩对比度仍需在真实宿主计算样式中验收。

## 2. 排版档位（已落地）

字号、行高和字重按实际使用值建立有限档位；几何上确有需要的 9/14/15/17/19/22/29px 作为精确语义特例，保留原值而不强行合并到相邻档位。

| 语义令牌 | 字号 | 典型用途 |
|---|---|---|
| `--lv-type-micro-size` | 9px | 极紧凑计数、角标 |
| `--lv-type-caption-size` | 10px | 键位、辅助标记、版本信息 |
| `--lv-type-meta-size` | 11px | 次级元信息、eyebrow |
| `--lv-type-control-size` | 12px | 控件说明、表格表头 |
| `--lv-type-body-size` / `--lv-type-body-sm-size` | 13 / 14px | 正文、较宽阅读文本 |
| `--lv-type-label-size` / `--lv-type-title-size` | 15 / 16px | 字段标签、卡片标题 |
| `--lv-type-title-lg-size` / `--lv-type-section-size` / `--lv-type-section-lg-size` | 17 / 18 / 19px | 区块层级标题、空态标题 |
| `--lv-type-heading-size` / `--lv-type-page-size` | 20 / 22px | 页面局部标题、窄屏标题 |
| `--lv-type-display-size` / `--lv-type-hero-size` / `--lv-type-metric-size` / `--lv-type-hero-lg-size` | 24 / 28 / 29 / 32px | 主行动区、指标和强调数字 |

紧凑状态文字、键位提示、日历数字和卡面内容按所在控件的几何与可读性处理，不能为了减少档数压低到不可读。R54 原型还有空态标题 `19px`、表格/筛选控件 `12px`、特定插画或图标比例等局部尺寸；除非同一语义反复出现并且视觉复核通过，不增设全局字体档。

通用行高令牌覆盖 tight/icon/title/body/reading/meta/relaxed/loose/reading-loose 及两个控件像素行高；字重令牌覆盖 400/500/550/600/650/700。源码中的字号、行高和字重声明已全部使用令牌，审计覆盖率为 100%。

## 3. 间距与尺寸

布局和组件间距以 **4px 栅格**为默认：`4 / 8 / 12 / 16 / 24 / 32px`。优先复用已有 `--lv-sp-1` 至 `--lv-sp-5`（当前分别解析为 `4 / 8 / 12 / 16 / 24px`）并按语义选档。扩充一个任意数值 token 前，先确认它不是已有栅格值或内容自然尺寸。

允许保留的光学/几何例外：

- `1px` 边框、分隔线和 hairline；`2px` 底线、进度轨道和焦点偏移等细部。
- icon、圆点、环、日历格、图表线、卡面图片区等由 SVG 坐标、比例或固有尺寸决定的值。
- 原型明确的固定控件高度：紧凑 `32px`、标准 `40px`、主动作 `48px`；触屏重要操作仍需实际命中区域测试。
- 页面容器及断点内边距按容器宽度变化。R54 的 `28px 30px 32px`、中断点 `24px`、窄容器 `23px 19px 27px` 是布局校准值；需以原型截图证明，不能误称为 4px 倍数。
- 由数据决定的百分比、内容高度、图表坐标和响应式断点，不转成静态间距档。

当前实现以 2px 基础单位生成 4px 常用节距，并保留 1px hairline 与奇数像素光学校准；组件使用覆盖达到稳定后再删除未引用档位，避免为了提高数字而改变布局。

## 4. 圆角、阴影、层级与动效

| 类别 | 默认语义 | 保留理由/限制 |
|---|---|---|
| 圆角 | 小控件 `8–10px`、面板 `16–18px`、弹层 `20–22px` | 小尺寸标签 `4–8px`、进度 `2–5px`、圆形 `50%`、胶囊 `999px` 是形状特例；同一种控件不得在相邻页面漂移 |
| 阴影 | 普通卡片不加厚静态阴影；交互悬浮使用轻层级；弹层使用较强阴影 | 阴影需在明暗主题都看得清但不形成大面积黑雾；焦点环属于可达性状态，不算海拔阴影 |
| z-index | 基础内容 < 局部卡片控件 < 复习侧面板 < 宿主遮罩 < 插件抽屉及抽屉内容 | 使用语义层级令牌；不得单独为修复一个 stacking context 任意加大数字。portal/宿主对话框须在真实嵌套层验证 |
| 动效 | 120ms 微反馈、180ms 面板/状态切换、240ms 进度或强调反馈；共用缓动曲线 | `prefers-reduced-motion: reduce` 将过渡时长归零并关闭 skeleton shimmer；业务计时和进度事实不可因动画偏好改变 |

## 5. 通用组件变体

变体只表达明确的操作语义或尺寸，不应仅为某个页面临时配色而增加新类型。

| 组件 | 必要变体 | 保留理由 |
|---|---|---|
| 按钮 | Primary、Neutral、Ghost、Text、Danger；Compact `32px`、Standard `40px`、Large `48px` | 主按钮标记唯一主要动作；Neutral 承载普通提交/选择；Ghost 用于低权重命令；Text 用于轻量内联导航；Danger 表达破坏性操作。尺寸档对应密集工具行、常规鼠标操作、触屏/主 CTA |
| 输入框 | Text、Select、Textarea 三种语义元素；Standard / Compact 尺寸；Default、Focus、Invalid、Disabled 状态 | 控件语义由原生元素决定；状态必须复用同一边框、焦点环和错误说明口径，避免再按页面复制皮肤 |
| 标签 | Neutral、Brand、Success、Warning、Error 语义色；紧凑胶囊形状 | 标签只陈述状态/分类，不替代带动作的按钮；颜色以外还需文案或图标，不单靠色相传达状态 |
| 卡片 | Panel（默认内容面）、Hover（仅可交互卡片）、Hero（主行动区）、Review（复习专用阅读面） | Panel 保持中性分层；Hover 只给可点击对象；Hero 负责首屏行动层级；Review 适配专注阅读。普通静态数据卡不新增装饰变体 |

控件统一提供 hover、focus-visible、active、disabled 状态；禁用控件须给原因或由相邻说明解释。错误状态应贴近具体字段并可被读屏关联。具体 API 与状态责任见 [46-组件目录与状态契约](./46-组件目录与状态契约.md)。

## 6. 对比度复核

以下比值按 R54 原型当前静态 HEX 颜色计算，使用 WCAG 相对亮度公式；普通文本目标 `4.5:1`，大字/非文本控件边界至少 `3:1`。

| 配对 | 浅色 | 深色 |
|---|---:|---:|
| 主文本 / 页面底 | `12.92:1` | `15.37:1` |
| 辅助文本 / 页面底 | `4.91:1` | `8.19:1` |
| 品牌文字 / 页面底 | `6.44:1` | `10.19:1` |
| 品牌软底文字 / 品牌软底 | `6.69:1` | `8.13:1` |
| Warning 软底文字 / 底色 | `5.75:1` | `8.09:1` |
| Success 软底文字 / 底色 | `6.14:1` | `7.74:1` |
| Danger 软底文字 / 底色 | `5.50:1` | `7.40:1` |

这些数字只覆盖原型表中对应的静态颜色配对，不覆盖透明混合叠加、hover/disabled/focus、SVG 描边、宿主主题和第三方调色。生产使用思源变量，必须在真实亮色、暗色及至少一种第三方主题中读取最终 computed foreground/background 后复测；源码 token 映射本身不是对比度证据。在生产对比度记录补齐前，验收状态标记为“静态原型通过、宿主主题待验证”。

## 7. 验收与复现

迁移前后用同一源码范围记录：语义 token 引用数、字面值声明数、独特字面值数、保留特例及其组件用途。只统计变量声明数量会掩盖“token 零引用”；覆盖率必须以实际属性声明使用 `var(--lv-...)` 的比例计算。本轮基线为 **691/1219（56.7%）**，迁移后为 **1129/1219（92.6%）**；字号、字重、行高、gap、z-index 达到 100%，圆角为 95.8%，padding 为 95.3%，剩余主要是 `0`、`auto`、透明色和容器几何特例。

```powershell
rg -n --glob '*.{scss,svelte,css}' -- 'font-size:|line-height:|font-weight:|border-radius:|gap:|padding:|margin:|z-index:' src
rg -n --glob '*.{scss,svelte,css}' -- 'var\(--lv-type-' src
rg -n -- 'data-theme|prefers-color-scheme|--lv-color-' src/index.scss docs/prototypes/lv-cards-r54.html
```

视觉核对覆盖原型的浅/深预览、320/390px 窄屏、桌面和长中文文本；生产另测思源浅/深主题、第三方主题、键盘焦点与 200% 字体。修改令牌后复查共享页面、复习、制卡工作台、管理器、弹窗及抽屉，确认没有局部颜色、尺寸或 stacking context 漏改。
