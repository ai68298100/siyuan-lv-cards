# 小驴闪卡 · UI 组件库规范（Lv Kit）

> **本组件库是后续所有 UI 开发的唯一装配来源**：新界面 = Kit 组件组合 + 少量领域样式；禁止绕过 Kit 手写页面骨架。
> 三层结构：`令牌（index.scss 的 --lv-*）→ Kit 组件（src/ui/kit/）→ 业务屏幕（src/ui/*.svelte）`。
> 视觉规格见 15-视觉设计系统；交互行为见 12；本文是"有什么、怎么用、什么时候用哪个"。

## 1. 分层与规则

| 层 | 位置 | 允许 | 禁止 |
|---|---|---|---|
| 令牌层 | `src/index.scss` | `--lv-*` 变量、共享类（.lv-card2/.lv-btn-primary/.lv-tabs/.lv-table/.lv-skeleton…） | 出现业务专属选择器 |
| Kit 层 | `src/ui/kit/Lv*.svelte` | 组合令牌与 b3 类；通用、无业务语义 | import 业务模块（api/core） |
| 屏幕层 | `src/ui/*.svelte` | 组合 Kit + 领域样式（复习卡面等专属渲染） | 手写页面容器/分区/表格/空态等 Kit 已覆盖的结构 |

Do & Don't：
- ✅ 新屏幕先在本文 §4 找"装配配方"；缺组件先补 Kit 再用
- ✅ 颜色只用 `--lv-*`/`--b3-*`；间距只用 `--lv-sp-*`；动效只用 `--lv-dur-*`/`--lv-ease`
- ❌ 不硬编码色值（阴影/遮罩的 black/white 透明梯度除外）；不复写 Kit 内部样式（ gap/prop 不够就改 Kit）
- ❌ Kit 组件不做数据请求、不弹消息——数据与副作用永远在屏幕层

## 2. 组件目录（10 个）

| 组件 | 用途 | 关键 Props | 已用于 |
|---|---|---|---|
| `LvPage` | 页面容器 + 页头（题/副题/呼吸点/动作区） | `title, subtitle, dot, #actions, children` | 总览/管理 |
| `LvSection` | 卡片分区（card2 + 区块题） | `title, sub, children` | 总览/设置 |
| `LvStat` | 统计卡（色点/大数字/分母/进度） | `label, value, denom?, tone, progress?(-1 关)` | 总览 |
| `LvProgress` | 迷你渐变进度条 | `value(0-100)` | LvStat 内/未来考试卡 |
| `LvTabs` | 二级胶囊页签 | `tabs[{id,label}], active, onchange` | 闪卡中心子导航（v0.9） |
| `LvEmpty` | 空态（✦ 圆徽 + 文案 + 动作） | `text, actionLabel?, onaction?` | 管理 |
| `LvRow` | 设置行（左标签+提示 / 右控件插槽） | `label, hint?, #children` | 设置 |
| `LvHeatmap` | 复习热力图（含图例与今日环） | `days[{date,stat}]` | 总览 |
| `LvChip` | 语义状态章 | `tone: default/primary/warn/error` | V2 徽章/阶段标签 |
| `LvKbd` | 键位徽章 | `k` | 评分按钮 |

共享 CSS 类（index.scss）：`.lv-page .lv-pagehead .lv-card2(+--hover) .lv-hero-num .lv-secthead .lv-dot .lv-btn-primary .lv-glass .lv-badge .lv-tabs/.lv-tab .lv-chip2--* .lv-kbd2 .lv-table(.lv-num-col) .lv-skeleton .lv-mini-track/.lv-mini-fill`

## 3. 组件状态与可达性基线

- 所有可交互组件：hover 抬升/加色（180ms）+ active scale(.98) + `:focus-visible` 焦点环（令牌统一）
- 禁用态：`disabled` 属性 + opacity 0.5；不做颜色区分以外的自定义
- 加载态：屏幕级用 `.lv-skeleton` 骨架（见总览/管理器），按钮级用 b3 原生 loading
- 错误态：`.lv-card2` 内联红字 + 重试按钮；永不白屏
- 动效：全部经 `--lv-dur-*`（reduced-motion 归零）或包 `no-preference` 守卫

## 4. 装配配方（后续屏幕照此拼装）

### 4.1 闪卡中心子导航改造（v0.9）
```
LvPage(title=闪卡中心)
  └ LvTabs(tabs=[总览,管理,考试,数据], active, onchange)
  └ {#if active==='overview'} 总览内容（现 dashboard 主体）{/if} …
```

### 4.2 AI 制卡向导（Dialog，M2·FR6-10）
```
svelteDialog(640px)
  LvTabs(步骤 1 选源 · 步骤 2 预览)          ← 步骤指示复用 tabs
  步骤1: LvSection(来源)  + LvRow×4(单选) + LvSection(配置) + LvRow×n
  步骤2: LvSection(候选卡预览) + 卡片行(管理器 lv-row 同款) + 批量勾选
  底部: lv-btn-primary(生成/落库)
```

### 4.3 考试子页（M7）
```
LvPage(title=考试, actions=[新建计划])
  计划卡 = LvCard2 + LvProgress(倒排进度) + LvChip(滞后预警 warn/error)
  今日应学 → openReview(计划范围)
  倒计时 = LvChip(primary) + 呼吸点
```

### 4.4 数据子页（M10）
```
LvSection(V2 迁移) LvRow×n → LvSection(复习日志) LvRow(导出/清空)
  → LvSection(体检) .lv-table(文件/体积/版本)
```

### 4.5 首次引导（Onboarding）
```
全屏 Dialog：LvStat 风格的三张画像卡（复用 lv-persona 样式）→ 步骤 2/3 全屏复习面板
```

### 4.6 移动端
```
LvPage 自动适配（padding 收窄由 --lv-sp 承担）；悬浮球为独立组件（v1.0，样式引用令牌）
```

## 5. 新组件准入流程

1. 先问：现有 Kit + b3 类能否拼出？（80% 的情况是能）
2. 确需新增：在 `src/ui/kit/` 建 `LvXxx.svelte`，零业务依赖，样式只用令牌
3. 本文目录表 + 装配配方同步更新（否则 PR 不合）
4. 命名：`Lv` 前缀 + PascalCase；CSS 类 `lv-` 前缀 + kebab-case；令牌 `--lv-` 前缀

## 6. 现状盘点

- Kit 10 组件全部有真实使用场景（无"纸面组件"）
- 四个既有屏幕已完成 Kit 装配改造（总览/管理/设置/复习），是配方的活样例
- 待开发屏幕（§4）预计零新增 Kit 组件即可完成装配——这就是成套性的验收标准
