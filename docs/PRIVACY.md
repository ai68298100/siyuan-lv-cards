# 隐私说明

> 当前 v0.207.6 无遥测、无埋点。用户选择 AI 制卡并确认请求后，所选材料会发送到配置的服务商；核心复习、统计和导出可独立于 AI 使用。下文将当前行为与规划中的 AI/Agent 隐私要求分开说明。

### 复习日志（revlog.json）的构成与上限语义

- **明细**：最多保留最近 20,000 条评分记录（时间、卡 ID、卡组 ID、块 ID、评分、来源、可选作答耗时）；更早明细被截断后不可恢复，其每日聚合以快照形式保留；
- **knownCards**：最多 20,000 个曾有过评分的卡 ID（仅 ID，不含内容），用于明细截断后仍能区分「新卡/复习」；卡在内核侧删除后 ID 会保留在本列表中（上限兜底，见 BZ-2 对账策略）；
- **每日聚合（days）**：按本地时区日期的计数，含截断前日期的历史快照；
- 以上均为本地统计用途，不改变内核卡片与调度；清空复习日志（设置 → 数据）会一并清除。

## 什么情况数据会离开本机

当前已实现路径中，**AI 制卡**时，你选中的材料会发送给你配置的 AI 服务商：
- 默认走「思源内置 AI」，使用你在思源设置里配置的服务商与密钥；
- 如改用「自定义端点」，则发送到你填写的地址。
- 自定义模式配置了备用端点时，主请求遇到**网络故障/服务端 5xx/限流**才自动回退（BU-28 降级阶梯，v0.189.0 起）；密钥错误（401/403）、配额耗尽、内容策略拒绝、响应解析失败和用户取消一律直接中止并给出原因，绝不静默换端点重发；回退发生时界面会提示已切换备用端点及可能产生的额外费用。

AnkiConnect 测试连接会访问用户填写的地址。当前 AIInvocation、字段脱敏预览、逐任务同意中心和 Agent 工具账本尚未实现，不能据本文认定发布版本已经具备这些控制。

## 规划中的 AI/Agent 隐私要求

未来解释、应用、维护和 Agent 任务统一使用逐任务授权、最小上下文和可撤回的数据范围。调用前须显示材料、端点/模型、用量、保存策略与恢复路径；拒绝后不发送，备用模型不能扩大授权范围。AI 调用日志默认只保留哈希、计数、状态和用量，密钥迁移到宿主 secret 存储，完整 prompt 或原文的保留需单独选择。

思源 Agent 只可使用注册且获授权的能力，读取统计摘要可能仍会把摘要带入宿主模型对话，因此工具本地读取与对话模型外发分别检查。AI 建议评分与用户正式评分分离；内容写入、删除和分享经过范围预览与确认。具体设计见 [AI战略与内置提示词体系](./29-AI战略与内置提示词体系.md)，实现状态见 BU 组。

## 你可以随时

- 导出/清空复习日志（设置 → 数据）；
- 清空 AI 批次记录（删除 ai-batches.json）；
- 卸载插件时选择是否保留私有数据。

AI 调用元数据清理、端点同意撤回和 AI 缓存清理是后续规划能力，不是当前版本已提供的按钮。
