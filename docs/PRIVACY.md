# 隐私说明

> 当前 v0.63.0 无遥测、无埋点。用户发起 AI 制卡时，所选材料会发送到配置的服务商；核心复习、统计和导出可独立于 AI 使用。下文将当前行为与规划中的 AI/Agent 隐私要求分开说明。

## 数据都在哪

| 数据 | 位置 | 说明 |
|---|---|---|
| 卡片本体 | 思源笔记内核（riff 库） | 本插件只读写内核接口，不复制不锁定 |
| 设置 / 复习日志 / 考试计划 / AI 批次 | `data/storage/petal/siyuan-lv-cards/` | 随思源同步走你自己的同步渠道；当前自定义端点主/备用 key 仍在设置中保存，secret 迁移见 AW-1 |
| 示例卡 / AI 卡 / 快速制卡文档 | 你的笔记本内普通文档 | 用户可见可删 |

## 什么情况数据会离开本机

当前已实现路径中，**AI 制卡**时，你选中的材料会发送给你配置的 AI 服务商：
- 默认走「思源内置 AI」，使用你在思源设置里配置的服务商与密钥；
- 如改用「自定义端点」，则发送到你填写的地址。
- 自定义模式配置了备用端点时，当前主请求失败后会自动回退到该端点；按错误分类和授权范围控制回退仍是 AQ-15/BU-28 待办。

AnkiConnect 测试连接会访问用户填写的地址。当前 AIInvocation、字段脱敏预览、逐任务同意中心和 Agent 工具账本尚未实现，不能据本文认定发布版本已经具备这些控制。

## 规划中的 AI/Agent 隐私要求

未来解释、应用、维护和 Agent 任务统一使用逐任务授权、最小上下文和可撤回的数据范围。调用前须显示材料、端点/模型、用量、保存策略与恢复路径；拒绝后不发送，备用模型不能扩大授权范围。AI 调用日志默认只保留哈希、计数、状态和用量，密钥迁移到宿主 secret 存储，完整 prompt 或原文的保留需单独选择。

思源 Agent 只可使用注册且获授权的能力，读取统计摘要可能仍会把摘要带入宿主模型对话，因此工具本地读取与对话模型外发分别检查。AI 建议评分与用户正式评分分离；内容写入、删除和分享经过范围预览与确认。具体设计见 [AI战略与内置提示词体系](./29-AI战略与内置提示词体系.md)，实现状态见 BU 组。

## 你可以随时

- 导出/清空复习日志（设置 → 数据）；
- 清空 AI 批次记录（删除 ai-batches.json）；
- 卸载插件时选择是否保留私有数据。

AI 调用元数据清理、端点同意撤回和 AI 缓存清理是后续规划能力，不是当前版本已提供的按钮。
