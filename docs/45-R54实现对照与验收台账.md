# R54 实现对照与验收台账

> 更新：2026-10-14；代码基线：v0.209.3。R54 原型是 UI 结构、视觉、文案、交互状态和响应断点的唯一规范事实源；本台账记录生产实现相对该规范的状态和证据。R53 仅是既有生产界面的历史参考。原型固定样例不代表真实数据或宿主验收。

## 1. 证据规则与状态标签

每项只允许使用以下状态：

| 标签 | 含义 |
|---|---|
| **代码已落地** | 当前源码有可定位实现；必要时有单元/Svelte 测试。不能据此推断真机通过 |
| **自动化已验证** | 本地测试、构建、smoke 或隔离 e2e 有明确通过输出；注明范围 |
| **原型已实现** | `docs/prototypes/lv-cards-r54.html` 中可选择页面/场景核对 UI 规范；固定数据不连接思源或模型，不能证明生产行为 |
| **宿主待验证** | 需要桌面、Android、浏览器、不同思源版本、真实模型或多窗口证据 |
| **未完成** | 当前没有足够实现，或已知契约尚未满足；保留原因和后续入口 |

原型是 UI 规范的唯一事实源；源码和测试证明当前实现行为，思源运行结果证明宿主行为。原型中的按钮只改变页面内存状态，不能作为 API、FSRS、权限、持久化或网络成功证据。发现不一致时，在此登记并更新生产实现与原型，不新建平行 UI 规范。

### 状态必须保持的契约

- 到期数未知、部分卡组读取失败和旧数据刷新失败时显示“—/保留快照”，不得当作 0；正式复习主动作应被阻止，并给出重试或缩小范围入口。
- 加载期间重复触发必须锁定；错误态保留输入/旧数据并提供可读重试；筛选无结果与空库使用不同引导。
- AI 的取消、超时、401、限流、配额、服务器错误、网络失败、预算超限、敏感材料和旧请求迟到必须分别说明；未配置 AI 时手工路径仍可完成。
- 正式评分只有在内核回执后推进会话和日志；未知回执进入待核对，不能重复提交制造脏数据。
- 选择题干扰项不足降为二选/三选，无法生成可靠干扰项回退自由回忆，不展示占位干扰项。

## 5. 本轮发现的退化与已修复项

本轮只记录实际发现并已修改的退化：

1. **全局到期合并可能把部分失败当成完整结果**：任一卡组读取失败时原先可能继续返回少卡结果；现改为失败显式抛出，不缓存不完整合并。证据：`src/api/riff.ts`、`tests/deck-due-merge.spec.ts`、`tests/riff.spec.ts`。
2. **详情切换残留旧原文**：切换卡片时先清空旧预览，以请求序号丢弃迟到响应，失败显示重试。证据：`src/ui/card-detail.svelte`、`tests/card-detail-preview.spec.ts`。
3. **管理器筛选分页不回第一页**：搜索、状态和遗忘筛选现在回到第一页并重载；筛选空态只描述当前加载页；删除保存筛选不再清空搜索词。证据：`src/ui/manager.svelte`、`tests/manager-row.spec.ts`。
4. **R54 原型状态夹具不完整/条件重复**：已补部分卡组读取失败、AI 错误场景和容器宽度选择器；2026-10-12 的两个 Node 内嵌脚本语法检查通过。已用本地浏览器完成 320px/390px 暗色首屏、加载取消、部分失败缩小范围和 AI 401 降级冒烟；逐控件全页面、1024px/宽屏、字号放大、reduced-motion 和第三方主题仍待补证据，不能据此声称生产交互全部可用。
5. **学习目标写入先改内存后落盘**：目标保存、删除和优先级变化现在在独立快照上串行持久化，成功后才替换运行态；失败保留旧快照并让页面显示可重试错误。证据：`src/index.ts`、`src/ui/goals-page.svelte`、`src/ui/hub.svelte`。
6. **320px 顶部工作区被挤成逐字换行**：移动断点同时给工作区标题、搜索入口和铃铛分配固定空间，导致标题/搜索文案竖排和右侧裁切；已在 R54 原型中加入单行省略、窄视口搜索图标模式和主动作不换行规则，并通过本地浏览器 320px/390px 截图复测。
7. **Hub 导航与原型图标层级退化**：生产品牌标记、收件箱/上手入口和移动导航曾使用文字/字符替代，主导航没有原型中的 SVG 图标与到期数，顶栏缺工作区上下文和收件箱快捷入口；现以 `LvIcon` 收敛线性图标，Hub 导航展示可信到期数（刷新/未知时显示“—”），增加带数量说明的收件箱入口、工作区与内测标记，并让窄屏断点统一到 780px。证据：`src/ui/kit/LvIcon.svelte`、`src/ui/kit/LvTabs.svelte`、`src/ui/hub.svelte`、`src/ui/dashboard.svelte`、`tests/kit-tabs-row.spec.ts` 和 R54 原型。
8. **原型顶栏快捷入口错跳**：收件箱模块在生产 Hub 中是独立懒加载子页，但 R54 原型只提供“待处理与恢复”模拟页；入口已改为指向已注册的 `recovery` 页面，避免点击后无页面响应。
9. **收件箱当前页未传达给辅助技术**：侧栏、顶栏快捷入口和学习子导航此前只用视觉类标记选中项；现在生产实现与原型都在当前收件箱入口输出 `aria-current="page"`，顶栏快捷入口同时保留选中视觉态。学习子导航的四个子页面也输出当前页状态；主导航继续使用 `LvTabs` 的 `aria-selected` 页签语义。2026-10-12 在原型浏览器中逐一检查 9 个页面、320/390/760/780/781/1024px 六档**容器宽度**，共 54 组：页面、顶栏、导航无横向溢出，页签均关联现存 tabpanel；780px 使用移动导航，781px 使用侧栏。低高度设置页使用文档纵向滚动，没有固定面板裁切。思源宿主和真实读屏仍待验证。
10. **复习异步动作边界**：选择题生成中的旧响应不能覆盖切换后的卡；改期只能提交一次，失败后必须保留卡片、错误说明、原截止时间与重试入口。新增 `tests/review-async-actions.spec.ts` 三项生产组件测试覆盖迟到选择题响应、改期双击锁和改期失败后的稳定重试。组件测试同时发现改期曾复用页面级错误态、整页被错误页替换，导致重试入口消失；现在错误信息显示在改期表单内，保留原卡和确认动作。R54 原型已补 pending/error/retry/success 演练：可勾选首次写入失败，失败后显示原卡、精确目标和“重试相同目标”，成功仅推进一张；浏览器已实际走通该路径。
11. **管理器返回现场与到期筛选错误**：筛选 change 处理器原先可能先读旧状态，造成选择“今日到期”后没有按预期加载；现在显式读取本次 select 值，失败显示错误和重试而非空结果。返回卡库时等真实行渲染、到期请求结束后恢复页码、滚动与焦点；设置解析把超大正整数钳制到上限。`tests/manager-view-state.spec.ts` 和 `tests/manager-row.spec.ts` 覆盖回归；当前相关测试通过。
12. **暂停/恢复写入闭环与部分扫描文案**：今日页与维护页共用串行快照写入，先持久化、成功后再提交界面状态；失败保留原卡片和状态、锁定重复提交并提供同一操作重试。部分扫描错误改从顶层 i18n 资源读取，并保留已扫描结果及扫描重试。证据：`src/core/suspend-today-persistence.ts`、`src/ui/dashboard.svelte`、`src/ui/maintenance-page.svelte`、`tests/dashboard-suspend-restore.spec.ts`、`tests/maintenance-page-persistence.spec.ts`。
13. **总览结构与周视图贴近 R54**：首屏改为左侧复习行动和四项真实统计、右侧本周视图；周数据从本地复习日志计算，未来日期明确标成未到来，不构造未来记录。周视图在 780px 以下移至统计下方，560px 以下统计改成两列。`tests/dashboard-suspend-restore.spec.ts` 验证周数据来自日志且输出七个日项。R54 原型同步成动态日历周、四项非交互统计和明确标为合成样例的周记录。

20. **抽屉标题无障碍 ID**：抽屉标题 ID 改为实例级生成，多个抽屉同时挂载时 `aria-labelledby` 不再互相指向；焦点陷阱和关闭行为保持原契约。证据：`src/ui/kit/LvDrawer.svelte`、`tests/kit-drawer.spec.ts`、`tests/kit-layouts.spec.ts`。
21. **知识对象/关系重复确认与异步反馈**：移除实例此前由面板和宿主管理器各自确认，可能出现双重确认；现由面板保留一次确认，宿主只负责执行。注册、启用/停用、移除和派生统一走快照持久化队列，保存成功后才更新运行态；失败保留旧快照，显示可读错误并提供重试，按钮在写入期间锁定。关系添加/删除同样采用快照队列，重复或已不存在的关系进入错误态，不伪装成功。证据：`src/index.ts`、`src/ui/ko-panel.svelte`、`src/ui/relations-panel.svelte`、`tests/ko-panel.spec.ts`、`tests/relations-panel.spec.ts`、`tests/snapshot-mutation-queue.spec.ts`。
