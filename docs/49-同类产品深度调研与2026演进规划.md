## 1. 行业与竞品最新动态（2025 ~ 2026 纵览）

当前知识管理与记忆工具的竞争，已从单一的“算法排期”竞争演进为**“捕获 → 加工 → 记忆 → 维护 → 应用”的全生命周期体验竞争**。AI 的普及消除了“快速生成卡片”的技术壁垒，但随之带来“卡片泛滥、缺乏依据、脱离笔记上下文、难以长期维护”等严重副作用。

## 2. 核心竞品优劣势剖析与启示

### 2.1 Anki (v24.x / 25.x)
- **优势**：
  - FSRS 的原发地与标杆，拥有极高的统计专业度与全球极客社区认同；
  - 官方落地了原生图片遮挡（Native SVG Image Occlusion），支持矩形、椭圆与多边形绘制；
  - 拥有 AnkiHub 协作牌组生态，支持多人维护医学/法律海量卡库。
- **劣势与痛点**：
  - 卡片是“脱离母体”的碎片，用户往往“知其然而不知其所以然”，无法查看完整上下文；
  - 数据模型陈旧（SQLite 文本拼接），UI 现代感差，移动端各平台体验割裂。
- **对小驴的启示**：
  - 坚持 FSRS 调度事实源由内核掌控；
  - 进一步完善 SVG 遮挡卡与移动端手势体验；
  - 通过 `.lvcards` 轻量分享包解决牌组分发，无需中心化订阅服务器。

### 2.2 RemNote (2.0 ~ 2.1)
- **优势**：
  - 概念-描述符体系（`::` 概念卡、`:::` 描述卡、列表卡）：在大纲笔记中直接自然生长出闪卡；
  - **复习层级面包屑（Hierarchical Breadcrumbs）**：在卡片题面顶部显示“根页面 > 章节 > 父列表”，解决原子题目的上下文迷失问题；
  - 增量阅读（Incremental Everything）：支持将 PDF 重点分段推入学习流。
- **劣势与痛点**：
  - 强绑定树形 Outliner，无法良好承载现代富文本排版（代码块、复杂表格、LaTeX 公式嵌套等）；
  - 商业化严重，高级功能依赖高额月费。
- **对小驴的启示**：
  - 小驴是通用富文本块模型（思源），比 Outliner 表现力更丰富；
  - **应引入“复习卡面来源面包屑（Context Breadcrumbs）”**：复习时显示该卡片所属的笔记本、文档及父级标题路径，消除原子卡片的认知孤立。

### 2.3 MarginNote 4
- **优势**：
  - “文档摘录 - 脑图整理 - 闪卡复习”三位一体，视觉关联度极高；
  - 多层级遮挡（Layered Occlusion）：在一张材料图上分层逐步揭示答案。
- **劣势与痛点**：
  - 苹果单平台局限，跨平台学习不可行；私有数据库格式无法直接与通用笔记交互。
- **对小驴的启示**：
  - 强化思源块引用（Block Ref）与闪卡的联动，卡片就是文档块的投影；
  - 继续深化多步骤提示阶梯（Hint Ladder），实现类似的多层渐进揭示体验。

### 2.4 Readwise / Monic.ai / Knowt
- **优势**：
  - 自动化程度高，材料直接上传即可生成题库与测验；
  - 视觉设计现代（类 Linear / Raycast 质感）。
- **劣势与痛点**：
  - “生成即入库”引发严重的垃圾卡堆积；
  - AI 经常产生“幻觉断言”，用户背了错误知识却浑然不知；
  - 调度缺乏透明度，往往是伪间隔重复。
- **对小驴的启示**：
  - 坚持**可审计的 AI（Auditable AI）**：来源片段对齐（Grounded Contract）、质量评分卡门禁、未审不入库；
  - 永远提供无 AI 纯手工等价流程。

## 3. 待办事项梳理与工作包深化（Backlog Refinement）

依据上述调研，结合当前 v0.210.6 基线（已有 227 个测试文件、1832 项测试），对现有待办工作包进行聚焦与精细化梳理：

### 3.1 重点攻坚领域（近期高价值）
1. **WP-review-study-experience (复习沉浸与上下文感知)**
   - **新增细化 [BX-11] 复习来源层级面包屑**：在卡片顶部提供“文档 > 所在章节”轻量路径提示，支持一键定位并折叠，消除原子卡复习时的“孤岛感”。
   - **深化 [M3·FR8] 超时模式与动效调优**：确保计时器在复杂公式与长代码块场景下无掉帧渲染。
2. **WP-ai-governance-pipeline (AI 全生命周期治理)**
   - **推进 [BU-11] 统一 AI 调用流水线运行时**：收拢单次、流式与批处理，统一超时与中断处理。
   - **推进 [BU-12] Token 与成本预估硬上限引擎**：发送前估算费用，支持单次与单日硬上限拦截。
3. **WP-migration-interop (生态迁移与数据主权)**
   - **深化 [BX-12] 分享包导入差异比对（Diff Inspector）**：当导入同名卡组出现部分修改卡片时，提供并排字段级对比，由用户选择覆盖或保留。
4. **WP-maintenance-quality (知识健康与长效维护)**
   - **落地 [BT-3] 误解簇 UI 视图集成**：将核心聚类算法在闪卡中心维护页以交互图表呈现，直接生成反例卡。
