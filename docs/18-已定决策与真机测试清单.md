## 二、🧪 真机测试清单（等你有空时反馈，一次过）

> 全部为**跳过开发继续**的项；测试方法都很轻，按顺序约 30 分钟。

### 1. 安装与冒烟（5 分钟）
- [ ] `make-link` 后重启思源，集市"下载"页出现并启用小驴闪卡
- [ ] 顶栏出现图标 + 角标（有到期卡时显示数字）
- [ ] 左键图标 → 直接打开复习面板；右键 → 菜单（含 V2 行[3.8 无此行属正常]）
- [ ] 亮/暗主题各切一遍：四个界面无违和（重点：卡片渐变面、评分按钮底色）

### 2. 复习链路（10 分钟）
- [ ] 无卡时复习面板空态文案；有卡时翻面/评分/跳过正常
- [ ] **评分后开发者工具 Console 过滤 `click-flashcard-action`**：`window.siyuan.ws.app.eventBus` 手动触发或直接观察——记录事件 detail 的真实字段名（当前代码按 cardID/deckID/rating 猜测）
- [ ] 撤销/回看/今天不学/超时模式各试一次
- [ ] 移动端（如有）：全屏复习、滑卡手势区、悬浮球缺失已知

### 3. 统计与中心（5 分钟）
- [ ] 复习几张后总览热力图当日格变色、数字滚动
- [ ] 管理器筛选框输入即时过滤；空结果文案
- [ ] 设置：画像切换确认框→模块开关变化→保存后生效
- [ ] 设置-数据：导出 JSON 下载、清空需确认、V2 状态章显示 "N/A (<3.9.0)"（3.8 正常）

### 4. 内核 API 实测（10 分钟，开发者工具 Console）
- [ ] 逐个调用 `window.siyuan` 不可用则用 fetch 打 `/api/riff/*`：skip 是否消耗当日配额
- [ ] `resetRiffCards` type=0/1/2 三种行为记录
- [ ] 块移动到其他文档后，管理器"来源"列是否更新、何时更新
- [ ] 文档删除后卡的状态（坏卡能否被 `getRiffCards` 查到）
- [ ] `getRiffCards` 响应里是否真无 cardID（决定管理器改造路线）
- [ ] `updateCards` 广播触发时机（评分后其他已开界面是否刷新）

### 5. 数据与同步（可选）
- [ ] 两台设备（或两个工作空间）各自复习后同步：revlog 合并是否正常
- [ ] settings.json 同步冲突时插件是否正常启动（normalize 兜底）
