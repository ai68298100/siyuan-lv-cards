## 1. 结论

小驴闪卡已经越过插件骨架阶段，形成了本地优先的完整闪卡平台。核心链路是：思源材料捕获 → 制卡 → 内核 FSRS 复习与评分 → 本地日志/统计 → 管理、维护和迁移；学习目标、收件箱、入口上下文、会话恢复、考试、AI 安全链、备份恢复、Obsidian/Anki 互通和 R53 UI 也已经有代码。

当前适合描述为：**核心功能代码已具备，离线工程质量较好，真实设备、真实模型和发布事实仍未完全闭环，集市发布条件未满足。**

最先处理的不是继续增加题型或生态，而是修复已经存在的阻断、补齐宿主证据，并让文档和发布包与当前事实一致。

本轮已处理：Kit 三个可绑定控件的回写、复习手势的阶段语义、启动单键容错、设置持久化入口、引导定时器/顶栏监听卸载清理、通用内核请求边界、大库文档归属查询并发上限、AI 向导迟到结果守卫、chunk 失败/版本切换清理，以及发布包资源白名单。下文仍保留这些项目的原始问题和完成定义，供回归验收；真实 Android 和宿主行为仍需复核。

## 4. 已确认的 UI 问题

### P0：Kit 控件的双向绑定没有回写（本轮已修复，待真机复核）

此前 `LvSwitch.svelte:13-20`、`LvInput.svelte:19-30`、`LvSelect.svelte:15-21` 只把事件值传给回调，没有给 `$bindable` 的 `checked/value` 赋值。现已先回写绑定值再调用回调，并新增真实 Svelte 宿主测试 `tests/kit-bindables.spec.ts`。

完成定义：组件事件后内部值、父级 draft、保存结果三者一致；补 `LvSwitch/LvInput/LvSelect` 双向绑定测试，并在设置页真机复核。

### P0：复习左右滑评分被状态守卫拦截（本轮已修复，待 Android 复核）

`src/ui/review.svelte:1162-1171` 已改为调用 `src/core/review-gesture.ts`：问题态左右滑不评分，仅上滑揭晓；答案态右滑=3、左滑=1。新增 `tests/review-gesture.spec.ts`。仍需在 Android 思源中验证输入框、链接、选区、滚动容器和一次手势只结算一次。

### P1：抽屉缺少完整焦点闭环（本轮已修复，待宿主复核）

`src/ui/kit/LvDrawer.svelte` 已接入 `focus-trap`：打开时焦点移入、Tab/Shift+Tab 循环、Esc 关闭、销毁后焦点归还，并声明 `aria-modal`/`aria-labelledby`；关闭标签通过 `closeLabel` 传入。详情抽屉和移动端返回行为仍需键盘、读屏和 Android 真机复核。

### P1：页签和详情分面语义不完整（本轮已修复，待宿主复核）

`LvTabs.svelte` 现在支持 `aria-controls` 面板前缀、横向方向和按焦点页签处理方向键/Home/End；Hub 和详情分面已补对应 `tabpanel`、焦点索引与键盘切换。仍需在读屏和宿主主题下复核。

### P1：管理器行把多个交互嵌在 `role=button` 行内（本轮已修复，待宿主复核）

`src/ui/manager.svelte` 已拆为独立 checkbox、原生详情按钮和打开文档按钮，checkbox 增加本地化 `aria-label`，避免嵌套交互元素与冒泡依赖。仍需在触屏和读屏下复核点击区。

### P1：窄屏和真实移动布局证据不足

虽然 390px 的结构化走查已有记录，但不能证明 320px、字体放大、软键盘、安全区、横屏和宿主主题下仍稳定。`index.scss:58-65` 的页面内距、复习卡的最小高度/内距和评分区仍应在 Android 思源中复核。桌面响应式或 browser-mobile 不应计作 Android 验收。

### P2：学习日历的网格读屏语义（本轮已修复）

`src/ui/kit/LvCalendar.svelte` 是只读展示，已移除不完整的 `role="grid"` 声明，保留月份 `aria-label`，避免把非交互内容暴露成可操作网格；`tests/kit-components.spec.ts` 增加结构回归。真实读屏器和宿主主题仍可在真机验收时复核。
