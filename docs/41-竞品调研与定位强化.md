## 1. 竞品与同类调研摘要（2026-10 网络调研）

### 1.1 专用间隔重复工具

| 产品 | 核心优势 | 明显短板 | 对小驴的启示 |
|---|---|---|---|
| **Anki**（含 25.x） | FSRS 的事实标准与发源地；海量共享牌组（医学/法律）；插件生态无敌；桌面+移动全平台 | UI 陈旧、学习曲线陡；统计靠插件（Review Heatmap 是最受欢迎插件之一）；协作靠 AnkiHub 订阅制 | FSRS 口径必须对齐（已由内核承担）；**热力图/预测图是一级需求**而非插件；共享牌组是生态护城河 → 做轻量「分享包」而非平台 |
| **RemNote** | 笔记+SR 一体（大纲层级驱动）；卡片即笔记的节点 | 自研算法透明度低；无思源式的块级双向链接；社区牌组少 | 「笔记即卡片来源」路线已被验证；小驴的差异化是**块级可回源**（卡片能跳回原文与版本），比 RemNote 的大纲绑定更强 |
| **Quizlet / Knowt** | 现成牌组市场、游戏化学练模式、上手零门槛 | Learn 模式不是真 SR；免费档持续缩水（Quizlet）、Knowt 靠 Quizlet 导入获客 | 游戏化要克制但存在（挑战/配对已有）；**上手零门槛**是小驴缺的——onboarding 引导 + 示例工作区（已有）要在原型里成为一级体验 |
| **Mochi** | markdown 笔记→卡片最流畅；界面极简干净；移动端好 | 无 AI 管线；无来源追踪；生态封闭 | 「从笔记到卡片的最短路径」是体验标杆——小驴的收件箱/划词制卡要做到同样顺手，且**多出可回源这一步** |
| **SuperMemo** | 增量阅读（IR）鼻祖，知识流入→摘录→卡片的全链路思想 | UI 几十年未现代化；学习成本极高 | 「材料流入→摘录→制卡」的全链路思想与 docs/27 使命一致；小驴的收件箱+AI 审核就是现代化的 IR |

### 1.2 AI 制卡工具（Monic.ai / Knowt / AnkiPro / Cogni 等）

- 2025-26 的现状：**「上传 PDF/PPT/视频/提示词 → 自动生成牌组」已是标配**，不再是差异点；Monic 还加 AI 对话材料、摘要、测验。
- 共同短板：生成内容**无来源锚定**（不知道卡片段落来自原文哪里）、无审核工作流（生成即入库）、调度黑盒。
- 对小驴：AI 管线的差异点不在"能生成"，而在 **「可核对」**——来源分条、逐卡预览、审核状态机、成本预算、拒绝策略（已在 T02/T03 落地）。原型要把这条审计链可视化为一级体验，这是所有 AI 竞品都没有的。

### 1.3 Obsidian 生态

- **st3v3nmw/obsidian-spaced-repetition**：笔记内卡片、Anki 式挖空、多牌组、复习弹窗——生态位与小驴最接近，但功能深度（统计/目标/考试/维护/管理器）远落后。
- 新一代极简插件（Euphoric Flashcards、Spaced Everything）证明：**「轻」本身是卖点**，但天花板低。
- 对小驴：互通已是双向（Obsidian SR 导入/导出已落地）；差异化继续拉开功能纵深，同时**保证首屏简单**（总览只回答"现在学什么"）。

### 1.4 思源生态内

- 思源**原生闪卡**（riff/FSRS）：块一键制卡、内核调度——小驴的调度地基，也是最大"竞品"。原生的短板：无 AI、无统计、无管理器、无目标/考试、界面简陋。小驴全部增值都建立在"内核管调度，插件管全生命周期"的分工上（ADR-3）。
- 集市同类：划词制卡/挖空增强类插件只做单点；无全生命周期平台型竞品。**小驴在思源集市内的定位唯一。**

### 1.5 体验基准（工具型软件的天花板）

Linear / Notion / Raycast 给出的通用标准，也是用户说"原型不够优秀"时的隐性参照系：

1. **一屏一个主问题**：首屏回答"我现在做什么"，其余渐进展开。
2. **键盘优先**：⌘K 命令面板、全快捷键、可见的 kbd 提示。
3. **信息密度可调**：默认疏朗，专业用户可加密（密度切换）。
4. **状态即设计**：loading/empty/error/partial 与正常态同等设计精度。
5. **微动效克制**：120-240ms、只动 transform/opacity。
6. **数据可视化克制**：数字为主，图表为辅，零装饰性图形。

## 2. 定位（锐化版）

> **小驴闪卡：思源笔记里的全生命周期记忆引擎。**
> 让笔记里的每一段值得记住的内容，都能**可回源地**变成卡片，用 **FSRS** 科学排期，用 **可审计的 AI** 提效；数据本地优先，带得走。

与 docs/27 的「全域学习操作系统」是同一定位的两句话版本：对外传播用上面这句（更具体），战略文档保留原句。三个不可替代的差异点（调研验证）：

1. **块级可回源**：卡片 ↔ 原文块双向跳转 + 内容版本历史——RemNote/Monic/Obsidian-SR 都没有。
2. **可审计的 AI**：来源分条 → 请求预览 → 逐卡审核 → 记分卡入库；AI 竞品全都是"生成即入库"。
3. **本地优先 + 带得走**：数据全在用户工作区，Anki `.apkg` / Obsidian SR 双向互通、备份恢复——Quizlet/Monic 类云服务的反面。

## 3. 功能地图（现状 → 强化 → 新增）

### 3.1 已实现（保持，原型覆盖）

制卡（划词/挖空/图片遮挡/QuickCard/文档批量）· 收件箱材料筛选 · AI 向导（来源→候选→审核入库）· 复习面板（四档评分/提示阶梯/超时/听写/打字/选择）· 统计（热力图/保持率/覆盖/连击/XP）· 管理器（筛选/详情四分面/版本追踪）· 目标（三步链+预算）· 考试计划（动态建议）· 维护（烂卡/暂停/回源）· 演练 · 备份恢复 · Obsidian SR 与 Anki apkg 互通 · 游戏化（连击/挑战/配对）。

### 3.2 强化（本轮设计直接体现）

| 强化点 | 依据 | 落点 |
|---|---|---|
| 总览改「今日驾驶舱」 | §1.5-1：一屏一个主问题 | R53 T01：hero 现场卡 + 目标环 + 4 统计瓦片（带趋势与迷你走势）+「下一步」清单，深度统计渐进展开 |
| 复习沉浸化 | Mochi/Anki 复习体验标杆 | R53 T04：720px 沉浸列、22px 卡面、HUD 进度+计时、四档评分（kbd+间隔）、提示阶梯 |
| 命令面板 | §1.5-2 键盘优先 | R53 T13（规划面）：⌘K 聚合「开始复习/继续现场/去卡组/快速制卡/导入导出」 |
| 学习日历与负载预测 | Anki Review Heatmap/Forecast 是最受欢迎能力，小驴只有热力图无预测 | R53 T14（规划面）：月历按日负载着色 + 未来 14 天到期预测条 + 可「平峰」调 schedule（只建议不改内核） |
| AI 审计链可视化 | §1.2 差异点 2 | R53 T03：来源分条 → 请求预览（片段数/端点/预算）→ 逐卡审核（记分卡 chip）三段式 |
| 状态即设计 | §1.5-4 | R53 全部面带 loading/empty/error/partial 样例状态切换 |
