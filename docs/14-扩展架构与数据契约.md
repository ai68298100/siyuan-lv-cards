# 小驴闪卡 · 扩展架构与数据契约

> 本文是"未来扩展空间"的落点：所有可变的东西（内核版本、题型、模块、生态）都有正式的接口或模式承接。实现语言 TypeScript，接口签名与 11 章模块编号对应。

---

## 1. FlashcardGateway：统一数据网关（L1）

上层模块唯一的数据通道。内核变化 = 换适配器，上层零改动。

```ts
/** 能力键：决定 UI 显隐与功能开关 */
export type GatewayCapability =
    | "decks" | "dueQueue" | "review" | "skip" | "undo"          // 复习基本盘
    | "setDueTime" | "reset"                                     // 干预
    | "queryAst"                                                 // V2 AST 查询（riff 为本地过滤）
    | "browseCards" | "manageCards" | "cardHistory"              // 管理
    | "tags" | "flag" | "editLater" | "suspend"                  // 卡属性
    | "statistics"                                               // 官方统计（V2）
    | "studyPolicy"                                              // V2 学习策略
    | "ankiConnect" | "ankiImport";                              // Anki 兼容

export interface FlashcardGateway {
    readonly kind: "riff" | "v2";
    readonly capabilities: ReadonlySet<GatewayCapability>;
    has(cap: GatewayCapability): boolean;

    // —— 复习 ——
    listDecks(): Promise<DeckRef[]>;
    fetchDue(scope: ReviewScope, opts: QueueOptions): Promise<DueQueue>;
    rate(card: DueCardRef, rating: Rating): Promise<void>;
    undoLast(): Promise<void>;
    skip(card: DueCardRef): Promise<void>;
    setDue(cards: DueCardRef[], due: string): Promise<void>;
    reset(cards: DueCardRef[]): Promise<void>;

    // —— 浏览/管理 ——
    browse(query: CardQuery): Promise<Paged<CardBrief>>;   // 内部翻译为 AST 或本地过滤
    cardDetail(id: string): Promise<CardDetail>;           // 含 history / S·D（若可得）

    // —— 统计 ——
    statistics(req?: StatisticsReq): Promise<StatisticsResult | null>; // riff 返回 null

    // —— 生命周期 ——
    migrationStatus(): Promise<MigrationStatus | null>;
}
```

- `RiffGateway`：17 个 `/api/riff/*`（`src/api/riff.ts` 已有雏形）；`statistics` 返回 null → 统计模块自动只用本地 revlog。
- `V2Gateway`：`/api/flashcard/*`；`browse` 翻译 `CardQuery` → 查询 AST。
- **选择器**：启动探测（M1·FR1）→ `GatewaySelector.pick()` 返回当前网关；`lv-cards:gateway-changed` 事件广播切换。
- 规则：**模块代码禁止直接 import riff/flashcardV2 API**，只能要 Gateway（lint 可加 import 边界规则）。

## 2. 卡型系统：`registerCardType`（M4，可插拔题型）

同一契约、双通道落地——**3.8 内部渲染 / 3.9 官方 V2 卡型桥接**：

```ts
export interface CardTypeRegistration {
    /** 如 "type" → sourceType = plugin:lv-cards:type */
    typeName: string;
    displayName: string;
    /** 是否参与调度评分（配对/挑战类为 false，只入激励） */
    gradable: boolean;
    /** 问题态渲染：挂载交互并返回"是否可判分" */
    renderQuestion(ctx: CardRenderCtx): CardTypeQuestionHandle | void;
    /** 判分：把用户作答映射为 Rating */
    grade?(answer: unknown): { rating: Rating; detail?: string /* diff 等 */ };
    /** 创建（向导里出现该题型）与编辑 */
    create?(ctx: CreateCtx): Promise<void>;
    edit?(ctx: EditCtx): Promise<void>;
}

interface CardTypeQuestionHandle {
    /** 打字题：阻止"点击空白翻面"抢焦点 */
    wantsInput?: boolean;
    onReveal?(): void;   // 翻面时回调（显示对照）
    destroy?(): void;
}
```

桥接策略：

| 内核 | 落地方式 |
|---|---|
| 3.8.x（无 V2 卡型） | 本插件复习面板内按 `CardTypeRegistration` 渲染；数据侧用标记符/块属性表达题型 |
| 3.9.0+ | 启动时把每个卡型映射到官方 `registerFlashcardV2PluginType(namespace="lv-cards", …)`：`render→render`、`grade→answerController.check`、遮挡类→`revealController`；create/edit 直通 |

官方 V2 渲染模型（`getRenderModel` + `IFlashcardV2PluginRenderContext`）作为 3.9 的首选渲染通道；内部渲染仅作 3.8 兜底。**新题型 = 新注册项**，不碰会话引擎。

## 3. 模块注册：`registerModule`（M0-M12 全体）

```ts
export interface LvCardsModule {
    id: string;                       // 稳定 ID（settings.modules 键）
    nameKey: string;                  // i18n
    phase: "v0.1" | "v0.9" | "v1.0" | "v1.x" | "v2.x";
    personas: Persona[];              // 参与哪些画像预设
    requires?: GatewayCapability[];   // 网关能力不足时自动隐藏并提示
    mount(ctx: ModuleCtx): void | Promise<void>;
    dispose?(): void;
}
// ModuleCtx = { gateway, settings, eventBus, storage, ui: LvKit, openReview(), i18n }
```

- **`ui: LvKit`**：呈现层统一入口（docs/16）——模块挂载 UI 时只能经 Kit 组件装配，保证全插件观感一致；Kit 缺件按 16 §5 准入流程补件。
- 设置面板、画像预设、事件系统**全部由注册表驱动**：新模块注册即被纳管，无需改设置代码。
- `requires` 不满足（如 statistics 在 riff 下）→ 模块置灰 + tooltip 说明，而不是报错。

## 4. 事件契约（L4 生态互通）

命名空间 `lv-cards:*`，载荷全部带 `plugin: "lv-cards"` 与 `v` 版本字段：

| 主题 | 载荷 | 消费者 |
|---|---|---|
| `lv-cards:reviewed` | `{cardID, deckID, rating, due}` | 打卡/复盘 |
| `lv-cards:session-finished` | `{summary:{new,review,forget,skip,durationMs}, scope}` | 打卡/复盘 |
| `lv-cards:streak-changed` | `{streak, milestone?}` | 打卡（去重后记账） |
| `lv-cards:cards-created` | `{batchId, count, source:"manual"/"ai", aiPresetId?}` | 复盘/拾遗 |
| `lv-cards:exam-milestone` | `{planId, daysLeft}` | 打卡/提醒 |
| `lv-cards:gateway-changed` | `{kind:"riff"/"v2"}` | 内部模块 |

反向消费：打卡插件数据存在才读（探测其存储/事件），读取失败一律静默。事件是模块间唯一软通道——**禁止跨模块 import**。

## 5. 存储模式（`data/storage/petal/siyuan-lv-cards/`，随思源同步）

| 文件 | 内容 | 版本策略 |
|---|---|---|
| `settings.json` | `{version, modules{}, persona, targets, ratingStyle, timeout, …}` | version=1 起步；字段只增不删 |
| `revlog.json` | `{version, entries[], days{}}`（现有） | 2 万条明细滚动；days 永久 |
| `exam-plans.json` | `{version, plans:[{id,name,examDate,scope,newLimit,cramDays,state…}]}` | v1.0 引入 |
| `ai-batches.json` | `{version, batches:[{id,preset,promptHash,cardIDs[],createdAt}]}` | 质量反哺（M2·FR11） |
| `suspend-today.json` | `{date, cardIDs[]}` | 次日自动清理 |

迁移规则：`load → migrate(vN→vN+1) → normalize → use`；每个版本一个纯函数，测试覆盖。所有文件可从数据子页导出/清空（M10）。

## 6. 兼容与变更管理

- **契约快照**：`docs/14` 随版本记录 riff/V2 端点使用面与已知字段（现状见 05）；内核升级后跑"兼容性事件"计数（M1·FR5）。
- **宽容解析**：所有内核响应经 normalize（缺字段→默认值/置灰），禁止直接解引用深层字段。
- **降级矩阵**：任何 P1+ 功能标注"无 V2 时行为"（例如统计=本地、撤销=官方缓存、搜索=本地过滤），写入 11 章 FR 的实现注记。
- **发版检查单**：`minAppVersion`、bazaar 文件齐备、双端构建、i18n 完整性、迁移函数测试、性能预算（启动 <100ms、评分链路 <50ms 额外开销）。

## 7. 扩展示例（验证架构的三个假想）

1. **官方 4.0 换调度**：只写 `V3Gateway`，能力矩阵微调，上层无感。
2. **新题型"完形填空多篇连做"**：新建 `card-types/cloze-passage` 注册即可；向导、复习面板、V2 桥接自动生效。
3. **小驴复盘要消费统计**：复盘插件监听 `lv-cards:session-finished` / 读取周报导出文件，双方零代码耦合。

## 8. 事件契约（lv-cards:* · 561 固化）

所有事件经思源 plugin.eventBus 广播；payload 一律含 `plugin: "lv-cards"` 与 `v: 1`（协议版本，向后兼容时只增不改）；消费方须 try/catch 自包（生产者已旁路，不因消费者崩溃）。

| 主题 | 触发时机 | payload（v1） | 幂等性 |
|---|---|---|---|
| `lv-cards:reviewed` | 每次有效评分写入本地 revlog 后 | `{cardID, deckID, blockID, rating(1-4), source("plugin"|"native")}` | 每评分一次，不重放 |
| `lv-cards:streak-changed` | 连击天数变化时（reviewed 内联判断） | `{streak}` | 仅变化时发 |
| `lv-cards:session-finished` | 会话进入完成态且本会话有有效评分（每次进入只发一次） | `{summary:{new,review,forget,skip}}` | 同会话去重 |
| `lv-cards:gateway-changed` | 设置页手动重探 V2 后 | `{state("Active"|"Preparing"|"Legacy"|"LegacyDiverged"|"N/A (<3.9.0)")}` | 手动触发 |
| `lv-cards:cards-created` | 预留（制卡批次事件，待消费端一并落） | — | — |

> 失败隔离：emit 全部包 try/catch，事件总线异常不影响主流程；消费端异常由消费方自负。
