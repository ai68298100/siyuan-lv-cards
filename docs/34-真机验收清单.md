## E2E-1 自动化验收首轮（2026-10-04，v0.110.2 · 计算机操控自动化）

**环境**：思源 3.8.6 桌面 Windows / 工作区 `D:\小飞驴的SIYUAN` / 单文件内联构建（见发现 1）/ 启动方式 `scripts/e2e-launch.ps1`（显式 `--workspace`，PowerShell 需 UTF-8 BOM 否则中文路径乱码）。
**结果**：通过 7 项；发现 3 个真问题（均已处置或登记）。

**发现 1（P1，登记 AT-12）**：思源 3.8.6 插件 require shim 为 `ut==="siyuan"?ge():window.require?.(ut)`——相对路径 chunk require 原样透传给 Electron Node require，以应用包为基准解析必然失败（bundle 反证：common.js line 5326）。多分包 CJS 构建（本插件 chunk 版、官方 install-package、siyuan-home、siyuan-exam 间歇）全部受累。**处置**：真机构建采用单文件内联产物（`vite build -c vite.config.inline.mjs`，gzip 88KB）；正式修复与门禁影响归 AT-12。
**发现 2（P2，登记 AT-13）**：`getRiffDueCards` 全局（deckID=""）对**手动创建卡包**的新卡返回 0（卡组维度正常）——全局角标与「全部」复习范围受影响；内核 3.8.6 行为。
**发现 3（已修复=v0.110.2）**：Plugin 实例 openTab 方法已移除（旧 API），入口点击抛 TypeError；另 custom.id 必须与 addTab 注册键一致（`plugin.name + type` 无分隔符，bundle addTab 实现反证）。

**复验指引**：重跑本轮 = `pnpm build && npx vite build -c vite.config.inline.mjs` → 部署 dist-inline 到 `data/plugins/siyuan-lv-cards/` → `scripts/e2e-launch.ps1` → 顶栏图标走查。

## V-1 会话恢复冒烟（AQ-1 / AQ-2 / M-03 · P0）

**前置**：一个卡组 ≥5 张到期卡；插件 v0.77.x。
**步骤**：
1. 打开复习，评 2 张（1 张评分、1 张跳过），记下完成页/头部计数；
2. 设置 → 禁用再启用小驴闪卡（或重启思源）；
3. 重新打开复习。
**预期**：计数恢复为「已评 2」；跳过的卡不再出现；队列从剩余卡继续；进度条位置正确。
**证据**：禁用前后各截一张复习头部；「复制诊断」一份。
**失败特征**：计数归零（AQ-1 回归）；跳过的卡重新出现（AQ-2 skippedIDs 断）。

## V-3 原生评分旁听（AQ-5 · P1）

**前置**：思源原生复习入口（块 hover → 闪卡图标）。
**步骤**：在**原生界面**连续评分同一张卡 2 次（快速），再正常评 2 张不同的卡；复制诊断。
**预期**：诊断 recent log 中每卡一条 `native rating`；重复点击出现 `deduped`；总览计数与实际次数一致。
**失败特征**：同一评分记两次；出现 rating 越界的脏记录。

## V-4 写入失败可观测（AQ-4 · P1）

**步骤**：① 正常复习数张确认统计推进；②（可选故障注入）以只读方式打开 `data/storage/petal/siyuan-lv-cards/`（如占用文件锁），再评分，观察是否出现「数据保存失败」提示；解除占用后任意操作一次。
**预期**：正常路径无感知；故障时有限重试后出现一次错误 toast（30s 限流不刷屏）；诊断 persist 段可见 `fail≥1` 与 lastError；解除后恢复写入。
**证据**：诊断输出。

## V-5 对话框关闭责任（AR-2 · P0）

**步骤**：逐个打开 选卡组/AI 向导/快速制卡/标记制卡/遮挡编辑器/挑战/配对，分别验证 ① 内部「取消/完成/导入成功」后对话框关闭 ② 宿主 X 关闭 ③ Esc 关闭 ④ 各路径只触发一次（无残留遮罩/重复回调，如 onboarding 不重复 markOnboarded 弹 toast）。
**附加（选卡组）**：断网或输错使 `createRiffDeck` 失败 → 对话框**不关闭**、红字错误、已选卡组与新建名保留。
**附加（焦点）**：从思源编辑器按钮打开任一对话框，Esc 关闭后按方向键，焦点应回到编辑器（AR-2 焦点归还）。
**证据**：每对话框一张关闭后截图；失败保留草稿录屏。

## V-7 AI 取消与降级（AQ-14 / AQ-15 · P1 · 需真实 AI 配置）

**步骤**：① 配置主端点+备用端点，点生成后立刻点 ✕ → 无「已切换备用端点」提示、无批次记录增加；② 生成中切换卡型/材料再生成 → 旧候选不被旧响应覆盖；③ 把主端点改成必 5xx 的地址 → 自动回退并 toast 提示；④ 改成 401 → 直接报错不回退。

**证据**：每种情况截屏 + 诊断。

## V-8 超时与挑战计时策略（AR-7 / AR-10 · P1 · 📱）

**步骤**：① 开启超时翻面（60s），复习中切后台 30s 再回 → 剩余时间按壁钟扣减（约剩 30s）；② 限时挑战开始后立即切后台 10s → 回前台倒计时同样按壁钟校正且到 0 只结算一次。
**预期**：无「倒计时冻结」或「回前台瞬间跳完成」。
**证据**：录屏。

## V-9 考试动态建议与复盘报告（AQ-8 / AR-11 · P1）

**步骤**：① 新建计划（deck 范围、总卡量留空）→ 卡片显示「容量未知」口径；② 填 totalCards=100、createdAt 设为 5 天前 → 显示日均 4/天 + 落后补偿；③ 把每日上限调小使剩余量/天数超限 → 显示「需 N 天，来不及」；④ 生成复盘报告 → 窗口起点=计划创建日、范围正确、无「缺失计 0」。
**证据**：三种状态截图 + 一份导出报告。

## V-15 AI 导入中断续传（AQ-17 / ADR-7 · P1 · 需真实 AI 配置）

**步骤**：
1. AI 向导生成 5 张卡 → 预览 → 选卡组导入；
2. 导入进行中（第 2 张落卡后）强制中断：关闭思源窗口（或断网使 appendBlock 失败）；
3. 重新打开 AI 向导。
**预期**：顶部横幅「上次有未完成的 AI 导入（2/5 已落卡）」+ 继续/放弃；点「继续」从第 3 张续传且不重复前 2 张；全部完成后横幅消失、卡组内 5 张齐全。失败卡用「复制失败明细」导出核查错误原因。
**附加**：中断后选「放弃」→ 横幅消失、已落卡保留不动（设计决策：不回滚，见 docs/24 ADR-7）。
**证据**：中断前后卡组截图 + 横幅截图 + 续传后卡组清单。

V-1/V-2（核心，10 分钟）→ V-5（对话框，10 分钟）→ V-3/V-4（10 分钟）→ V-6/V-10/V-12（15 分钟）→ V-9/V-11/V-13/V-14（20 分钟）→ V-8（📱 移动端专场）→ V-7（需 AI 配置，最后）。全程约 1.5-2 小时。V-15（AI 导入续传）与 V-7 同属需真实 AI 配置的专场，建议紧随 V-7 执行；另需一次「导入中强制中断」的操作配合（关窗或断网）。
