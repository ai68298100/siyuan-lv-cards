# FAQ 与故障排查

**Q：为什么路线图里有些功能现在没有？**

小驴闪卡的目标是覆盖最完整的闪卡学习能力，但能力按当前宿主、外部依赖、隐私和验证条件分阶段交付。暂时做不到的项目会进入后置池，保留依赖、替代路径和复评条件；这不代表永久取消。查看[产品使命与全功能战略](./27-产品使命与全功能战略.md)和[分层路线图](./04-路线图.md)。

## 复习

**Q：点「开始复习」提示没有卡？**
先在编辑器里为块添加闪卡（块图标菜单 → 添加到卡组）。范围选择器只显示有到期卡的范围。

**Q：面包屑按钮没出现？**
该入口仅在宿主提供所需接口且「复习面板」模块开启时注册，具体版本与设备还需验收。没有按钮时可从顶栏或命令面板进入，不仅凭版本号判断支持。

**Q：撤销按钮灰了 / 没反应？**
撤销基于本场历史栈，本场还没有评分时不可用。

**Q：打字模式判分太严/太松？**
设置 → 学习偏好中的严格判分开关影响大小写与标点处理。相似提示仅供对照，当前宽松规则对数值、符号和多余内容仍有误判风险；请核对参考答案后自行评分，不能把相似度当作正确性。

## 统计

**Q：热力图是空的？**
热力图数据从启用本插件起记录（本地复习日志）。旧版思源的历史不含在内。

**Q：「AI 批次质量」区块是空的？**
使用 AI 制卡向导完成一次导入后出现；保持率需要该批卡片被复习过才有样本。

**Q：数字对不上官方统计？**
本插件热力图和保持率主要使用自启用后记录或导入的本地日志；内核提供的统计另有覆盖范围。保持曲线虚线当前是固定衰减参考，不是你的个性化内核预测；口径与样本不同，不能直接据高低判断掌握或效果。

## 考试模式

**Q：每日建议量显示 "—"？**
需要在计划里填写「范围总卡量」（卡组范围可自动，笔记本/全部范围无法自动统计）。

**Q：cram 模式怎么触发？**
剩余天数 ≤ 计划的「考前 cram 天数」时自动激活，计划卡片变红。

## 数据

**Q：清空复习日志会丢什么？**
只丢热力图/连击等本地统计；卡片与调度完全不受影响。清空前会先提示，建议先导出备份。

**Q：两台设备复习后统计不一致？**
复习日志按条目去重合并（时间+卡片+评分+来源）；如仍分叉，用「导入合并」手动合并一次。

**Q：CSV 导出的 `review_state` 列为什么是空的？**
本地日志没有内核的复习状态字段，导出时显式留空而不猜测（v0.66 起格式：`...,source,duration,review_state`）；`duration` 是插件复习面板的作答耗时秒，原生界面的评分该列为空。统计口径详见内置帮助「复习日志统计口径」与[隐私说明](./PRIVACY.md)。

**Q：很久以前的明细去哪了？**
本地明细只保留最近 2 万条评分；更早日子的每日聚合（热力图/连击）以快照保留，不会回退。完整构成与上限见[隐私说明](./PRIVACY.md)。

**Q：V2 · LegacyDiverged 是什么意思？**
这是探测中的迁移分歧状态，不等于已完成 V2 复习切换。当前中心没有独立“数据”子页，请结合设置/诊断中的实际宿主状态与[宿主调研](./05-内核闪卡V2重构调研与应对.md)核对；任何迁移或恢复操作先确认备份和该版本支持的流程，不能仅凭徽章直接重跑迁移。

## AI 制卡

**Q：点生成报错？**
检查思源设置里的 AI 配置是否可用；或在本插件设置切换到自定义端点。材料过长请分段。

**Q：生成的卡片质量差？**
先在原文或剪贴板中准备范围清楚、带必要条件的材料，再载入向导；控制题量，逐张编辑、取消不适合的候选。当前向导材料预览/裁剪仍待完善，批次记录只反映用量及已观察到的复习样本，不能证明答案正确或哪批最耐记。

**Q：思源 Agent 能直接替我评分、改期或删除卡吗？**

当前小驴 Agent 接入属于规划，尚未上线。规划中 Agent 负责理解意图、查询和准备候选计划；AI 不能代替正式评分，涉及内容写入、分享、删除或外发的动作经过预览确认。宿主缺少所需接口时使用普通 UI 或手工流程。

**Q：为什么 AI 没有直接给出答案？**

规划中的任务模板将区分来源不足、来源冲突、内容过时、权限不足和模型限制，返回“待核实/需补材料”。当前生成错误可先缩小材料范围、检查模型配置或手工制卡；成本硬上限、本地模型与统一拒答机制见 BU 待办。

**Q：AI 请求前为什么要显示上下文和外发范围？**

这是 BU 组规划中的统一交互，尚未完整实现：预览将列出来源片段、脱敏结果、端点/模型、用量和保存策略，并支持裁剪或取消。当前请在发送前检查所选材料与主/备用端点；核心复习和导出可独立使用。
