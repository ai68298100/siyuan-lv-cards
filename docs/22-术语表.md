# 术语表（中英对照）

| 中文 | English | 含义 |
|---|---|---|
| 复习集 | Review Set | 一组可复习的卡片集合（对标 Anki Deck） |
| 新卡 | New Card | 尚未进入复习调度的卡片 |
| 复习卡 | Review Card | 已进入复习调度的卡片 |
| 遗忘 | Lapse / Again | 复习时未想起（评分 1） |
| 连续天数 | Streak | 连续每天至少完成一次复习的天数 |
| 烂卡 / Leech | Leech | 遗忘次数达到阈值的顽固卡片 |
| 保持率 | Retention | 复习时成功回忆的比例 |
| True Retention | True Retention | 按卡片成熟度分层的真实保持率 |
| FSRS | Free Spaced Repetition Scheduler | 开源间隔重复调度算法（内核原生） |
| Stability | Stability | FSRS 记忆稳定度参数 |
| Difficulty | Difficulty | FSRS 记忆难度参数 |
| 考试计划 | Exam Plan | 以考试日期为目标倒排学习进度的计划 |
| 考前 cram | Pre-exam cram | 考前 N 天集中强化模式 |
| 睡前巩固 | Evening consolidation | 只学新卡的快速过一遍模式 |
| 画像预设 | Persona preset | 一键切换模块开关与参数组合 |
| 挖空 | Cloze deletion | 文本中挖空关键词让用户填答 |
| 图片遮挡 | Image occlusion | 图片区域遮挡式问答 |
| 听写模式 | Dictation mode | 朗读答案 + 输入听写的练习模式 |
| 选择题模式 | Multiple-choice mode | 四选一练习模式 |
| AnkiConnect | AnkiConnect | Anki 的 HTTP API 插件（思源也兼容此协议） |
| apkg | Anki package | Anki 牌组导入导出格式 |
| revlog | Review log | 复习历史记录（逐次评分明细） |
| 作答耗时 | Answer duration | 题面呈现到评分的秒数（仅插件面板记录，按设置封顶；原生评分无此字段留空） |
| knownCards | Known cards | 曾有评分的卡 ID 列表（明细截断后仍保留首评语义，上限 2 万） |
| 卡片覆盖 | Card coverage | 本地有评分的卡 ÷ 内核卡组规模合计；覆盖率≠掌握率 |
| SR 语法 | Obsidian SR syntax | Obsidian 闪卡语法（`::`/`:::`/`?`/`??`/`==挖空==`），标记制卡兼容识别 |
| 动态建议 | Dynamic advice | 考试计划的每日学习量建议（含落后补偿与不可行提示；只读，不改内核调度） |
