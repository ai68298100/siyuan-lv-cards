# 小驴闪卡 · UI 原型图（ASCII Wireframe）

> **视觉语言已升级为「星轨 Starline」设计系统（docs/15）**：本文线框表达布局与信息层级；实际观感按 15 的令牌执行——表面微渐变卡片、派生 1px 边框、双层软阴影、主色渐变展示数字、语义色 soft 评分条、毛玻璃浮层、120/180/240ms 微动效。代码实现见 `src/index.scss`（令牌）与四个 Svelte 组件。
> 视觉基准：全部使用 b3 变量派生（color-mix），亮暗主题自适应。
> 图号与 12-交互设计规范 的状态一一对应。

## 设计令牌（Design Tokens）备注

- 颜色：仅 `--b3-theme-*` / `--b3-*` 变量；语义映射 主色=良好/主操作、error=遗忘/危险、warning=困难/滞后、成功=目标达成。
- 圆角：卡片 6px（.b3-card 默认）；按钮 .b3-button 默认。
- 间距：页面 16px / 卡内 12px / 组件间 8px。
- 字号：页题 18/700、区块题 14/600、正文 14、元信息 12。
- 动效：翻面 160ms、评分按压 80ms、庆祝 ≤2s；全部尊重减弱动态。
