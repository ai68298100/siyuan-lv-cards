## 1. 原型如何阅读

### 1.1 当前能力与目标设计分开

| 状态 | 在本文中的含义 | 用户界面应如何处理 |
|---|---|---|
| 源码已有 | 当前 v0.63.0 存在相应页面或调用路径；不等于本轮已经通过回归 | 发布介绍只写实际可用子集；不能由目标线框推断全部能力 |
| 现版回归待验 | 已有路径仍有已登记断点，或需要核对真实宿主行为 | 先修、先验；失败与能力限制可见，不包装成“已经完善” |
| 规划 | 对应既有待办和体验规格，尚未开发或未完整交付 | 只出现在规划文档；产品内只有能够执行的入口才可用 |
| 宿主/研究后置 | 稳定接口、专业验证、数据或外部依赖尚未成立 | 隐藏不可执行动作或解释限制，并保留本地人工替代 |

当前中心只有**总览、管理、可选考试**三类子页；AI 制卡向导有配置、候选两个画面。下文十个任务面是总览上层、上下文工作面、抽屉、任务步骤或设置分面，**不要求十个顶级 Tab**，也不强行把每个任务装入同一种容器。

| 当前载体 | 源码已有范围 | 本轮原型补齐的目标 | 状态 |
|---|---|---|---|
| 总览、中心 | 统计、模块入口与三类导航 | 今日行动优先、继续现场、选择模式与正常收工 | 源码已有；任务层级为规划 |
| AI 制卡 | 配置、加载材料、候选编辑与创建 | 可读可改材料、外发预览、已审状态、局部改写、结果落点 | 源码已有；安全与取消路径回归待验，扩展为规划 |
| 复习面板 | 揭晓、用户评分、跳过、输入/选择、来源与小结等路径；限时到点揭晓答案，不自动评分 | 阶段动作一致、正式评分由用户确认、互斥本场偏好、提交未知处理、旁路结果分账 | 源码已有；恢复、计数和手势等回归待验 |
| 管理、详情 | 分页列表、本页过滤与详情抽屉 | 统一搜索范围、上下文返回、内容/来源/记录/问题分区 | 源码已有；全库检索与深层详情为规划 |
| 考试 | 范围、计划与相关报告入口 | 目标/课程、投入预演、应用证据与多目标取舍 | 考试源码已有；课程与深层证据为规划 |
| 设置、首用 | 模块与偏好配置、三步首用示例 | 设置查找、效果预览、隐私分面、隔离修卡演练 | 源码已有；搜索/预览/隔离演练为规划 |
| 待处理、侧栏、Agent | 各模块有独立状态或相关基础路径 | 任务聚合、可恢复交接、伴随学习与受限智能体动作 | 聚合为规划；宿主侧栏/Agent 运行时契约需分别验证 |

### 1.2 所有任务面的共同骨架

进入时回答“我在做什么、依据哪份材料、当前是什么模式”；离开时回答“已做成什么、还未确定什么、回来从哪里继续”。

~~~text
┌ 返回原任务 · 任务名 ──────────────────────────────────────────┐
│ 目标/范围 · 当前对象 · 模式        本地状态/最后检查时间       │
│ [任务内容与依据：材料、问题、答案、差异或真实结果]             │
│ 未决项就在相关内容旁；必要条件不藏在帮助或长日志中             │
│ [次级动作]                              [本阶段主动作]       │
│ 保存/退出的影响可查看；不确定的写入仍保持“待核对”              │
└──────────────────────────────────────────────────────────────┘
~~~

共用约束：

- 短确认可用弹窗；多材料、长审核、可恢复作业用工作面；对象详情优先抽屉。容器由任务长度、来源上下文和设备决定。
- 一个阶段通常有一个主动作；揭晓后的评分是同级选择，不突出某个档位为“建议接受”。批量写入前给真实范围和影响预览。
- 主状态区分空、加载、旧数据、失败、未知、取消、部分成功和缺能力。刷新失败保留最近有效数据及时间，未知不能显示为 0。
- 返回保存对象、查询、范围、排序、页码、选择语义、滚动和焦点；跳到来源保留精确块与原任务返回点。过期选择先重新核对。
- 只在真实可执行的下钻处显示链接或箭头。静态数字不伪装导航，费用/数量/进度无可靠数据时写“未知”或“估算”。
- AI 建议、人工确认、已创建内容、正式复习和应用证据各有明确身份。AI 失败时保留材料与草稿，手工路径继续服务同一目标。
- 发模型前说明本次任务、实际材料、端点与预算；用户可裁剪或拒绝。思源智能体只在宿主契约与权限已验证时出现，不由工具注册推断能自动打开对话。

### 1.3 R52 视觉质感与页面节奏

目标质感来自**稳定的阅读节奏**：中性背景托住白色工作面，任务标题、当前对象、主动作按同一条垂直轴对齐；品牌色只强调当前状态和可执行动作，不能用大面积渐变、玻璃或动效制造“高级感”。

| 层级 | 规格 | 目的 |
|---|---|---|
| 页面框架 | 桌面内容最大宽度约 1200px，侧栏/工作面留 24px 间距；窄屏左右内边距 16—18px，首屏先给当前任务 | 让任务有呼吸感，避免统计与工具栏抢题面 |
| 表面 | 页面背景、工作面、软提示面三层；边框 1px，卡片圆角 12—16px，阴影只表示层级 | 让来源、编辑、卡面、结果各自成组，低端可退纯色 |
| 文字 | 页题 24/700、区题 15/650、正文 14、说明 12；数字使用等宽数字；长答案按段落和条件分层 | 先读懂内容，再看状态和操作 |
| 状态 | 候选/已审/已创建/待核对/失败使用文字 + 低饱和语义面；未知永远不显示为 0 | 不用颜色或徽章替代事实含义 |
| 动作 | 主动作每阶段最多一个；次级动作描边/文字按钮；评分按钮同级且不自动强调某档 | 减少“下一步到底点哪里”的猜测 |
| 动效 | 默认静态；只对揭晓、保存、错误和任务切换做 120—240ms 短反馈；`prefers-reduced-motion` 时完全可关闭 | 不打断回忆和长内容阅读 |

桌面三栏只在宽度足够且用户正在查证时启用；窄屏改为“来源 / 编辑 / 卡面”同一对象的分面切换，并保留返回点、焦点、滚动和草稿。原型中所有数字和材料都是状态夹具，实际实现须从真实对象、内核结果或明确的未知状态填充。

### 1.4 R52 评审稿的边界与视觉实现缺口

- 评审稿是十个任务面的合成数据场景夹具；它用于比较信息层级、状态语义、响应式断点和动作落点，不作为产品功能、统计数据或宣传截图。
- `正常 / 加载 / 旧数据 / 失败 / 未知 / 取消 / 部分成功 / 禁用 / 焦点 / 长内容` 需要在页面级组合场景中逐一核对。组件画廊只负责单个 Kit 组件，页面级组合快照与差异门禁归入 [BY-1](./17-待办清单.md#by-第九轮原型质感场景夹具与视觉验收仅扩充规划)；不将营销素材当作验收证据。
- 视觉实现时继续复核 `prefers-reduced-motion`、用户动画偏好和认知负荷：状态点默认静态，只有真实进行中的任务才允许短暂动效；揭晓反馈也必须受相同门禁约束。当前源码中的装饰性 `breathe`/`glow` 不能直接视为 R52 规范已落地。
- 所有页面级快照应标注 `synthetic`，并检查亮/暗主题、第三方主题、320/768/1280 断点、键盘焦点、长答案/代码/表格、返回上下文和无障碍结构；真实数据、评分、费用和模型外发不进入评审稿。

## 2. 导航与学习旅程

### 2.1 当前导航承载渐进任务面

~~~text
顶栏 / 命令 / 块菜单
  ├─ 开始复习：确认范围与模式 → 专注复习 → 结果与下一步
  ├─ 闪卡中心
  │    ├─ 总览：今日行动 → 继续现场 / 复习 / 材料 / 待处理
  │    ├─ 管理：范围与列表 → 对象详情 → 来源/维护 → 返回列表
  │    └─ 考试：模块启用时显示；目标/课程在其相关任务面渐进扩展
  ├─ 材料入口：材料整理 → 手工或 AI 候选 → 审核 → 真实结果
  └─ 设置 / 上下文帮助：偏好与隐私 / 演练
文档阅读上下文
  └─ 块菜单 / 选区命令 → 材料或对象；稳定宿主能力成立后可加伴随侧栏
~~~

顶栏有到期时可直接进入复习，无到期时进入中心；到期查询未知显示核对与重试。移动端若使用启动器，其行为与此相同，不能总是打开空复习页。入口图标、角标、菜单和快捷键的实际可用性仍按发布包与宿主核验，不由线框承诺。

~~~mermaid
flowchart LR
    A[今日或文档入口] --> B[材料与范围]
    B --> C[手工或 AI 候选]
    C --> D[来源与实际卡面审核]
    D --> E[真实创建结果]
    E --> F[正式复习或旁路练习]
    F --> G[结果与下一步]
    G --> H[来源与内容维护]
    H --> B
    C --> I[待处理与恢复]
    D --> I
    E --> I
    I --> C
    A --> F
~~~

## 3. 今日行动：先让用户开始一件合适的事

状态：现有总览为载体，以下今日任务层级为规划。对应 E-01/02/21/25/28、BX-3；旧 W1/W6/W13。

宽屏首屏：

~~~text
┌ 小驴闪卡 ── [总览] [管理] [考试：启用时] ──────────── [设置] ┐
│ 今日 · 目标：能解释网络基础        可用时间 [15 分钟 ▾]      │
│ ┌ 继续现场 ─────────────────────────────────────────────┐  │
│ │ 第 3 章 · 正式复习 · 上次停在第 5 张                    │  │
│ │ 剩余范围与来源仍有效；本场偏好：自由回忆                │  │
│ │ 本场结束：时间到 / 本范围完成 / 主动收工均可            │  │
│ │                                            [继续本场]│  │
│ └───────────────────────────────────────────────────────┘  │
│ 正式到期 12（内核） · 范围：网络基础      [核对范围]        │
│ 其他选择：[整理材料 3] [处理疑问 2] [只练习，不正式评分]    │
│ ▸ 查看统计与依据     ▸ 查看目标/课程      ▸ 待处理与恢复    │
└────────────────────────────────────────────────────────────┘
~~~

窄屏保留任务优先级，统计折叠：

~~~text
┌ 今日 · 网络基础 ────── [更多] ┐
│ 可用时间 [15 分钟 ▾]         │
│ 继续：第 3 章，正式复习       │
│ 上次现场与范围已核对         │
│ [继续本场]                   │
│ 正式到期 12 · [范围]         │
│ [整理材料] [处理疑问]         │
│ ▸ 统计与依据                 │
└──────────────────────────────┘
~~~

主动作按状态选择“继续本场”或“开始复习”；两个动作不同时争夺主层级。AI 可按用户选择给一个范围/投入建议和理由；无 AI 时用本地计数、已知目标与手工选择，仍能启动、整理或收工。返回来源后恢复今日任务和原现场，推荐可忽略。

| 状态 | 内容与下一步 |
|---|---|
| 空 | 无卡时“选择一段值得学习的材料”，可手工制卡或演练；确认无到期可正常收工、练习或维护 |
| 失败 | 今日数据拉取失败保留旧值及更新时间，给重试；仍允许打开材料/本地可用内容 |
| 未知 | 到期、时间估算或来源有效性未知就标未知；不根据旧值宣称目标完成 |
| 取消 | 关闭建议或取消会话准备回今日，不改变全局偏好、不创建评分 |
| 部分成功 | 目标加载成功、部分范围不可用分别列出；可选已核对范围，其余进入待处理 |

└────────────────────────────┘
~~~

主动作通常是“结束并保存现场”，需要修复时明确未决状态并给对应入口。完成、时间到、精力不足、主动结束、中断和部分失败分别命名；收工不制造失败感，也不默认推“再来一批”。创建任务结束后可打开真实对象、继续审核、旁路试练或回源，不用瞬间消失的提示替代结果页。

AI 可解释真实数据、给可编辑下一步；本地摘要同样展示结果、依据和对象。正式复习、旁路练习、应用、演练、AI 建议与系列外部动作不加成一个“学习完成数”。图表展示窗口、分母、缺失与数据时间，有文本/表格等价，不把经验曲线当个人预测。

| 状态 | 内容与下一步 |
|---|---|
| 空 | 没有写入或作答也可“未执行，现场已保留”；回任务、演练或正常结束 |
| 失败 | 摘要/报告生成失败不抹除已确认动作，本地结果仍可读；重试报告不重做原写入 |
| 未知 | 未知写入、缺计时或数据不完整就显示未决/未知；不能宣布全部完成或掌握 |
| 取消 | 中止任务说明已成功与未执行范围；取消 AI 报告仍能收工，保留原数据 |
| 部分成功 | 逐项已成功/失败/未执行/待核对；仅重试确定未成功且允许重试的项 |

| 取消 | 停止作业说明已发送/已写入范围；退出面板不等于取消原作业，撤回需原任务支持 |
| 部分成功 | 明确每项成功、失败、未执行、未知；只恢复允许的剩余项，完成后回原返回点 |

## 13. UI、内容与设备的统一规则

这些规则作用于十个任务面，详细参数取 12/15/16，避免维护第二份令牌。

| 维度 | 原型中的约束 | 验证关注点 |
|---|---|---|
| 视觉层级 | 任务与阶段、学习内容、来源/状态依次清晰；统计与装饰不抢当前动作 | 长材料、长答案、多个问题时仍能找到主动作与依据 |
| AI 内容 | 内容旁展示引用、未知与差异；高级模型参数按需展开 | 未核实候选不伪装事实，取消/拒绝/无模型路径完整 |
| 学习文案 | 说明发生什么、依据什么、下一步做什么；收工、暂停与返场正常化 | 不用连击、百分数、经验曲线宣布永久掌握或制造负担 |
| 操作语义 | 文字/数字与颜色并用；图标可读，有禁用原因；真实动作才可点击 | 键鼠、触屏、读屏同义；不靠 hover 找操作 |
| 焦点与输入 | 关闭浮层回调用入口；搜索/输入/IME/选区/媒体不触发页面评分 | Esc 分层关闭不误丢草稿，输入法确认不提交 |
| 窄屏 | 同对象分面与保留返回点；评分可 2×2；软键盘不遮待提交输入和必要动作 | 320px、字号放大、横竖屏、长代码/表格、safe-area |
| 主题与动效 | 从宿主语义色派生，默认静态；纯色/无 blur/减弱动态保留状态 | 亮暗/第三方主题、对比度、可见焦点；派生不等于通过 |
| 数据与性能 | 大列表按实际结果集分页，图表有文本/表格；旧响应不覆盖新范围 | 大库、快速切换、刷新失败、低端设备、前后台恢复 |
| 隐私 | 本次范围可见可裁剪；私密展示有持续状态与退出；诊断默认脱敏 | 不外发未经允许材料，不暴露密钥，不误导遮蔽能力 |

面向用户的主流程使用“任务、范围、候选、已审、正式复习、练习、待核对、来源”等词。原始接口、错误堆栈、模板标识、协议与诊断轨迹进入可复制的诊断详情；不要把这些实现名词堆到首屏。

## 14. 逐步验证与交付范围

不按本文章节顺序一次开发全部页面，继续服从 30 的切片与门禁：

| 阶段 | 原型验证与交付关注 |
|---|---|
| 当前真实阻断优先 | 加载/恢复、揭晓/评分计数、关闭/取消、手势阶段、输入与来源范围先修先验 |
| 一条手工主链 | 今日或文档→材料→手工候选→实际卡面审核→正式复习→结果→回源维护；无模型也完整 |
| 首个 AI 增强 | 问答/挖空按任务安全调用、来源校验、审阅、差异与批次恢复；不是等待全部模板完工 |
| 按价值扩展 | 卡型、目标/课程、应用证据、设置预览、演练、数值政策按真实任务分别验证 |
| 宿主与生态 | 伴随侧栏、思源 Agent、系列插件与互通按稳定接口和最小契约独立验收；核心本地流程继续可用 |

先用低保真观察五类任务：首次从材料建卡；只有五分钟开始学习；觉得答案有误；批量任务中断；长时间离开后返场。每次包括成功、主动取消、失败、未知、部分成功、缺依赖和窄屏返回；“看懂图”不能替代可用性或真机验收。

本轮验证只核对规划文档、引用、编号映射与语义。ASCII 与 Mermaid 不证明视觉对比度、读屏、性能、模型质量或宿主行为已经通过；后续真实切片需要对应证据才能改变状态或发布承诺。
