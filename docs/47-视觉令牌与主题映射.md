# 小驴闪卡 · 视觉令牌与主题映射

> 本文记录 R54 原型静态配色与生产样式令牌之间的语义映射，以及可复用控件的必要变体。原型用于视觉评审，生产界面使用思源宿主主题；两者共用语义命名，不共用颜色数值或主题运行机制。

## 1. 主题边界

生产界面在 `src/index.scss` 中读取思源的 `--b3-theme-*` 变量，再派生 `--lv-*` 语义色。安装插件的宿主主题可能不同，因此生产颜色随思源主题变化；原型的 `:root` 与 `[data-theme="dark"]` 则保留独立静态色值，供设计评审时稳定切换。原型中的 literal 值不应复制进生产组件，也不代表宿主主题的最终颜色。

| 语义 | 原型令牌 | 生产来源/令牌 | 使用位置 |
|---|---|---|---|
| 工作画布、主表面、浮起表面 | `--lv-color-canvas`、`--lv-color-surface`、`--lv-color-surface-raised` | `--lv-color-canvas`、`--lv-color-surface`；浮起面继承表面 | 页面底、工作面、对话框 |
| 主文字、辅助文字 | `--lv-color-text`、`--lv-color-text-muted` | `--b3-theme-on-background`、`--b3-theme-on-surface` 经 `--lv-color-*` 映射 | 正文、次要说明 |
| 边框、柔和中性面 | `--lv-border`、`--lv-color-surface-subtle` | `--lv-border`、`--lv-surface-hover`；中性面按组件表面派生 | 分割线、悬停和辅助底色 |
| 品牌色与品牌强调文字 | `--lv-color-brand`、`--lv-color-brand-strong` | `--lv-color-brand` 对应 `--b3-theme-primary`；强调文字需按上下文选择可读的宿主文本色 | 主按钮、链接、选中态 |
| 品牌柔和面与面上文字 | `--lv-primary-soft`、`--lv-color-on-brand-soft` | `--lv-primary-soft`；文字使用可读的前景语义色 | 当前导航、模板选择、选中行 |
| 警告、成功、错误面与面上文字 | `--lv-warn-soft` / `--lv-color-on-warning-soft`、`--lv-good-soft` / `--lv-color-on-success-soft`、`--lv-danger-soft` / `--lv-color-on-danger-soft` | `--lv-warn-soft`、`--lv-good-soft`、`--lv-danger-soft`；生产前景色来源于对应 `--b3-theme-warning/success/error` 与可读文本色 | 标签、提示、状态图标 |
| 阴影、动效 | `--lv-shadow-2` | `--lv-shadow-1/2`、`--lv-dur-*`、`--lv-ease` | 浮层与短交互反馈 |

原型的 `--lv-color-on-*-soft` 是静态配色板中的前景适配名，不意味着生产已经提供同名的一对一变量。生产主题需在真实宿主色值下核对前景和背景搭配。`--lv-color-brand-strong`、`--lv-color-surface-subtle` 与浮起表面也属于原型角色名；生产实现应优先复用现有 `--lv-*` 派生令牌，确有共享需求时再补对应语义变量。

## 2. 静态原型对比度抽查

以下结果由 R54 原型的静态 hex 配色按 WCAG 相对亮度公式计算，取 1:1 比值。正文/控件文字参考普通文字 4.5:1，非文本边界与焦点提示参考 3:1。检查覆盖代表性组合，并不等同完整页面、图表或生产宿主主题验收。

| 组合 | 亮色 | 暗色 |
|---|---:|---:|
| 正文 / 主表面 | 13.80:1 | 13.70:1 |
| 辅助文字 / 主表面 | 5.24:1 | 7.30:1 |
| 链接强调文字 / 主表面 | 6.87:1 | 9.09:1 |
| 主按钮文字 / 品牌底色 | 5.57:1 | 7.90:1 |
| 当前态文字 / 品牌柔和底色 | 6.69:1 | 8.13:1 |
| 警告、成功、错误文字 / 对应柔和底色 | 5.75 / 6.14 / 5.50:1 | 8.09 / 7.74 / 7.40:1 |
| 正文 / 工作画布 | 12.92:1 | 15.37:1 |
| 品牌焦点色 / 工作画布 | 5.22:1 | 8.86:1 |

抽查的原型组合达到上述文字或非文本参考值。尚未据此宣称生产主题对比度合格：思源主题、第三方主题、透明混色、禁用态、图表文字及图标边界仍需在实际运行时抽样；新增主题或颜色改动后应重新测量。颜色不应成为唯一状态信号，状态文字和图标需同时保留。

## 3. 字体、间距与组件规范

字号、行高、字重、4px 栅格、圆角、组件变体和验收数字统一以
[47-视觉令牌与组件变体规范](./47-视觉令牌与组件变体规范.md) 为唯一口径。这里不再复制一份独立的字号表，避免两个文档在同一语义上产生漂移。迁移后的实际引用覆盖率由 `test-evidence/token-audit-after.json` 记录；新增页面应直接复用该规范中的语义令牌。

## 4. 间距与几何

常规留白以 2px 基础单位表达，常见节距为 4、8、12、16、24px；1px 仅用于边线。容器内边距、卡面宽高、图表比例、触控目标、断点和日历格子是布局/内容几何，不能为了令牌覆盖率而改成不合适的相邻栅格值。R54 保留这些特例以避免原型视觉漂移。

圆角按用途选用：控件约 10px、紧凑标签约 5–8px、面板约 16–18px、主画布约 22px、胶囊/圆形使用专用形状。圆角不是一个可在所有组件间机械统一的变量；新增档位必须对应实际组件形态，而不是单处装饰偏好。

## 5. 通用组件变体

| 组件 | 必要变体与尺寸 | 使用理由与约束 |
|---|---|---|
| 按钮 | 语义：默认、主动作、幽灵、文字、柔和、危险；尺寸：紧凑 32px、标准 40px、主动作 48px；图标方形沿用对应尺寸 | 主次操作、轻量导航、状态动作和危险操作需要可辨识层级；文字按钮不应用于需要独立触控边界的核心动作。尺寸复用，不因颜色另开尺寸变体。 |
| 输入控件 | 标准文本/选择/文本域；原生复选框与范围控件；禁用、焦点、错误由状态表达 | 输入类型决定浏览器原生语义；校验和错误文案贴近具体字段。不为颜色或每个页面重复造输入风格。 |
| 状态标签 | 默认、品牌、警告、成功、错误 | 显示筛选、内测、同步或内容状态；必须带文字，不能单靠色块表达。 |
| 容器 | 普通面板、可交互卡片、结果/提示面板 | 纯展示面板不显示悬停或箭头暗示；卡片只有实际可点击时才有交互反馈与键盘焦点。 |
| 分段/页签 | 选中与未选中；不可用仅在真实前置条件不满足时出现 | 表达互斥模式或页面分面；使用原生 ARIA/键盘行为，避免另造颜色/大小变体。 |
| 图标按钮 | 标准触控方形，带可访问名称；危险语义由确认或邻近说明补足 | 用于搜索、关闭、更多等图标动作；tooltip 不能替代 `aria-label`。 |
| 提示 | 中性、警告、成功、错误；错误带恢复/重试入口（适用时） | 按事实严重度选择语义；加载、失败和空结果分开表示。 |

仅在交互目的或语义不同、且基础组件无法通过现有属性表达时新增变体。页面特有的 active/pressed/loading/disabled/error 状态属于状态，不自动算作新的视觉变体。

## 6. 变更验收

- 修改原型语义色时，同时验证亮暗两组代表性文字搭配；修改生产色时使用真实思源亮暗主题抽查，不以静态原型数值代替。
- 修改字体、间距、圆角或控件尺寸后，检查宽屏、窄屏、长文本和放大字号下是否溢出或改变主要操作位置。
- 新增通用变体时记录它解决的明确任务，并说明为何现有语义、尺寸和状态不能满足。
- 生产源代码中令牌覆盖率、残余字面值和同语义一致性以对应的样式审计结果为准；本文不预填未经统一口径复测的前后数值。
