# 小驴闪卡 · 闪卡产品市场调研报告（40+ 产品全景）

> 2026-10-01。配套文档：`00-调研轮次记录.md`（轮次与来源）、`02-功能全景清单.md`（功能矩阵）、`03-技术方案.md`、`04-路线图.md`、**`05-内核闪卡V2重构调研与应对.md`（必读：官方 feature/flashcard 分支已实现统计/管理/撤销/AnkiConnect/apkg 导入，本报告的"思源侧空位"结论以 05 的 V2 对照表为准）**

## 0. 结论速览

0. **2026-09-30 最大变量**：官方 `feature/flashcard` 分支完成闪卡 V2 重写（目标 3.9.0），统计/管理/撤销/动态复习集/AnkiConnect 兼容/apkg 导入全部进内核——原"0 竞品空位"大半被官方填掉，插件定位需按 05 文档重划：**AI 制卡、考试倒排、游戏化、题型增强（V2 卡型）、统计增值、AnkiConnect 生态桥**是主战场。

1. **调度算法层面已无差异化空间**：Anki 原生 FSRS、Obsidian SR 双算法、MarginNote 4 也上了 FSRS。思源内核更是已内置 go-fsrs v3，且 V2 的 ReviewState 直接暴露 Stability/Difficulty。**插件不做算法，做算法的驾驶舱**（高级可视化、优化、调度干预）。
2. **竞争格局更新（对比 7 月旧报告）**：Anki 互通不再是 0 竞品——`imiacc/siyuan-ankiLinker`（2026-06）已实现思源→Anki 单向同步；AI 方向出现新玩家 `AI Flashcards Native`（2026-09，AI 生成+知识图谱）；**最大的"竞品"是官方自己**：feature/flashcard 分支（3.9.0）把统计、管理、撤销、Anki 导入都做了。
3. **功能融合的五大金矿**（各赛道验证过、思源侧空白）：① 多题型互动（Quizlet/RemNote 系）② 图片遮挡（Anki/RemNote/MN）③ AI 制卡与对话复习（Knowt/滑记系）④ 考试 deadline 倒排（Deckline/filtered cram）⑤ 游戏化激励（墨墨/Quizlet/Memrise 系）。
4. **中文用户特有的高价值设计**：墨墨的"每日上限经济"（打卡赚上限）、遗忘曲线可视化、认识/模糊/不认识三档；滑记的滑卡交互与图片 AI 制卡；记乎/Markji 的牌组分享市场。
5. **大杂烩的正确姿势**：模块化 + 开关化。ZY/sy-tomato 的经验是单点功能极易被官方或全家桶覆盖，**完成度和组合体验**才是护城河。

## 1. Anki 生态（功能最全的参照系）

### Anki Desktop
- 卡组树 + **牌组选项预设组**（preset，多牌组共享一套参数）；**筛选牌组/自定义学习**（filtered deck：按搜索语法临时抽卡 cram，不动原进度，结束后卡片"回家"）
- **Note Type 卡片模板系统**：字段 + 正反面 HTML/CSS 模板 + 条件渲染，一张笔记生成多张卡；挖空 note type `{{c1::...}}` 多重挖空
- sibling burying（同源卡互斥）、leech 标记（遗忘 N 次自动打标签）、挂起/冻结、旗标
- 浏览器高级搜索语法（tag:、deck:、is:due、prop:ivl>=21、正则）、批量操作、重排
- 导入导出：apkg/colpkg/csv；AnkiWeb 同步；统计页（future due forecast、review count、answer buttons、interval、ease、true retention）

### AnkiDroid / AnkiMobile
- 白板手写答题（Droid 独有）、全自定义手势、桌面小部件（widget）、TTS 集成、统计页移动版

### 关键 add-ons
| 插件 | 解决什么 | 移植启示 |
|---|---|---|
| Image Occlusion Enhanced（442★） | 图片遮挡制卡：框选区域→每区域一张卡，支持"全部遮挡显示一个" | 思源无图片编辑器，可用 SVG overlay 实现简化版 |
| Review Heatmap | GitHub 风格复习热力图 + 连续天数统计 | 统计仪表盘标配 |
| Speed Focus Mode | 超时自动翻页/自动评分，防磨蹭 | 复习面板可选计时器 |
| ReMemorize | 一键把卡重新排入指定天数 | 已可由 batchSetRiffCardsDueTime 实现 |
| True Retention by Maturity | 按成熟度分层计算真实保持率 | 统计页核心指标（新/幼/成熟三层） |
| Advanced Browser | 列自定义、正则搜索、批量改 | 卡管理器列自定义 |
| Deckline | 每牌组设 deadline+预期总量→按日倒排进度条 | 考试模式核心逻辑 |
| Anki Timeline | 事件时间线 + 考试倒计时 | 考试模式 UI |

### FSRS 生态
- fsrs4anki：调度器替换 + ML 优化器拟合个人记忆参数；理论源头含**墨墨的 KDD'22/TKDE'23 论文**（随机最短路/记忆动态性）
- fsrs-optimizer：输入 revlog（含 timezone、day_start、rating、state、duration 字段）→ 输出 19/21 维权重；有 HuggingFace 在线版
- ts-fsrs：TS 实现（复习状态机可直接在前端复算）；官方新出 `binding` 包支持 **WASI 里跑优化器**——插件内闭环"导出→优化→写回"成为可能
- 思源内核现状：go-fsrs v3 已内置，`RequestRetention`/`MaximumInterval`/`Weights` 三个配置可写；**评分走服务端（Rating 1-4），插件不可替换算法**，但可用 ts-fsrs 做"影子计算"（统计、预测、模拟）

## 2. 笔记型软件（与思源范式最接近）

### Obsidian Spaced Repetition（2.6k★，FSRS 或 SM-2）
- 卡片语法：单行 `Q::A`、单行双向 `Q:::A`、多行 `Q ? A`、多行双向 `Q ?? A`、挖空 `==高亮==` / `**粗体**` / `{{花括号}}` / 自定义正则
- 牌组即标签（`#flashcards/子牌组`）或文件夹；卡片上下文自动取 `笔记标题 > 一级标题 > 二级标题`
- 笔记也可复习（整页作为复习单元）；统计页；15 种语言翻译

### Obsidian Incremental Writing（208★）
- 多队列（queue）、笔记/块入队、优先级（数字越小越重要）、编辑间隔/下次日期、手动排程、状态栏显示当前队列——SuperMemo 增量写作的轻量移植

### Logseq
- `#card` 标签制卡、cloze、SM-5 调度（未上 FSRS）
- 社区呼声 = 空位清单：随机出卡顺序、复习热力图、双面卡、列表卡、图片遮挡（Anki/RemNote 式）

### RemNote
- 笔记即 Rem，卡片可在任意 Rem 上生成；类型最全：Basic 双向、Completion 挖空、**Image Occlusion**、多选题、**表格生成卡**（一行一卡）、多行卡、自定义卡
- 模板系统、父子卡（grandchildren scheduling，子卡未掌握时父卡延期）、卡片方向设置、队列优先级

### Mochi
- Markdown 卡片、牌组分享市场、AI 生成（Pro）、媒体内嵌、界面现代清爽——"Anki 替代"口碑点在**简洁 + AI**

### SuperMemo（范式源头）
- 增量阅读：文章队列 → extract 摘录 → cloze 挖空成卡，读写 intertwined；优先级队列 %；本插件以"轻量增量阅读"致敬即可，不做全量

## 3. 大众学习平台（题型与游戏化的来源）

### Quizlet
- 7 种模式（2026 现状）：Flashcards 卡片翻转、**Learn**（Leitner 分箱自适应 + 书写题型可选）、**Write** 书写模式、**Spell** 听写拼写、**Test** 自动组卷（可配题型/题量）、**Match** 配对计时游戏；~~Gravity~~ 已下线
- 图像卡、多选题卡、语音朗读（18 种语言）、班级/分享、Q-Chat（AI 导师）；Plus 订阅：高级 Learn/Test、进度追踪

### Brainscape
- **Confidence-Based Repetition**：1-5 置信度评分替代"认识/忘记"；1 分卡快速连续重现、5 分卡推远；卖点=元认知训练；据评分映射间隔

### Memrise
- **mems 助记**（用户贡献的记忆图片/短语）、母语者原生视频例句、积分/连胜/排行榜/限时挑战（克制的游戏化）

### Kahoot / Quizizz（借鉴项）
- 课堂实时竞赛、倒计时答题、错题排行榜——借鉴其"限时答题 + 即时反馈"形式，不做多人在线

## 4. 中文市场（中文用户习惯的来源）

### 墨墨背单词
- 算法：1200 亿记忆行为数据（BMMS）+ 动态复习规划，定位每个词的**遗忘临界点**（R=90% 保留率）；KDD/TKDE 论文即其理论
- **认识 / 模糊 / 不认识** 三档快捷反馈；限时回忆
- **单词上限经济**：学新词耗额度、复习永远免费；打卡/分享赚上限（付费买上限）——把"坚持"变成货币
- 遗忘曲线可视化（个人记忆曲线 vs 理论 Ebbinghaus 曲线对比）、三大统计图表、自定义助记、批量移出

### 墨墨记忆卡（Markji）
- 墨墨出品的通用闪卡：统计学优化的间隔重复、**牌组市场**（创作者可收益）、牌组模板

### 滑记
- **滑卡交互**（滑动切换卡片，适配碎片时间）、**分享图片即可 AI 制卡**、UGC 牌组社区、学习小组件/快捷指令/控制中心集成、考研考证资源丰富
- 短板（知乎共识）：UGC 卡片质量参差——社区生态要配审核与创作者激励

### 记乎
- 现成卡包下载市场、桌面端编辑器制卡、多端同步、刷题模式

### MarginNote 3/4
- 文档/学习/复习三模式：摘录 → 一键成卡（同一段摘录同时进导图和卡组）；按标签/颜色/搜索**批量入组**；排序（添加时间/到期/文档位置/随机）；MN4 已上 **FSRS**
- 启示：**"摘录即卡片"** 与思源块引用天然同构

### Anki 中文社区高频痛点（知乎/少数派共识）
- 上手陡峭（牌组/模板/插件三座大山）、手机电脑同步折腾、制卡太慢、复习积压焦虑（"Anki 负债"）、中文 TTS 麻烦——每个痛点都是我们的功能入口

## 8. 各赛道"值得移植 Top 功能"汇总

- **Anki**：筛选牌组/cram、leech 识别、sibling burying、预设组、true retention、热力图、图片遮挡、超时模式、apkg
- **笔记型**：卡片语法五式、标签即牌组、卡片上下文标题链、笔记复习队列、增量队列、表格生成卡、父子卡调度
- **大众平台**：Learn 自适应、Test 组卷、Match 配对、Write/Spell 书写听写、CBR 1-5 评分、限时答题
- **中文**：三档反馈、每日上限+打卡经济、遗忘曲线对比图、滑卡交互、牌组市场（分享链接）、摘录成卡
- **AI**：多源生成（选块/文档/标签→AI）、预览编辑后入库、对话式复习、错题本
- **语言**：句子填空模式、TTS 朗读、跟读录音

## 9. 不移植清单（明确不做及原因）

- 云服务/账号体系（AnkiWeb、Quizlet 班级）——思源本地优先，同步走思源自身
- 多人实时对战（Kahoot 课堂）——单机插件形态不匹配
- 完整增量阅读（SuperMemo 全量）——渐进学习已占，且工程量失控
- UGC 牌组付费市场（记乎/Markji）——涉及交易合规，远期只做"分享链接导入导出"
- 原生移动 App/桌面小部件——思源移动端插件形态内做降级适配即可
