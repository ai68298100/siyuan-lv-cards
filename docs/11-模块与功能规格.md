# 小驴闪卡 · 模块与功能规格说明书

> 编号规则：`M{模块}·FR{序号}`。优先级：`[P0]` v0.9 集市首发前 / `[P1]` v1.0 / `[P2]` v1.x / `[P3]` v2.x。
> 每条 FR 标注数据通道（`GW` = 经 FlashcardGateway，见 14；`EV` = eventBus；`ST` = 插件私有存储）。
> **UI 实现约定**：所有 FR 的界面一律使用 UI Kit（`src/ui/kit/`，目录与装配配方见 `16-UI组件库规范.md`）拼装；Kit 缺件先补 Kit。
> V2 = 官方 3.9.0 闪卡 V2（ riff = 旧接口，兼容路径）。

---

## M1 网关与能力检测（foundation）

**目标**：上层模块不感知内核版本；V2 迁移全程可见。

- M1·FR1 `[P0]` `GW` 启动时探测 `getMigrationStatus`（404 → 无 V2）；结果缓存并提供手动重探按钮（数据子页）。
- M1·FR2 `[P0]` `GW` 提供统一接口：decks/reviewSets、dueQueue、review、undo、queryCards、statistics、mutate；Riff/V2 两实现，能力矩阵见 14。
- M1·FR3 `[P0]` 迁移状态 `Legacy/Preparing/Active/LegacyDiverged` 在顶栏菜单与数据子页可见；`LegacyDiverged` 显示黄色提醒（旧侧仍有写入，建议重跑迁移）。
- M1·FR4 `[P1]` V2 Active 时，统计/管理/撤销自动切 V2 通道；切换事件广播 `lv-cards:gateway-changed`。
- M1·FR5 `[P2]` 契约变更看门：响应缺关键字段时记 warn 日志并计数，数据子页显示"最近一次兼容性事件"。

## M2 制卡工作流

**目标**：把"想到→成卡"压到 3 秒内；AI 批量成卡必过人眼。

### 手动制卡

- M2·FR1 `[P0]` `GW` 块右键菜单「添加到卡组」：单块/多选块 → 选复习集（或新建）→ addCards。
- M2·FR2 `[P0]` `GW` 面包屑「复习本文档」按钮（3.8.2+），点击即以当前文档为范围开复习。
- M2·FR3 `[P1]` `GW` 快速问答制卡：菜单「快速制卡」弹出迷你输入（问/答两栏），生成隐藏文档块对并入集——不污染当前笔记。
- M2·FR4 `[P2]` 标记符制卡：行尾 `?`/`？`/`::` 触发问/答解析（吸收 flash-enhance，兼容 Obsidian `::` 语法），设置可关。
- M2·FR5 `[P2]` 斜杠命令注册验证：`/闪卡` 提供制卡/复习入口（若官方斜杠扩展不可用则降级为命令面板）。

### AI 制卡向导（旗舰）

- M2·FR6 `[P1]` `EV` 输入源四种：当前选区 / 当前文档（可限标题层级）/ 笔记本或标签范围 / 粘贴文本；拾遗剪藏后续经 M11 事件接入。
- M2·FR7 `[P1]` 生成配置：题量（5-50）、题型配比（问答/挖空/打字）、语言、难度；默认走思源 AI 配置，高级项可填 OpenAI 兼容端点。
- M2·FR8 `[P1]` **必过预览**：候选卡列表可编辑/删除/合并，支持"全部接受/仅接受勾选"；未确认绝不落库。
- M2·FR9 `[P1]` `GW` 落库：V2 用 `createAdvancedSource`（自定义模板）；riff 把问答写入「AI 制卡」日记文档再 `addRiffCards`；每批打 `lv-ai/<批次id>` 块标签。
- M2·FR10 `[P1]` 成本预检：发送前估算 token 量并提示；生成失败保留草稿可重试。
- M2·FR11 `[P2]` **质量反哺**：统计中心按 AI 批次聚合保持率，标注"哪批卡最耐记"，反向提示 prompt 策略。

## M3 复习面板（会话引擎）

**目标**：官方会话之上的全功能体验层；键鼠与触屏等价。

- M3·FR1 `[P0]` `GW` 范围选择：全部 / 复习集 / 当前文档 / 标签；显示各范围到期数（60s 缓存）。
- M3·FR2 `[P0]` `GW` 队列：到期卡按范围拉取，支持混合比（新卡优先/旧卡优先/交替）与随机顺序开关；一批耗尽自动取下一批。
- M3·FR3 `[P0]` 渲染：v0.9 用 `getBlockDOM`；**v1.0 切嵌入式只读 Protyle**（公式/嵌入块/mermaid 正确渲染），渲染失败降级静态 DOM。
- M3·FR4 `[P0]` 翻面与评分：问题态点击空白处/空格翻面（**输入控件区域不触发**）；评分按钮显示快捷键数字 + `nextDues` 间隔预览；四档/三档（认识/模糊/不认识）/1-5 置信度三种风格。
- M3·FR5 `[P0]` 会话内即时操作：跳过、编辑原块（跳转编辑器）、改期、**今天不学**（本地屏蔽到次日）、打开来源文档。
- M3·FR6 `[P1]` 上一张回看（`[` 键），只读快照不重评。
- M3·FR7 `[P1]` `GW` 撤销上一步：V2 `undoReview`；riff 走官方缓存恢复语义。
- M3·FR8 `[P1]` 超时模式三选：关 / 超时自动翻面 / 超时自动评"遗忘"，阈值秒数可调，计时环显示于角落。
- M3·FR9 `[P1]` `EV·ST` 每次评分写入 revlog 并广播 `lv-cards:reviewed`；会话结束出小结（新/复习/遗忘/跳过/用时）。
- M3·FR10 `[P2]` 手势（移动端）：右滑=良好、左滑=遗忘、上滑=翻面、长按=操作面板；悬浮球一键进入。
- M3·FR11 `[P2]` 白板层（移动端）：可开关的画布覆盖层，随卡切换清空。

## M4 题型系统（V2 卡型先发）

**目标**：题型可插拔；3.9 用户获得官方复习面板内的题型体验。

- M4·FR1 `[P1]` 卡型注册架构 `registerCardType`（契约见 14）：双实现——3.8 内部渲染 / 3.9 桥接官方 `registerFlashcardV2PluginType`。
- M4·FR2 `[P1]` **打字题**（首个注册卡型 `plugin:lv-cards:type`）：问题态输入框作答 → 提交后逐字符 diff 高亮；容错规则可配（忽略大小写/标点/全半角）；判分映射 Rating（完全匹配≥3，相似度阈值 2，否则 1）。
- M4·FR3 `[P2]` 选择题：同复习集采样干扰项生成四选一；判定后显示解析（源块链接）。
- M4·FR4 `[P2]` 配对挑战：从今日队列抽 6-8 张做计时配对小游戏，结果不计调度、只入激励。
- M4·FR5 `[P3]` 图片遮挡增强卡型：SVG 多边形区域，"遮挡全部/显示一个/逐个"三模式，超越官方内置的组合与键盘导航。
- M4·FR6 `[P3]` 听写卡型：TTS 播报→输入，语言/语速可配（Web Speech API 起步，引擎可扩展）。

## M5 统计中心

**目标**：官方数据的高级消费端；本地 revlog 补足官方未覆盖的纵向档案。

- M5·FR1 `[P0]` `ST` 总览六指标：今日到期/新卡/复习卡/今日已复习/连续天数/卡片总数。
- M5·FR2 `[P0]` `ST` 复习热力图（近 17 周，GitHub 风格）+ 连击；数据自本地 revlog，首日起累积。
- M5·FR3 `[P1]` `GW` V2 激活后渲染官方 `getStatistics`：overview 卡片化、history 折线、due 未来负荷柱状、interval/S/D/R 四分布直方图；图表全 SVG 自绘（零重依赖）。
- M5·FR4 `[P1]` `ST` 遗忘曲线对比：个人实测保持率 vs 理论 R(t) 曲线（数据源：revlog 或 V2 retrievability 分布）。
- M5·FR5 `[P1]` `GW` 复习集对比表：各集到期/新卡/保持率/leech 数（riff 路径按卡组聚合估算）。
- M5·FR6 `[P2]` 报告导出：周报/月报一键生成 Markdown（含图表快照数据），可写入日记（对接复盘插件）。
- M5·FR7 `[P2]` True Retention：新/幼/成熟三层真实保持率。

## M6 管理器

- M6·FR1 `[P0]` `GW` 浏览：跨复习集分页列表，列（内容摘要/来源路径/到期/状态）可配；点击打开来源文档。
- M6·FR2 `[P1]` `GW` 搜索：V2 用 AST 字段（tag/state/leech/ivl/editLater…）；riff 用本地过滤（内容关键词+状态）。
- M6·FR3 `[P1]` `GW` 批量操作：改期/重置/移除/挂起（V2 suspended；riff 本地屏蔽），全部需确认并显示影响数。
- M6·FR4 `[P1]` `GW` 卡片详情抽屉：复习历史（V2 getCardHistory / riff revlog 本地）、S/D 值（V2）、所属集与来源。
- M6·FR5 `[P2]` leech 工作台：按阈值筛出 → 一键加入"重写清单"→ 跳 AI 向导改写（与 M2·FR11 闭环）。
- M6·FR6 `[P3]` 重复检测：同集内问答相似度提示。

## M7 考试模式（旗舰，riff 路径即可用）

**目标**：从"有考试"到"考完复盘"的全流程，考前不积压。

- M7·FR1 `[P1]` `ST` 考试计划：名称、考试日、范围（集/标签/文档）、总卡量（自动统计或手填）、每日学习容量、考前 cram 天数 N、多计划并存。
- M7·FR2 `[P1]` `GW·ST` 倒排曲线：剩余未学 ÷ 剩余天数 = 每日应学；每日进度条（应学/实际）；滞后自动预警（红/黄/绿三态）。
- M7·FR3 `[P1]` `GW` 今日应学队列：按计划范围过滤到期+未学卡，倒序优先级（先高频后长尾由旧卡优先策略保证）。
- M7·FR4 `[P1]` `GW` 考前 cram：进入"考试模式"横幅态，队列重排为按薄弱优先（riff：lapses 降序；V2：retrievability 升序），并可一键"考前再过一遍"（不动原调度，仅过滤）。
- M7·FR5 `[P1]` 倒计时：考试日 countdown 常驻（闪卡中心头部 + 移动端悬浮球角标），里程碑（30/7/1 天）提醒。
- M7·FR6 `[P2]` 考后复盘：计划归档 + 生成复盘报告（覆盖进度/保持率/放弃率），可对接小驴复盘。
- M7·FR7 `[P2]` `GW` V2 StudyPolicy 同步：计划参数写入官方 study policy（当官方支持后），实现"计划即策略"。

## M8 激励系统

- M8·FR1 `[P1]` `ST·EV` 每日目标（新卡/复习量）+ 完成庆祝（轻量 toast + 角标变绿）；进度在闪卡中心头部常驻。
- M8·FR2 `[P1]` `EV` 打卡联动：优先读写打卡插件的当日记录（事件/存储协议探测），无打卡插件时本地维护。
- M8·FR3 `[P2]` `ST` XP/等级（默认关）：评分得分=XP，等级徽章在总览页；纯本地荣誉。
- M8·FR4 `[P2]` 限时挑战（默认关）：3 分钟快答计数 / 配对赛计时，复用 M4·FR4。
- M8·FR5 `[P3]` 上限经济（默认关）：可选"新卡额度"荣誉制，连续打卡获奖励额度（致敬墨墨，不涉真实付费）。

## M9 Anki 桥

- M9·FR1 `[P1]` `GW` AnkiConnect 客户端面板：目标地址、鉴权 key、连接测试、可用 action 探测（apiReflect）。
- M9·FR2 `[P2]` `GW` 状态可视化：思源作为 AnkiConnect 服务端时的开关状态（内核 conf）、第三方写入账本（AnkiConnectNotebook）最近动态。
- M9·FR3 `[P2]` 导出跟随：官方 ankiLinker 已覆盖思源→Anki，本插件不重复；提供跳转与文档链接。若官方 V2 导出端点出现则接入 Gateway。

## M10 数据与健康

- M10·FR1 `[P1]` `ST` revlog 管理：导出 JSON/CSV、导入合并（按 ts+cardID 去重）、清空（双重确认）。
- M10·FR2 `[P1]` `GW` V2 迁移助手：状态查询、重探、`LegacyDiverged` 诊断指引（链接官方迁移 API 说明）。
- M10·FR3 `[P2]` 多设备诊断：revlog 分叉检测（同日两端均有记录且冲突）与一键合并预览。
- M10·FR4 `[P2]` 存储体检：私有数据体积、版本、最近写入时间一览。

## M11 生态联动（小驴全家桶）

- M11·FR1 `[P1]` `EV` 事件广播契约：`lv-cards:reviewed`（单次评分）、`lv-cards:session-finished`（会话小结）、`lv-cards:streak-changed`、`lv-cards:cards-created`（制卡批次）——命名空间与载荷见 14。
- M11·FR2 `[P1]` `EV` 打卡互操作：向打卡插件广播"今日闪卡已完成"；读取其连击数据展示（存在才显示，永不报错）。
- M11·FR3 `[P2]` 复盘联动：周报数据集（M5·FR6）注册为复盘插件可消费的数据源事件。
- M11·FR4 `[P2]` 拾遗联动：剪藏/划段内容进入"待制卡箱"，AI 向导可直接选箱批量成卡。

## M12 设置与画像

- M12·FR1 `[P0]` 画像预设包：备考/笔记/语言/自定义，应用时仅覆盖模块开关与推荐参数（弹预览 diff，可撤销）。
- M12·FR2 `[P0]` 模块开关：12 模块总开关，禁用即不注册入口/不跑后台。
- M12·FR3 `[P0]` 学习偏好：评分风格、每日目标、超时模式、随机顺序、混合比。
- M12·FR4 `[P1]` FSRS 参数面板：RequestRetention/MaximumInterval/Weights 可视化编辑（写内核 conf），预设组（冲刺/日常/休养）一键切换。
- M12·FR5 `[P1]` 外观：复习卡片最大宽度、答题按钮密度、角标开关。
- M12·FR6 `[P2]` 画像导入导出（JSON 分享）。
