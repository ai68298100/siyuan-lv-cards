## 3. 评分口径总表（正式评分的唯一通道）

| 通道 | 方向 | 事实 |
|---|---|---|
| 插件复习面板 `rate()` | 插件→内核 | `reviewRiffCard`（`riff.ts:109`）成功后才写 revlog 旁账与 revlog.dur（`review.svelte:589-596`）；skip 走 `skipReviewRiffCard`（`riff.ts:112`），revlog 记 rating=0 |
| 原生复习界面 | 内核→插件旁听 | `click-flashcard-action` → `normalizeNativeCardAction`（`index.ts:1424`，AQ-5：rating 严格 1-4、eventId/时间窗幂等、真实事件时间缺失标估算）；**只记账，不回写内核** |
| 撤销 | 仅本地 UI | `undoHistory` 恢复面板状态与计数；**内核评分不可撤销**（无 undo 通道，V2 undoReview 宿主依赖，见 §5） |
| 挑战/配对/重现 | 不产生 | 见 §2；文档级练习（docs 面板的筛选练习）同属此类 |
| 快速改期 `f` | 插件→内核 | `batchSetRiffCardsDueTime`（`riff.ts:134`）——改期是内核调度写入，属用户显式操作，不经评分通道 |

**推论**：任何「练习/挑战/AI 建议」都不允许直接调用 `reviewRiffCard`；AI 建议评分与用户正式评分分离（[29-AI战略](./29-AI战略与内置提示词体系.md)）在现版的落点即打字/选择题的建议 chip。

## 4. N/A 与缺失字段口径

| 缺失 | 表现 | 依据 |
|---|---|---|
| 原生评分无 duration | revlog.dur 缺失，耗时统计不补 0 | `review.svelte:591-592`（仅插件面板记录）、`revlog.ts` studySecondsOn |
| 原生评分常缺 deckID | deckCoverage unattributedCards 单独列示 | `revlog.ts` deckCoverage |
| 块删除/移动后归属缺失 | docCoverage unattributed 单独列示 | `revlog.ts` docCoverage；`siyuan.ts` getBlockDocMap 查不到即缺失 |
| 内核复习状态（state/interval/due）未开放 | CSV `review_state` 恒为空；mastery/分层视图 V2 后补 | AQ-9/AQ-12 验收注记（docs/17） |
| 明细 >2 万条截断 | 截断前日期聚合快照保留；首评语义由 knownCards（≤2 万）保留 | `revlog.ts` normalizeRevlog/recalcDays/appendRevlog（AQ-21） |
| V2 端点缺失/状态不可识别 | null（未升级，走 riff 兜底）/ Unknown（保守降级显示未验证） | `flashcardV2.ts:26`（detectFlashcardV2 + normalizeMigrationStatus，AQ-6） |
| AI 未配置/被拒 | 无请求发出；fallback 仅网络/超时/5xx/429 | `ai.ts`（AQ-14/15）；取消不触发 fallback |

## 6. 本轮查重结论

扫描中发现的断点均已有条目承载，**本轮不新增 checkbox**：

- 选择题干扰项占位文本补位 → E-10（W2→W4）已有验收；
- 遮挡 overlay 定位与初始依赖 → v0.64 已修（`review.svelte:1256` 绝对定位），剩余边界归既有遮挡验收；
- SR 导入的 deck tag 仅作提示不自动建组 → 与选卡组弹窗交互一致，归 AQ-11 验收；
- 超时「自动评遗忘」属正式评分的边界 → AT-10/AQ-13 注记已含，无独立条目。

后续能力复核（合并/降级/新增）以本文为基线，随版本演进在 R 轮次中更新。
