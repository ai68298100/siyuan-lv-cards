# 小驴闪卡 · 视觉设计系统「星轨 Starline」

> R50 · 视觉规格 v1.0（2026-10-02）。配套：[13-UI原型图](./13-UI原型图.md)、[12-交互设计规范](./12-交互设计规范.md)、[32-产品体验优化与页面蓝图](./32-产品体验优化与页面蓝图.md) v1.0；排期以 [30-待办治理与执行顺序](./30-待办治理与执行顺序.md) v1.2 为准。
>
> 本文定义目标视觉规则，本轮只更新规划；现有令牌/样式和所需调整不等于已通过主题、读屏或真机验收。实现载体为 `src/index.scss` 与 Kit/业务屏幕，不能据文件存在宣称全部规格已实现。
>
> **颜色从 b3 语义变量派生**（`color-mix` 调透明度/混色）；派生有利于融入宿主，但亮暗和第三方主题仍需验对比度。black/white 透明值仅用于阴影、遮罩或装饰高光，不是主题可读性证明。

## 1. 理念：品牌服务阅读与学习

用户应先看清材料、问题、答案、来源和下一步。视觉品牌通过秩序、留白和稳定层级表达；装饰不能增加猜测或改变学习信息。今日任务、材料审核与结果页按 32 的任务蓝图展开，每阶段一个清楚主动作；正式评分档位保持同级。

参考谱系：

- **Linear / Vercel(Geist)**：中性表面 + 微妙边框 + 克制的强调色；数字一律 `tabular-nums`
- **Things 3 / Apple HIG**：大留白、单焦点、柔和阴影层次、缓出动效
- **shadcn/ui**：语义令牌（surface/border/soft）而非写死色值——与 b3 变量派生策略天然同构
- **墨墨 / Quizlet**：学习场景的柔和色块与进度反馈（改用低饱和"色调面"而非大色块）

三条铁律：

1. **层次先由结构与可读性表达**：可用 surface、1px 边框和有限阴影区分层级；微渐变/blur 为可关闭增强。低性能、低带宽、小屏或异常主题允许纯色、无 blur 和简化动效，不能损失状态与动作。
2. **强调色占比 ≤ 10%**：主色只出现在关键数字、进度、焦点环、主按钮；大面积一律中性面。
3. **动效只服务状态变化**：120/180/240ms 为优先时长，`cubic-bezier(.2,.8,.2,1)` 缓出；默认无持续呼吸或装饰循环。静态文本已足以表达状态；尊重 reduced-motion、用户关闭及设备降级。

## 3. 组件解剖

### 3.1 统计卡（StatCard）

```
┌──────────────────┐ ← surface-grad + r-l + shadow-1
│ ● 今日到期        │ ← 12px 语义色点 + 元信息标签
│       12          │ ← 展示数字：32/700 tabular-nums，hero-grad 文字
│  ▁▂▃迷你趋势(预留) │
└──────────────────┘
静态数据卡不显示可点击箭头或链接式 hover；只有真正有对应钻取动作时才提供 hover、焦点、键盘和触摸等价入口。
```

### 3.2 复习卡面（ReviewCard）

- 桌面常规参考：居中最大宽 720px、内边距 32px、r-l、适度阴影；实际宽度/字号按内容、用户设置与窄屏验收调整，不能硬套所有材料。
- 问题/答案切换：`fly:y:8 + fade` 180ms；答案追加段用 primary-soft 左边条引导
- 待翻面态：显示明确的揭晓按钮和翻面热区；可选 hover 不能暗示整卡任意文字/控件均可翻面，滚动和选区边界按 12 验收。

### 3.3 评分条（RatingBar）

- 每键 = 语义色 soft 底 + 可读文字 + `kbd` 数字徽章 + 间隔预览小字；文字优先 on-background，使用语义色文字时须有对比度证据。
- hover 可加深底色；active 为短反馈。四档是同级选择，不能用尺寸、默认焦点或强烈动效偏置某个正式评分。
- 四档语义：error/warning/primary/primary（第四档加 ⚡ 符号区隔）

### 3.4 热力图（Heatmap）

- 格 12px 圆角 3px；hover 外扩 1px + primary-border 描边；`color-mix(primary α)` 五档 α = 0/.2/.4/.65/1
- 图例右对齐；空态显示引导文案而非空白网格

### 3.5 列表行（管理器）

- 行卡片化：hover 时 surface→surface-grad + 左缘 3px primary 竖条；选中行 primary-soft 底
- 元信息颜色验实际对比度；关键操作不能仅 hover 才出现，键盘聚焦、触控和读屏均有等价入口。

### 3.6 页头（PageHeader）

- 左：页题 + 副题（元信息）；右：动作组（主按钮实底 + 次按钮描边）
- V2/考试等状态带：静态文字与状态章；未知、过期、不可用有可读含义。glass 可降级纯色；呼吸点默认静态，真实进行中的任务可用局部进度，但不得把待机画成持续忙碌。

## 4. 动效规范

| 场景 | 规格 |
|---|---|
| 可操作卡悬浮 | 可选边框/阴影变化，180ms；静态数据不做导航暗示 |
| 评分按下 | scale(.98)，120ms |
| 翻面 | 答案 fly(y:8)+fade 180ms；不做 3D 翻转（阅读连续性优先） |
| 浮层出现 | fade + scale(.98→1) 160ms |
| 数字变化 | 默认直接显示真实值；可选短过渡，不因切页重播或影响数值读取 |
| 状态点 | 默认静态；正在执行的真实任务优先文本/进度 |
| 骨架屏 | 首次无数据显示占位；已有数据刷新保留旧结果和过期说明，可用静态占位 |

全部包 `@media (prefers-reduced-motion: reduce) { transition/animation: none }`。

## 5. 可达性

- 语义色不加单腿：评分档位同时有文字+数字徽章；滞后同时有颜色+⚠
- `:focus-visible` 统一 `--lv-focus-ring`；主要触控目标 ≥ 44px，辅助密集控件按 AS-2 验尺寸、间距与等价路径
- 对比度：soft 面上的正文优先 on-background；仍须测正文、元信息、焦点、禁用说明、图表、错误和语义色，不能仅凭 token 派生宣称合格。
- 未知/错误/候选/已审/已入库必须同时有文本，颜色与图标不能替代状态。候选勾选与审核确认采用不同视觉语义。
- 窄屏、系统字号放大和高 DPI 保持阅读顺序；次级面可以切换，当前对象、状态和主动作不丢。

## 6. 装饰取舍与历史效果复核（R50）

以下是历史效果目录，不能作为默认必须实现的 checklist。每项仅在不影响阅读、性能和事实含义时保留；低性能/小屏模式可全部简化。

**质感（静态品质）**

- 卡片顶部**发丝高光**：`inset 0 1px 0 white 5%` —— 玻璃面板的受光缘
- 主按钮光泽：默认不启用扫过动画，必要强调优先文字与稳定表面
- 所有数字 `tabular-nums`；关键数字渐变文字（primary → primary/warning）
- 细滚动条（thin / 8px 圆角 thumb），容器内不污染全局
- 统计卡内**迷你目标进度条**（渐变填充 + 240ms 宽度过渡）

**灵动（动态生命感）**

- 统计数字：优先静态真实值；数字动画不能替代加载状态或在切页反复重播
- 评分条：各档同时可用，不以错峰入场延后某档可操作性
- 翻面：可选短淡入；辉光脉冲默认关闭，题面阅读顺序保持稳定
- 完成态：先显示结果、剩余和下一步；庆祝可选、可关闭，不以 pop/错峰遮挡收工
- 热力图今日环可静态；列表/表格只在真正能钻取时显示箭头，并提供非 hover 的操作路径
- 管理器搜索范围以 BW-1 的全库/指定集合语义为准，不能把当前页过滤包装为全库检索或“零延迟”承诺

纪律：可选动效只在 `prefers-reduced-motion: no-preference`、用户允许且设备合适时启用；无默认循环装饰动画，V2 状态点也不例外；单一元素同时最多一个动效。

## 7. 合规自检表（每次改 UI 过一遍）

- [ ] 无硬编码主题色（黑/白透明梯度仅限阴影/遮罩）
- [ ] 亮暗主题切换无需条件分支（全部派生）
- [ ] 强调色面积 ≤ 10%
- [ ] 动效三档时长 + reduced-motion 覆盖
- [ ] 8pt 网格对齐
- [ ] 亮暗、第三方主题、缩放、窄屏的文字与非文字对比度有实际证据
- [ ] 静态数据无假箭头，关键动作不依赖 hover；评分各档同级
- [ ] 纯色/无 blur/无装饰模式保留来源、状态、当前对象和主动作
- [ ] 默认无持续呼吸/辉光/光泽动画，用户关闭与系统 reduced-motion 同时生效
- [ ] BX-4 本地设置预览使用脱敏样例，取消不影响真实学习内容
