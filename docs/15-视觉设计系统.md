# 小驴闪卡 · 视觉设计系统「星轨 Starline」

> 配套：13-UI原型图（布局）、12-交互规范（行为）。本文定义**视觉层**：令牌、组件解剖、动效。
> 实现载体：`src/index.scss`（令牌与共享类）+ 四个 Svelte 组件。
> 硬约束：**所有颜色从 b3 变量派生**（`color-mix` 调透明度/混色），亮暗主题零适配成本；阴影用 black 透明梯度（中性、双主题通用）。

## 1. 理念：科技感来自秩序，舒适感来自留白

参考谱系：
- **Linear / Vercel(Geist)**：中性表面 + 微妙边框 + 克制的强调色；数字一律 `tabular-nums`
- **Things 3 / Apple HIG**：大留白、单焦点、柔和阴影层次、缓出动效
- **shadcn/ui**：语义令牌（surface/border/soft）而非写死色值——与 b3 变量派生策略天然同构
- **墨墨 / Quizlet**：学习场景的柔和色块与进度反馈（改用低饱和"色调面"而非大色块）

三条铁律：
1. **层次靠"面"不靠"线"**：surface 微渐变 + 1px 派生边框 + 双层软阴影，三层深度（`--lv-shadow-1/2/3`）。
2. **强调色占比 ≤ 10%**：主色只出现在关键数字、进度、焦点环、主按钮；大面积一律中性面。
3. **动效只在"状态变化"时发生**：120/180/240ms 三档，`cubic-bezier(.2,.8,.2,1)` 缓出；装饰性动画一律不做（尊重 reduced-motion）。

## 2. 令牌表（`src/index.scss` 实装）

| 令牌 | 值（派生自 b3） | 用途 |
|---|---|---|
| `--lv-r-s/m/l` | 8 / 12 / 16px | 圆角：控件 / 卡片 / 容器 |
| `--lv-sp-1..5` | 4 / 8 / 12 / 16 / 24px | 8pt 间距网格 |
| `--lv-ease` | `cubic-bezier(.2,.8,.2,1)` | 全部过渡 |
| `--lv-dur-1/2/3` | 120 / 180 / 240ms | 微交互 / 展开 / 转场 |
| `--lv-primary-soft` | `color-mix(primary 10%, transparent)` | 强调面：选中态、进度底 |
| `--lv-primary-border` | `color-mix(primary 32%, transparent)` | 焦点环、激活边框 |
| `--lv-danger/warn-soft` | error 10% / warning 12% 透明面 | 遗忘键、滞后预警 |
| `--lv-border` | `color-mix(on-background 8%, transparent)` | 派生 1px 边框（比 b3-border 更轻） |
| `--lv-surface-grad` | `linear-gradient(180deg, primary 6% → surface)` | 卡片表面微渐变 |
| `--lv-hero-grad` | `135deg, primary → primary/warning 混色` | 关键数字渐变文字 |
| `--lv-glass` | `background 78% + backdrop-blur(14px)` | 浮层（回看/页头）毛玻璃 |
| `--lv-shadow-1/2` | black 4-10% 双层 | 静置 / 悬浮两档海拔 |
| `--lv-focus-ring` | `0 0 0 3px primary 32%` | `:focus-visible` 统一焦点 |

字阶：页题 20/700（-0.02em）· 区块题 14/600 · 正文 14 · 元信息 12 · **展示数字 28-32/700 + `tabular-nums` + 主色渐变文字**。

## 3. 组件解剖

### 3.1 统计卡（StatCard）
```
┌──────────────────┐ ← surface-grad + r-l + shadow-1
│ ● 今日到期        │ ← 12px 语义色点 + 元信息标签
│       12          │ ← 展示数字：32/700 tabular-nums，hero-grad 文字
│  ▁▂▃迷你趋势(预留) │
└──────────────────┘
hover: translateY(-2px) + shadow-2，180ms
```

### 3.2 复习卡面（ReviewCard）
- 居中最大宽 720px、内边距 32px、r-l、shadow-2——**单焦点舞台**
- 问题/答案切换：`fly:y:8 + fade` 180ms；答案追加段用 primary-soft 左边条引导
- 待翻面态：卡面中央 ghost 按钮（虚线边框、悬浮点亮），整卡 hover 微升

### 3.3 评分条（RatingBar）
- 每键 = 语义色 soft 底 + 同色文字 + `kbd` 数字徽章 + 间隔预览小字
- hover：底色加深一档（20%）+ 上移 1px；active：scale(.98)
- 四档语义：error/warning/primary/primary（第四档加 ⚡ 符号区隔）

### 3.4 热力图（Heatmap）
- 格 12px 圆角 3px；hover 外扩 1px + primary-border 描边；`color-mix(primary α)` 五档 α = 0/.2/.4/.65/1
- 图例右对齐；空态显示引导文案而非空白网格

### 3.5 列表行（管理器）
- 行卡片化：hover 时 surface→surface-grad + 左缘 3px primary 竖条；选中行 primary-soft 底
- 元信息行用 on-surface 60%；操作按钮 hover 才浮现

### 3.6 页头（PageHeader）
- 左：页题 + 副题（元信息）；右：动作组（主按钮实底 + 次按钮描边）
- V2/考试等状态带：glass 底 + 呼吸点（2s 循环，reduced-motion 时静态）

## 4. 动效规范

| 场景 | 规格 |
|---|---|
| 卡片悬浮 | translateY(-2px) + shadow-1→2，180ms ease |
| 评分按下 | scale(.98)，120ms |
| 翻面 | 答案 fly(y:8)+fade 180ms；不做 3D 翻转（阅读连续性优先） |
| 浮层出现 | fade + scale(.98→1) 160ms |
| 数字变化 | count-up 240ms（v1.0 实现，先静态） |
| 呼吸点 | opacity 1→.4→1，2s 循环 |
| 骨架屏 | shimmer 1.2s（v1.0） |

全部包 `@media (prefers-reduced-motion: reduce) { transition/animation: none }`。

## 5. 可达性

- 语义色不加单腿：评分档位同时有文字+数字徽章；滞后同时有颜色+⚠
- `:focus-visible` 统一 `--lv-focus-ring`；触控目标 ≥ 40px
- 对比度：soft 面（10% 主色）上的正文一律用 on-background 原色，不用主色文字

## 6. 细节质感清单 v2（2026-10-01 第二轮打磨）

**质感（静态品质）**
- 卡片顶部**发丝高光**：`inset 0 1px 0 white 5%` —— 玻璃面板的受光缘
- 主按钮**光泽扫过**：hover 时 32% white 斜向高光 480ms 划过（`::after` skew）
- 所有数字 `tabular-nums`；关键数字渐变文字（primary → primary/warning）
- 细滚动条（thin / 8px 圆角 thumb），容器内不污染全局
- 统计卡内**迷你目标进度条**（渐变填充 + 240ms 宽度过渡）

**灵动（动态生命感）**
- 统计数字 **count-up**（420ms cubic 出场，reduced-motion 直落）
- 评分条**错峰入场**：四键依次 0/40/80/120ms rise
- 翻面瞬间卡面**辉光脉冲**（primary 24% 外扩一圈 240ms）+ 边框点亮
- 完成态：渐变**圆徽章 pop**（scale .6→1.08→1）+ 标题/统计/按钮三段 60ms 错峰 rise
- 热力图**今日环**（2px primary 32% 外描边常亮）；列表/表格行 hover 箭头滑入（opacity+translateX）
- 管理器**实时筛选**当前页（输入即过滤，派生态零延迟）

纪律：所有新动画包在 `prefers-reduced-motion: no-preference` 内；无循环装饰动画（仅 V2 呼吸点）；单一元素同时最多一个动画。

## 7. 合规自检表（每次改 UI 过一遍）

- [ ] 无硬编码主题色（黑/白透明梯度仅限阴影/遮罩）
- [ ] 亮暗主题切换无需条件分支（全部派生）
- [ ] 强调色面积 ≤ 10%
- [ ] 动效三档时长 + reduced-motion 覆盖
- [ ] 8pt 网格对齐
