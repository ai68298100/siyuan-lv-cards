# 42 · UI 设计规范 R53「星轨 Starline v2」

> 成文于 2026-10-07。输入：docs/41（竞品调研与定位）、docs/15（Starline v1）、docs/12（交互设计规范）。
> 原型实现：`docs/prototypes/starline-r53.html`（14 面，亮/暗/390px，含 loading/empty/error/partial 样例状态）。
> 本文是 R53 起所有 UI 工作的唯一视觉与布局事实源；与 docs/15 冲突处以本文为准，docs/15 保留作 v1 历史。

## 1. 设计原则（按优先级，冲突时序号小者胜）

1. **一屏一问**：每屏只回答一个主问题（总览="现在学什么"、复习="这张还记得吗"）；其余信息渐进展开，不允许首屏统计轰炸。
2. **主色即动作**：品牌色只出现在「当前唯一主动作」与「进行中状态」上；其余全部中性。整屏主色覆盖率 ≤5%。
3. **来源可见**：凡是 AI 生成或自动推导的内容，界面必须就近给出依据（来源块、参数、预算、置信），没有依据的不展示。
4. **状态即设计**：loading / empty / error / partial / unknown 与正常态同精度设计；「未知不显示为 0」。
5. **键盘优先，指针不排他**：所有操作有键盘等价且 kbd 可见；hover 只做增强不做唯一入口。
6. **克制动效**：120/180/240ms 三档、统一 `cubic-bezier(.2,.8,.2,1)`、只动 transform/opacity；无呼吸、无光泽扫过、无错峰入场。
7. **主题自适应**：全部颜色由 `--b3-*` 派生（color-mix），不硬编码色值；亮暗主题是同一套令牌的两个取值域。

## 2. 令牌表（`src/index.scss` 实装口径）

### 2.1 色彩

| 令牌 | 值（派生） | 用途 |
|---|---|---|
| `--b3-theme-background` | 宿主 | 页面底色（最深层） |
| `--b3-theme-surface` | 宿主 | 卡片/面板工作面（第二层） |
| `--lv-border` | on-bg 8% | 1px 描边（唯一卡片分层手段） |
| `--lv-border-strong` | on-bg 14% | hover 描边 / 输入框描边 |
| `--lv-primary-soft` | primary 10% | 选中态、进行中 tag、进度条轨道底 |
| `--lv-primary-softer` | primary 5% | hero 洗色、激活 tab 底 |
| `--lv-warn-soft` / `--lv-good-soft` / `--lv-danger-soft` | 语义 12% | 通知与语义章底 |
| `--lv-shadow-1/2` | 黑 5-9% 两层 | 悬浮抬升（仅 hover/浮层），禁静态阴影 |
| `--lv-focus-ring` | primary 32% 3px 环 | :focus-visible 唯一焦点指示 |

**禁**：纯黑阴影、实色边框、彩色渐变文字、渐变卡底、品牌色大面积填充。

### 2.2 字号阶梯（中文优先）

| 级 | 字号/行高/字重/字距 | 用途 |
|---|---|---|
| eyebrow | 11px / 1.2 / 650 / +0.16em 大写 | 小节标签、页眉眉线 |
| caption | 12px / 1.6 / 400 | 辅助说明、间隔提示 |
| body | 13px / 1.65 / 400 | 正文、列表主文本 |
| body-strong | 13px / 1.5 / 600 | 行标题、强按钮 |
| panel-title | 15px / 1.5 / 650 | 面板标题 |
| page-title | 22px / 1.35 / 650 / -0.02em | 页头标题 |
| stat-num | 30px / 1.2 / 650 / -0.03em / tabular-nums | 展示数字 |
| study-face | 21px / 1.7 / 400 | 复习卡面正文 |

中文栈：`system-ui, -apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`。数字一律 `font-variant-numeric: tabular-nums`。

### 2.3 间距 / 圆角 / 动效

- 间距 4 栅格：4 / 8 / 12 / 16 / 24 / 32；面板内边距 20-24（嵌套时外 24 内 16，外大内小）。
- 圆角梯度：4（kbd/chip）/ 8（输入/小钮）/ 12（stat/评分卡）/ 16（面板）/ 20（应用外壳浮层）；嵌套外大内小。
- 动效：`--lv-dur-1/2/3` = 120/180/240ms；`--lv-ease` = `cubic-bezier(.2,.8,.2,1)`；`prefers-reduced-motion` 全部归零。
- 触控目标 ≥40px（窄屏 ≥44px）；行高与点击区分离时用透明 padding 扩展。

## 3. 组件解剖与状态矩阵

> 每个组件列：结构（anatomy）→ 状态 → 用法禁例。实装类名以 `lv-` 前缀。

### 3.1 按钮 Button
- 结构：`[icon?] [label] [kbd?]`；高度 40（默认）/ 36（small）/ 48（hero/主动作）。
- 变体：**primary**（实底主色，每屏最多 1 个可见）/ **outline**（白面 1px 描边，次级动作）/ **ghost**（无底无框 muted，行内工具）/ **text**（主色文字，链接性行为）/ **danger**（ghost 形态 + error 色，破坏性操作需二次确认）。
- 状态：normal / hover（outline/ghost 抬底 5%；primary 上浮 1px + brightness 1.06）/ active（scale .98）/ disabled（opacity .65，不降透明度到不可读）/ loading（label→…，禁点）/ focus（focus-ring）。
- 禁例：裸 `.b3-button`（思源基类是实心主色）——插件作用域内已全局中性化（v0.206.1），新代码中性钮必须显式选 outline/ghost。

### 3.2 页签 Tabs（中心导航）
- 结构：文字 tab + 2px 主色底线（active），左右 16px 内缩；底部 1px 分隔线贯通。
- 状态：active / hover（提字色）/ focus-ring；≤740px 横向滚动。
- 数量上限 7；超出的入口收进命令面板，不再加页签。

### 3.3 卡片 Panel
- 变体：**panel**（surface + 1px border + r16 + 内边距 20-24）/ **panel-soft**（on-bg 4% 底，用于次级信息/NEXT 建议）/ **hero**（primary 5% 洗色 + 1px border，每屏最多 1 个）。
- hover 抬升仅用于可点击卡片（translateY(-2px) + shadow-2）；静态卡片禁止阴影。
- 面板标题：panel-title 级；右上角允许一个 ghost「查看全部 →」。

### 3.4 统计瓦片 StatTile
- 结构：`label(12px muted) / num(30px tabular) / delta? / sparkline?`；delta 用语义色 ▲▼ + 12px；sparkline 为 7 点 inline SVG 面积图（8% 主色填充 + 30% ink 描边，末点 primary 实心），高度 24。
- 状态：normal / zero（数值 0 时数字降为 55% 透明度，不隐藏）/ loading（骨架）/ unknown（显示「—」+ caption「内核未提供」）。

### 3.5 评分条 RatingBar
- 结构：4 列等宽（窄屏 2×2），每张：`label(600) + kbd 右上 / 下次间隔(11px muted)`；min-height 77、r12、白面 1px border。
- 状态：hover 抬 1px / active scale .98 / 键盘 1-4 直触；间隔文本缺失时显示「按调度排期」不显示 0。

### 3.6 复习卡 ReviewCard
- 结构：HUD（进度条 + 计时 + 卡组 chip）→ 卡面（720px、r18、内边距 48/44、min-height 300）→ 底部动作区（显示答案 primary 宽钮 / 评分条）。
- 卡面字号跟随 `cardFontScale`；问题态遮罩 `lv-masked`；答案揭晓 240ms 淡入。
- 状态：loading（骨架卡）/ face-error（⚠️ 占位 + 重试，不白屏）/ timeout（到点 notice，不自动评分）。

### 3.7 章 Badge / 语义章 Chip / 键位 Kbd
- badge：11px/550、r5、`--soft` 底无边框，语义三档（brand/good/warn）+ 中性档（1px border）。
- chip：r999、4/10 内边距；chip--warn/--error/--primary/--default。
- kbd：10px、1px border-strong、r4；必须与实际快捷键一致。

### 3.8 通知 Notice
- 中性（on-bg 4%）/ warn / good 三档；12px；r9；可携带一个行内按钮。进行中任务（恢复横幅/预算）用中性+primary 左缘 2px。

### 3.9 空态 Empty / 骨架 Skeleton / 错误 Error
- Empty：图标圈（primary-soft 底 40px）+ 一句话 + 可选主动作钮；禁插画堆砌。
- Skeleton：6-12% ink 渐变 shimmer（reduced-motion 静态）；高度贴近真实内容，禁止整屏灰块。
- Error：error 色一句话 + 重试 outline 钮 + （可选）「保留现场」ghost；错误态优先于空态展示（不误 0）。

### 3.10 命令面板 CommandPalette（P0 新增组件）
- 居中浮层 560px、r20、shadow-2、backdrop blur；`搜索框 + 分组结果（最近/动作/卡组/导航）+ 右侧 kbd`；↑↓ 选择 Enter 执行 Esc 关闭。
- 结果项：40px 行高；选中项 primary-soft 底；组标题 eyebrow。

### 3.11 日历热力/预测 CalendarHeat（P0 新增组件）
- 月历 7×N 格：过去格按复习量 0-4 档 primary 深浅；未来格按到期量 warn 深浅；今日 2px primary 描边。
- 下挂 14 天预测条：横条按日到期量着色，hover 显示数字；「平峰」ghost 按钮只给建议（把新卡上限挪期），不改内核。

### 3.12 行 Row / 表 ListRow
- 16px 行距 + 1px 发丝线（末行无）；左主文本（body-strong）+ 副文本（caption muted），右侧动作组（ghost small ≤3 个，超出收进 ⋯）。

### 3.13 对话框 Dialog
- 宽 min(620px, 94vw)；r20；头部 24 内边距 + 标题 15/650 + 关闭 ghost；底部动作区右对齐（取消 outline + 主钮 primary）；遮罩 on-bg 32%。
- 焦点陷阱（AS-1 已实装）；Esc 关闭；打开记录宿主焦点关闭归还。

## 4. 逐页规格（R53 原型 14 面）

> 每面：布局 → 关键组件 → 状态要求。宽度基准 1160px 内容列（复习列 720px）。

### T01 总览（hub overview）
布局：页头（TODAY/日期 eyebrow + 22px 题 + 副题）→ hero 现场卡（洗色）：左 = 继续/开始标题 + 描述 + 徽章行 + CTA（48px primary「继续本场」），右 = 目标环（SVG 圆环，今日目标%）+ 可用时间选择 → 4 统计瓦片（到期/新卡/复习/今日已学，带 delta+sparkline）→ 「下一步」清单面板（材料/疑问/待恢复行）→ 深度统计渐进展开（outline 宽钮）。状态：loading 骨架 hero+瓦片；空库 → Empty（开引导）；V2/考试 chip 通知条。
禁：首屏超过 1 屏半；统计瓦片 >4 个。

### T02 收件箱（材料筛选）
布局：页头 + 计数 chip 组（待筛选/暂存/已选/已淘汰）→ 工具行（筛选 chips + 视图切换 + 排序）→ 分栏：左材料卡列表（来源块、摘录高亮、单卡操作：暂存/选中/淘汰/回源），右固定「批量操作」面板（批量状态流转 + 送制卡 primary）。状态：空箱 Empty（指引块菜单加入）；加载骨架 3 行。

### T03 制卡工作台（AI 向导）
布局：三栏（来源 0.9fr / 编辑 1.2fr / 卡面预览 1fr，≤1050px 折两栏、≤740px 单栏+segmented 切换）：
- 来源栏：来源分条卡（active 态 primary 描边）+ 「追加/替换」ghost；范围提醒 notice。
- 编辑栏：问面/参考答案 textarea + 人工字段锁定 badge + 「提出局部改写」ghost。
- 预览栏：问题/答案 segmented + 实际卡面（preview-card）+ 「旁路试练」。
- 页脚审计条：本次请求片段数 · 端点 · 预算余量 + 审核状态机（已选 n / 已审 m）+ 主按钮「入库已审候选」。
状态：请求前必须出现「请求预览」确认步（片段/端点/预算/许可）；生成中骨架卡；部分成功 → notice 分条报告（成功 n / 失败 m / 可恢复）。

### T04 专注复习
见 §3.6。附加：底部 ghost 工具（上下文/偏好/刷新/帮助/撤销/回看/编辑/暂停/跳过）单行 wrap；入口上下文条（BI-3）带 primary 左缘。状态：卡面加载失败占位；超时到点 notice；预算倒计时 HUD。

### T05 复习完成
单面板 620px：check 软绿徽 + 「本场完成」+ 计数行 → 三列统计（已确认评分/跳过/用时+今日目标）→ 预算 notice（如适用）→ 剩余到期 notice（如实，不为清零诱导）→ 收工原因 ghost 行（可跳过）→ NEXT 软面板（跳过 n → 去管理器；遗忘 m → 排期说明）→ 动作区（再来一批 text / 撤销 outline / 查看统计 primary）。状态：无跳过无遗忘时 NEXT 面板整体隐藏。

### T06 管理器
布局：页头 + 总数 caption → 工具行（搜索框 / 筛选 chips：状态+只看烂卡 / 排序 / 刷新）→ 左列表（ListRow：checkbox + 内容 + 路径 caption + hover 显「打开文档」）+ 右详情面板（四分面 segmented：内容/来源/学习记录/问题；内容分面含版本数与历史展开；来源分面 = 来源快照 + 回源按钮；记录分面 = 正式记录与旁路证据分栏 notice）。
状态：空库 Empty；筛选无结果 Empty（清除筛选钮）；分页。

### T07 目标与计划
布局：页头 + 新建 primary → 目标卡列表：每卡 = 标题 + 活跃 badge + 截止/每日预算/水平 caption + 三步链（了解概念 → 主动回忆 → 解释应用，当前步 primary 实底圆点）+ 主目标/维持 ghost + 删除 ghost。右栏或下挂「可承担的投入」soft 面板：预算 select + 截止 date + 范围/到期 stat ×2 + 超预算 warn notice + 缩小范围/延后 ghost。状态：无目标 Empty（记录目标不强迫建卡）；缺口 warn（材料未圈/预算未定）。

### T08 考试冲刺
布局：页头 + 新建 outline → 计划卡：名称 + 冲刺 badge + 日期/剩余/范围 caption + 每日建议量 + 进度条 + 动态建议 notice（今日建议 n · 落后 m · 不改调度）→ 行内 ghost ×6（编辑/复盘/写入/归档/暂停/删除）+ 右上 primary「开始今日应学」。状态：无计划 Empty；过期 plan 灰显 + 「已过期」caption。

### T09 维护与恢复
布局：页头 + 扫描 outline → 债务队列行（烂卡 n 次遗忘 / 今日暂停可恢复 / 未完成 AI 导入），每行：内容 + 债务 caption + 恢复/回源 ghost；右栏 soft「检查点」面板：当前任务 + good/warn 分条（已确认/未创建）+ 影响范围 + 「继续原任务」primary。状态：扫描中骨架；无债务 Empty（「队列干净」good）。

### T10 修卡演练
布局：左 soft 步骤列（5 步，当前步 primary 圆点）；右练习面板：坏卡样例 + 问题 warn notice + 修改 textarea + 来源 quote + 查看固定改法 demo + 试练 primary。页脚说明 tiny（零网络零写入）。状态：步骤完成打勾；退出/重开 ghost。

### T11 数据与备份
布局：分栏。左「备份与恢复」面板：自动备份 badge good + 备份行 ×3（恢复/下载 ghost）+ 保留策略 caption + 立即备份 primary + 恢复覆盖 warn notice。右上「从 Obsidian 迁入」：文件行（映射卡组 + 行数 + 待核对 warn）+ 解析失败 notice（可导出缺失清单）+ 预览映射 ghost + 开始导入 primary + 指纹幂等 tiny。右下「导出到 Obsidian」soft：范围 demo + 导出 primary + 复习历史不导出 tiny。状态：备份中进度；导入部分成功 → 分条报告。

### T12 设置
布局：左主栏：搜索框（按任务查找）→ 分组（学习与作答 / 外观与无障碍 / 数据与备份行入口 / 来源与外发）每字段 = label(12px 600) + 控件；右栏：本地样例预览 soft 面板（外观改动实时反映在虚构样例卡）+ 生效来源 notice（值 + 来源：本场/目标/全局）。
状态：搜索命中分组高亮；无结果 Empty；修改未保存 → 底部动作条（取消/保存 primary）。

### T13 命令面板（规划 · P0）
见 §3.10。样例分组：最近（继续现场/上次卡组）→ 动作（开始复习/快速制卡/立即备份/生成周报）→ 导航（7 页签）→ 插件命令（原生命令面板委托）。kbd：全局 ⌘K/Ctrl+K 唤起。

### T14 学习日历（规划 · P0）
见 §3.11。布局：月历面板（7×N，过去=热力、未来=负载 warn 深浅）+ 14 天预测横条 + 「平峰」建议 demo（把 12 张新卡中的 4 张挪至周三）+ 图例。状态：无数据 Empty；reduced-motion 无动画。

## 5. 主题与平台适配

- 亮暗主题 = 同一令牌域两套取值；任何新组件必须先在两主题下各自过一遍对比度（正文 ≥4.5:1，辅助 ≥3:1）。
- 窄屏（≤740px）：三栏→单栏 + segmented；评分条 2×2；触控 44px；表格隐藏次要列。
- 样式隔离：全部 `lv-` 前缀；禁止覆写宿主类（`.b3-button` 只允许作用域内「中性化」，不允许改配色语义）。

## 6. 验收清单（每次 UI 变更过一遍）

1. 每屏唯一 primary；主色覆盖率 ≤5%。
2. 六类状态齐全且不互斥冲突（错误优先于空态）。
3. 键盘全路径可用 + kbd 与实现一致；焦点环可见。
4. 亮/暗、390px、reduced-motion 三项过一遍。
5. 动效只用三档时长；无 breathe/glow/错峰。
6. 数字 tabular；未知显示「—」不是 0。
7. 新组件已录入本文 §3，新页面已录入 §4。
