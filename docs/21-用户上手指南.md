# 小驴闪卡 · 用户上手指南（5 分钟版）

> 安装：思源设置 → 集市 → 搜索「小驴闪卡」；或从 GitHub Release 下载 package.zip 离线安装。需思源 3.8+。

## 第 1 分钟：认识入口

| 入口 | 位置 | 作用 |
|---|---|---|
| 顶栏图标（左键） | 顶栏右侧 🫏 | 有到期卡 → 直接开始复习；无到期 → 打开闪卡中心 |
| 顶栏图标（右键） | 同上 | 菜单：闪卡中心 / 开始复习 / AI 制卡 / 设置；角标显示今日到期数 |
| 块图标菜单 | 任意块左侧图标 | 添加到卡组 / 快速制卡 / 制作遮挡卡 |
| 编辑器面包屑 | 文档标题下方 | 「复习本文档」一键按钮 |
| 命令面板 | Ctrl+P 或 ⌘P | 搜索"小驴闪卡" |

## 第 2 分钟：做你的第一张卡

1. 打开任意文档，点击某块的**块图标**；
2. 菜单选「**添加到卡组**」→ 选择或新建一个卡组（如「我的第一组」）；
3. 想做挖空卡？选中文字按 `Ctrl+K` 加高亮，再「添加到卡组」——高亮部分就是答案。

## 第 3-4 分钟：第一场复习

1. 点顶栏图标（或命令面板「开始复习闪卡」）；
2. 问题出现后，**按空格显示答案**；
3. 按键评分：`1` 遗忘 / `2` 困难 / `3` 良好 / `4` 简单（每个按钮上都会显示下次复习时间）；
4. 常用键：`p` 撤销上一步 · `x` 跳过 · `s` 今天不学 · `[` 回看上一张。

## 第 5 分钟：看懂统计

闪卡中心 → 总览：
- **六宫格**：今日到期 / 新卡 / 复习卡 / 已完成（含目标进度条）/ 连续天数 / 卡片总数；
- **热力图**：每天一格，越深复习越多；今天的格子有外环；
- **记忆保持曲线**：实线是你的实测保持率，虚线是理论参考——实线在虚线上方说明记得牢。

## 让它更懂你：画像预设

设置 → 画像预设，一键切换：
- 🎓 **备考冲刺**：开启考试模式 + 打字题 + 激励，题量默认调大；
- 📝 **卡片笔记**：制卡效率 + 统计优先，安静无打扰；
- 🗣 **语言学习**：三档评分 + 朗读语速 + 选择题模式。

## 常用进阶

| 想做什么 | 去哪里 |
|---|---|
| 考前倒排每日任务 | 闪卡中心 → 考试 → 新建计划 |
| AI 批量把笔记变成卡 | 顶栏右键菜单 → AI 制卡 |
| 找出总是记不住的卡 | 总览 → 烂卡重写清单（阈值在设置） |
| 睡前安静复习不被打扰 | 设置 → 免打扰时段 |
| 导出/备份学习记录 | 设置 → 数据 → 导出 JSON/CSV |

## 遇到问题

先看 [FAQ 与故障排查](./20-FAQ与故障排查.md)；仍未解决请到 [GitHub Issues](https://github.com/ai68298100/siyuan-lv-cards/issues) 反馈（附「设置 → 数据 → 复制诊断信息」内容更佳）。

## 数据安全承诺

无遥测、无上传。你的所有数据都在思源笔记里，随你的同步走；卸载插件也不会丢失任何卡片。
