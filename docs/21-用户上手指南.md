# 小驴闪卡 · 用户上手指南（5 分钟版）

> 安装：从 [GitHub Release](https://github.com/ai68298100/siyuan-lv-cards/releases/latest) 下载 package.zip，在桌面端思源设置 → 集市 → 下载中导入安装包。最低声明为思源 3.8.0，具体设备功能仍需验收；集市新增 PR 已合并，索引部署有延迟，尚未搜到插件或新版本时可使用 Release 安装包。
>
> **长期方向**：小驴闪卡会逐步覆盖从材料捕获、制卡、复习到课程、应用、维护和生态联动的完整学习流程。当前指南按 v0.210.42 的已实现入口编写；真实设备覆盖以 docs/34 和 [docs/43 当前状态审计与开发交接](./43-当前状态审计与开发交接.md) 的证据为准，回归与设备验收范围见[待办清单](./17-待办清单.md)；其他能力见[产品使命与全功能战略](./27-产品使命与全功能战略.md)。

## 第 1 分钟：认识入口

| 入口 | 位置 | 作用 |
|---|---|---|
| 顶栏图标（左键） | 顶栏的小驴闪卡图标 | 有到期卡 → 直接开始复习；无到期 → 打开闪卡中心 |
| 顶栏图标（右键） | 同上 | 菜单：闪卡中心 / 开始复习 / AI 制卡 / 设置；角标显示今日到期数 |
| 块图标菜单 | 任意块左侧图标 | 添加到卡组 / 快速制卡 / 制作遮挡卡 |
| 编辑器面包屑 | 文档标题下方 | 宿主提供所需接口且复习模块开启时可出现「复习本文档」，未出现使用顶栏/命令入口 |
| 命令面板 | Ctrl+K 或 ⌘K | 搜索"小驴闪卡" |

## 第 2 分钟：做你的第一张卡

1. 打开任意文档，准备有可见题面和答案标记的卡片，例如 `法国的首都是 ==巴黎==`，点击该块的**块图标**；
2. 菜单选「**添加到卡组**」→ 选择或新建一个卡组（如「我的第一组」）；
3. 想做挖空卡？先在文档中选中文字，再从块菜单选择「挖空并制卡」；完成后检查实际题面与答案。

制卡、导入和编辑保存会检查最终卡面。普通卡不能只剩 `==答案==`；图片遮挡需要有效图片和遮挡区域。AI 候选也会检查结构和部分高置信问题，但这些检查不能证明知识内容正确，请在接受前自行核对。

## 第 3-4 分钟：第一场复习

1. 点顶栏图标（或命令面板「开始复习闪卡」）；
2. 问题出现后，**按空格显示答案**；
3. 按键评分：`1` 遗忘 / `2` 困难 / `3` 良好 / `4` 简单（每个按钮上都会显示下次复习时间）；
4. 按 `?` 查看本面板快捷键，`[` 可回看上一张；撤销、跳过和会话恢复仍有回归待办，不能据入口存在推断完整恢复能力。默认超时关闭；若启用“超时判遗忘”，现版会自动提交遗忘评分，希望每张自评时请关闭该项。

## 第 5 分钟：看懂统计

闪卡中心 → 总览：
- **六宫格**：今日到期 / 新卡 / 复习卡 / 已完成（含目标进度条）/ 连续天数 / 卡片总数；
- **热力图**：每天一格，越深复习越多；今天的格子有外环；
- **记忆保持曲线**：实线是插件本地日志的间隔分桶保持率，虚线是固定理论参考。它们不能直接比较得出掌握程度或学习效果；样本、分母和记录覆盖范围都影响结果。

## 让它更懂你：画像预设

设置 → 画像预设，一键切换：
- 🎓 **备考冲刺**：开启考试模式 + 打字题 + 激励，题量默认调大；
- 📝 **卡片笔记**：制卡效率 + 统计优先，安静无打扰；
- 🗣 **语言学习**：三档评分 + 朗读语速 + 选择题模式。

## 常用进阶

本地未发布候选新增：在插件命令面板搜索“导入与迁移”、Anki、Obsidian 或 `.lvcards`，可直接进入卡片导入、日志迁移与备份恢复的任务视图；“查看全部设置”会保留当前草稿。Anki 本地导入仍要求桌面宿主支持 SQLite 与 zlib。该快捷入口已包含在 v0.210.6 Release 中，范围见[本轮记录](./audits/2026-10-18-import-workflow.md)。

本地候选的 `.lvcards` 导入会完整读取同名卡组、检查包内重复与身份冲突，并在写入前检查题面/答案结构。若正文被拆成多个块而无法一一对应，会停止入组并保留导入文档；若入组结果未确认，先检查提示的文档及目标卡组，再决定是否重试。当前分享包导出仍存在大库截断和格式损失的已知问题，完整往返尚未验收，详见[导入完整性记录](./audits/2026-10-18-lvcards-import-integrity.md)。

| 想做什么 | 去哪里 |
|---|---|
| 考前倒排每日任务 | 闪卡中心 → 考试 → 新建计划（含动态建议：落后补偿/不可行提示，仅供参考不改调度） |
| AI 批量把笔记变成卡 | 顶栏右键菜单 → AI 制卡 |
| 找出总是记不住的卡 | 总览 → 烂卡重写清单（阈值在设置） |
| 睡前安静复习不被打扰 | 设置 → 免打扰时段 |
| 导出/备份学习记录 | 设置 → 数据 → 导出 JSON/CSV |
| 用 Obsidian 闪卡语法写卡 | `问题 :: 答案`、`问题 ::: 答案`（双向语法按正向制卡）、多行 `?`/`??`；写好后命令面板 → 标记符扫描制卡 |
| 排查旧卡、媒体和重复内容 | 闪卡中心 → 维护；查看原因、回源、编辑后重扫，近似重复需要人工审阅 |
| 查看来源问题的处理历史 | 维护 → 查看来源健康历史；确认来源后或移出卡组后仍保留记录 |

复习发现结构无效的旧卡时，会从本场呈现中隔离并提供修复重查，不改 due、评分或学习日志。批量修复先查看逐卡差异再确认；失败时可恢复精确的旧内容，旧卡结构无效也不会阻断补偿，正常编辑仍需校验。成功批次会写入 `maintenance-repair-journal.json`，维护页提供“上次批量修复记录”和撤销入口；如果卡片在修复后被再次编辑，撤销会因冲突保护而阻断。撤销日志用于恢复与审计，不是完整的逐次编辑备份。媒体探测显示“未判定”代表当前无法确认，不等于媒体已损坏。来源健康历史记录问题发现与处理，不记录每次编辑；没有历史不代表来源已经验证健康。

> 复习日志的统计口径（时区、2 万条明细上限、作答耗时封顶、CSV 列含义）见内置帮助「复习日志统计口径」与[隐私说明](./PRIVACY.md)。

## 数据安全承诺

当前无遥测。笔记与卡片由思源保存，插件设置和本地日志位于思源工作空间内，按你配置的同步渠道处理。AI 制卡会发送材料到配置的服务商；网络故障、超时、5xx 或限流时可自动尝试已配置的备用端点，鉴权、配额、策略、解析错误和用户取消不会回退。导出插件日志只备份该类记录，卸载或清理前请分别检查笔记、卡片与插件私有数据的保留范围，详见[隐私说明](./PRIVACY.md)。
