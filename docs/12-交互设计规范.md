# 小驴闪卡 · 交互设计规范

> 配套：13-UI原型图（本文描述状态与规则，13 画出样子）。交互总原则：**高频零层级、危险必确认、键鼠触屏等价、错误不阻断**。

## 1. 入口与导航

### 1.1 入口行为细则

| 入口 | 触发 | 行为 | 备注 |
|---|---|---|---|
| 顶栏图标 | 左键/单击 | 直接开复习（上次范围） | 移动端同 |
| 顶栏图标 | 右键/长按 | 菜单：V2 徽章(只读) → 今日摘要(只读) → 闪卡中心 → 开始复习 → 设置 | 移动端长按 0.5s |
| 顶栏角标 | — | 今日到期数；0 张时隐藏；>99 显示 99+ | 心跳 60s；移动端降级 |
| 命令面板 | — | 「开始复习」默认全局热键（待定避让）；「打开闪卡中心」；「快速制卡」 | |
| 块右键菜单 | 选中 1-N 块 | 添加到卡组 / 快速制卡 / 卡片信息 / 从卡组移除 | 无卡块与有卡块菜单项不同 |
| 面包屑按钮 | 单击 | 复习本文档 | 3.8.2+，倍数可调（对齐 ZY） |
| 悬浮球 | 单击/拖动/长按 | 复习 / 移动 / 设置；与胶囊启动器拼合 | 仅移动端 |

### 1.2 导航结构

```
顶栏 ─ 左键 ──────────► 复习面板（Tab，可停靠）
      └ 右键菜单 ──┬──► 闪卡中心（Tab）
                    │     ├ 总览（统计）
                    │     ├ 管理
                    │     ├ 考试
                    │     └ 数据
                    └──► 设置（Dialog）
编辑器 ─ 块菜单/面包屑 ─► 制卡 Dialog / 复习面板(文档范围) / 卡片详情抽屉
```

规则：
- 任何界面到"开始复习"≤1 步（顶栏左键/悬浮球/热键）。
- 闪卡中心二级导航吸顶，切子页不丢滚动位置。
- Dialog 只做"短任务"（设置、向导、改期），凡是"面"的内容一律进 Tab。

## 2. 复习会话状态机（核心）

```
                    ┌──────────────────────────────────────────┐
                    ▼                                          │
┌───────┐  范围确认  ┌────────┐  拉取成功  ┌─────────┐           │
│ Idle  ├──────────►│Loading ├──────────►│ Question │──────────┤
└───────┘           └───┬────┘           └────┬────┘           │
   ▲                    │队列空               │ 空格/点击空白/上滑│
   │                    ▼                     ▼                │
   │              ┌──────────┐          ┌─────────┐            │
   │              │ Done(小结)│◄─批耗尽──│  Answer  │◄──打字题:提交│
   │              └────┬─────┘          └────┬────┘            │
   │                   │再来一批/关闭         │ 1-4/手势         │
   │                   ▼                     ▼                │
   │              ┌──────────┐          ┌─────────┐            │
   └──────────────│  Rated   ├─────────►│  Next    │────────────┘
        (重开)     └──────────┘  写revlog └─────────┘
```

### 2.1 Question 态（问题阶段）

- 显示：题面（来源块渲染）+ 头部（范围名 · 进度 n/N · 新卡chip · reps/lapses）+ 操作条（显示答案 / 跳过 / 今天不学 / 编辑 / 打开来bf源）。
- **点击翻面热区 = 卡面空白与页脚**；卡面内输入控件、链接、代码块点击不翻面（为打字题与富交互预留）。
- 打字题卡型：题面下方出现作答输入框，回车提交进入判分（不翻面），显示 diff 后再进 Answer 态。
- 超时模式开启时右上角计时环；到阈值执行配置动作（翻面 / 自动评遗忘）。

### 2.2 Answer 态（答案阶段）

- 评分按钮：四档（遗忘/困难/良好/简单）或三档（认识/模糊/不认识）或置信度 1-5；**每键两行**：主标签 + 下次间隔（来自 nextDues，"10分/3天/1.2月"）。
- 撤销：`u` 键 / 完成页可撤；V2 调 undoReview，riff 走官方缓存恢复。
- 回看上一张：`[` 键，弹出只读浮层（前一张问题+答案），`Esc` 关闭，不产生任何调度副作用。

### 2.3 特殊动作

| 动作 | 语义 | 实现 |
|---|---|---|
| 跳过 | 本场跳过，不动调度 | V2 skip / riff skip，revlog 记 rating=0 |
| 今天不学 | 本地屏蔽到次日 0 点 | 插件私有 suspend-today 列表；V2 有 buried 时优先官方 |
| 改期 | 立即弹自然语言改期（"3天后/明天/下周一"） | batchSetRiffCardsDueTime / V2 mutate |
| 编辑 | 跳编辑器并定位块 | openTab zoomIn |

### 2.4 队列规则

- 顺序：默认 内核 ReviewMode（混/新优先/旧优先）→ 插件层可选「交替」与「随机」。
- 考试计划激活时：队列 = 计划范围过滤（M7·FR3），头部显示计划进度条，可一键暂停计划回普通复习。
- 深度：每批按内核上限；批耗尽自动续拉，间隔 300ms 防抖；全空 → Done 态。

### 2.5 Done 态（会话小结）

新卡/复习/遗忘/跳过/用时 五项 + 「再来一批」「关闭」；若达成每日目标，追加庆祝条（M8）。**可撤销最后一评**（回到 Rated 前状态）。

## 3. 键盘映射

| 键 | 问题态 | 答案态 | 任意 |
|---|---|---|---|
| `Space`/`Enter` | 翻面（打字题：提交） | 评"良好"(3) | |
| `1`-`4` | — | 评分 1-4 | |
| `x` / `0` | 跳过 | 跳过 | |
| `u` / `p` / `q` | 撤销上一评 | 撤销上一评 | |
| `[` | 回看上一张 | 回看上一张 | |
| `s` | 今天不学 | 今天不学 | |
| `e` | 编辑原块 | 编辑原块 | |
| `f` | 快速改期 | 快速改期 | |
| `Esc` | — | — | 关浮层/退出回看 |

规则：输入框聚焦时（打字题/搜索）数字与空格不触发评分/翻面；映射可在设置中重排（v2）。

## 4. 手势（移动端）

| 手势 | 区域 | 行为 |
|---|---|---|
| 右滑 | 卡面 | 评"良好" |
| 左滑 | 卡面 | 评"遗忘" |
| 上滑 | 卡面 | 翻面 |
| 单击 | 卡面空白 | 翻面 |
| 长按 0.5s | 卡面 | 操作面板（跳过/今天不学/改期/编辑） |
| 下滑 | 头部 | 退出会话（有进度时确认） |

滑动手势与三/四档映射：四档下左滑=1、右滑=3；三档一致。滑卡动画尊重系统减弱动态设置。

## 5. 反馈系统

| 层级 | 载体 | 用于 |
|---|---|---|
| 即时 | 按钮按下态/评分动画/进度条 | 每次评分 |
| 轻提示 | snackbar（2-3s） | 已改期/已加入卡组/已屏蔽今日/撤销成功 |
| 确认 | confirm Dialog | 批量操作、重置、清空数据（显示影响数量） |
| 庆祝 | 全屏轻量彩带（≤2s，可关） | 达成每日目标/连胜里程碑 |
| 常驻 | 顶栏角标/中心头部条 | 到期数/目标进度/V2 状态/考试倒计时 |
| 错误 | 内联红字 + 重试按钮 | 拉取失败（保留当前会话现场，不清屏） |

原则：评分链路永不因统计/激励失败而阻塞（旁路 try-catch）；网络/内核错误统一文案「内核无响应，请检查思源是否运行」+ 重试。

## 6. 空状态与引导

| 场景 | 文案方向 | 动作 |
|---|---|---|
| 全库无卡 | 「把第一条笔记变成卡，3 步搞定」 | 按钮：选一个块制卡 / 看 30 秒引导 |
| 范围内无到期 | 「这个范围今天学完了 ✓」 | 换范围 / 提前预习(仅浏览) |
| 内核无响应 | — | 重试 |
| V2 LegacyDiverged | 「检测到迁移后旧数据有写入」 | 前往数据子页诊断 |
| 首次启动 | onboarding 三步 | 见 §7 |

## 7. 首次启动引导（Onboarding，≤60 秒）

1. **选画像**：备考 / 笔记 / 语言（单选卡片，说明各自开什么）。
2. **建第一张卡**：贴一段文字 → 一键生成 3 张示例卡（本地演示，真数据）。
3. **复习 3 张**：直接进入复习面板完成第一场 → 完成页展示统计页入口。

跳过任意步；完成后画像可在设置改。引导完成状态存 settings（不重复出现）。

## 8. 移动端适配规则

- 复习面板：全屏无 Dialog；头部压缩为单行（范围 · n/N · 倒计时）。
- 闪卡中心：子导航变顶部横滑 chips；图表降采样（热力图仅近 9 周）。
- 悬浮球：默认右下，可拖动记忆位置；到期数角标同步。
- 触控目标 ≥ 44px；评分按钮全宽等分。
- 性能：统计缓存 60s、并发上限 4（对齐 ZY 实测经验）；后台 30 分钟后回前台强制刷新队列。

## 9. 无障碍与本地化

- 颜色对比走 b3 主题变量（亮暗自适应）；评分四档除颜色外带形状/文字双编码。
- 全部可达操作有键盘等价（§3）。
- i18n：zh-CN / en 完整；文案禁硬编码；日期格式随思源语言。
- 动画尊重 `prefers-reduced-motion`。
