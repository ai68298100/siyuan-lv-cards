# 44 · UI 重构分析与 R54 设计方案

> 日期：2026-10-11；核查基线：本机小驴闪卡 v0.209.3。
> 本文说明改版背景与实现边界；[R54 可交互原型](./prototypes/lv-cards-r54.html)是 UI 结构、视觉、交互状态和响应断点的唯一规范事实源。组件目录用于查 API，验收台账记录原型与生产实现的差异，不构成另一套 UI 规范。
> 原型使用合成数据，不连接思源、不调用模型、不写入卡片或评分；其样例不是生产数据或服务行为证据。源码、测试和宿主记录用于证明实际行为，并应与原型保持一致。R54 是本次 UI 修订号，与 docs/00 的历史研究轮次 R54 分开理解。

## 1. 要解决的问题

闪卡已有材料捕获、制卡、内核复习、管理、目标、考试、维护、AI 安全链和备份能力。问题在于入口和任务面逐渐累积，用户容易先看到工具集合，而不是“现在该做什么”。

重构目标是让新用户能完成第一张卡，熟练用户能迅速进入学习，复杂任务仍可深入处理。质感来自一致的层级、间距、色彩和反馈，也来自页面之间保留现场；不能只换配色和圆角。

本次保留“一屏一问、来源可见、未知不冒充零、键盘等价、克制动效”原则，形成与小驴打卡接近的独立浅深色板和更稳定的五项导航。R53 是既有生产实现的历史视觉基线；若 R53 文档与 R54 原型冲突，以 R54 原型作为 UI 规范，并在验收台账记录生产迁移差异。

## 3. 闪卡当前实现与迁移边界

现版 `src/ui/hub.svelte:70` 最多七个页签：总览、管理、制卡入口、目标、收件箱、考试、维护，部分按配置和界面模式出现。复习、详情、设置及向导还有各自表面。

[原型核对清单](./40-原型全页核对清单.md)明确了四项差异：制卡入口不是完整三栏审核面；维护页不是完整候选/导入/未知评分恢复中心；数据能力主要在设置；学习日历仍是内嵌只读统计和预测。R54 必须保留这些能力边界，不把布局补齐写成业务已实现。

保留 `src/core/*` 的领域逻辑和 `src/api/*` 的内核、AI 适配：FSRS 正式评分、卡片身份、来源关系、日志、预算、会话恢复、同步和存储语义继续使用原事实源。原型评分只演示流程；真实评分不能在 UI 自建第二套调度器。

复用或包裹现有 `src/ui/kit/*` 组件，逐页迁移 `dashboard.svelte`、`manager.svelte`、`ai-wizard.svelte`、`review.svelte`、`settings.svelte`，避免同时重写领域模型和视觉层。每次 UI 迭代先在 R54 原型中补齐变化，再按原型更新生产组件；有差异时将差异和证据登记在 docs/45，不把未实现的原型状态写成生产能力。

## 4. 信息架构：五个主导航与上下文表面

## 6. 视觉与组件基座

| 语义 | 浅色目标 | 深色目标 | 用途 |
|---|---|---|---|
| 画布 | `#F7F7FC` | `#141419` | 连续背景 |
| 工作面 | `#FFFFFF` | `#1D1E24` | 题面、卡片、表单 |
| 次级面 | `#EFF0FA` | `#26272F` | 分组、预览、解释 |
| 描边 | `#E4E6F4` | `#2C2D38` | 边界，不承担状态唯一编码 |
| 正文 / 辅助 | `#2A2B35` / `#63657A` | `#EFEFF6` / `#9FA0AC` | 中文可读性优先 |
| 操作 / 浅操作底 | `#5B65E8` / `#EAE6FF` | `#8B93F8` / `#2B2C44` | 主动作、焦点、选中 |
| 节奏暖色 | `#F6A94B` / `#FFF1D9` | `#F6B04E` / `#38301F` | 时间与温和反馈，不表示失败 |

色值是目标 token，真实组件还需分别验证对比度。主色文本与填充分开；状态使用文字和图形，未复习不使用惩罚红。图表颜色与业务含义稳定。

中文字体栈使用 Inter、苹方、微软雅黑及系统无衬线；标题 24–28px，正文 14px/22px，卡面 20–22px/1.7，帮助 12px/18px，数字等宽。间距 4/8/12/16/24/32px；小控件圆角 8–10px、行 12px、卡片 16–18px、弹层 22px。普通卡不加厚阴影，浮层使用轻阴影。

只在今日首屏、首用和结果使用本地 SVG 轻装饰，尺寸受限且 `aria-hidden`；卡库、制卡工作面、复习题面优先内容。装饰无需外部图片、字体或网络请求。

独立主题限定在插件根，例如 `.lv-cards-app[data-theme]`。提供“跟随思源 / 浅色 / 深色”，跟随只读取宿主明暗状态，映射到插件两套色板；不在 `:root` 或宿主全局重定义颜色。迁移时逐步替换旧组件的 `--b3-*` 依赖，单独挂载的复习/弹窗也应用同一主题提供器。

样式按 **tokens → primitives → layouts → pages** 分层：语义变量；按钮/输入/章/通知/状态；壳/列表/分栏/抽屉；页面组合。优先拆分现有样式职责，禁止为每次修补追加更高优先级覆写。

## 7. 响应式与承载形态

使用插件容器宽度而非宿主窗口宽度决定布局：建议 ≥1120px 完整侧栏与分栏；760–1119px 收为图标轨、详情可关闭；480–759px 单栏加底部导航；<480px 单栏与紧凑任务切换。断点是验收起点，依真实内容调整。

Tab 承载完整工作区；窄 Dock 只展示今日最小任务与继续学习；制卡和复杂管理进入 Tab。移动端保留五项导航，复习进入沉浸上下文，返回恢复原导航。底栏、Sheet、安全区和输入法都不能覆盖操作栏。

制卡宽屏是材料/候选/卡面三工作面，中屏两列，窄屏是同一草稿的分面切换；不能通过隐藏另一栏丢掉来源或编辑内容。卡库可由连续列表进入 Peek；窄屏改全高 Sheet。

每页只保留一个主滚动区；桌面密集控件最小 36–40px，触控操作 ≥44px；复习评分窄屏 2×2。200% 字体、中文长标题、640px 低高度和软键盘出现时主动作仍可达。

## 8. 关键页面与任务契约

### 8.1 今日与首次使用

页头是日期与保存/同步状态；主卡是当前范围、待复习数量、预计时间和开始/继续。今日小摘要只解释进度；待处理显示需要行动的原因，不把所有指标摆成同权重彩块。

空库提供“体验示例卡”和“创建第一张卡”，说明示例只用于了解翻面与评分。演示模式不写正式评分；把示例加入真实卡库需显式选择并说明影响。首次成功路径是体验/建卡 → 揭晓 → 评分反馈 → 查看结果；允许跳过和重新打开。

### 8.2 卡库与详情

搜索、牌组、状态、排序在统一工具栏。行显示卡面摘要、来源、真实状态和少量动作；鼠标悬停之外也能打开详情。多选后出现独立批量栏，先显示范围/数量/影响，再执行危险动作。

详情区分内容、来源、学习记录和问题；修改前后可比较，保存失败保留编辑。方向键、Enter、Delete 等现有快捷操作迁移后仍有效，编辑输入期间不触发全局快捷键。

### 8.3 制卡：手工默认可用，AI 是可选路径

材料入口支持粘贴、当前来源、收件箱选择与手工问答。未配置 AI 时展示“可先手工制卡”和“去配置”，解释将使用哪类服务；配置页返回后保留材料，不把整个制卡页禁用。

AI 发送前预览实际片段、端点、用途、预算和外发范围；敏感内容检测就近提示，并由用户确认该批实际发送内容。仅已确认且审核通过的候选入库；编辑使旧审核失效，人工锁定字段不被静默覆盖。

取消停止当前请求/后续写入并保留草稿；超时、401、限流、配额、服务器错误各有原因和恢复动作。预算超限禁止继续发送，仍保留编辑和手工保存。请求代次及 owning surface 隔离，旧结果不能覆盖新材料或新请求；取消后到达的结果不能显示为成功。

### 8.4 复习与结果

题面、来源和本场进度优先；揭晓前不提供评分，评分提交中锁定同一张卡的评分动作。只有内核确认后才推进进度和正式日志；未知结果显示“结果待核对”，禁止盲目重复提交，提供核对与恢复路径。

选择题干扰项不足时采用二选或三选；没有可信干扰项时退回自由回忆，说明“本题已改为自由回忆”，不用占位选项。练习方式变化不自动变成正式评分。

遗忘短期再练保留当前约三分钟循环语义，显示等待/继续其他卡的下一步；不把等待显示为整场完成。结果只统计已确认事实，显示遗忘、跳过、用时及下一步，允许查看对应卡或结束，不以“清零”制造压力。

### 8.5 学习与设置

学习页把计划与回顾分成任务页签：目标/考试计划、记录、日历与趋势。所有数字显示范围、口径、更新时间；未知显示“—”和原因，内核未提供的历史不绘制虚构走势。

设置先显示本地数据、同步、AI、备份四类健康状态，再进入分类详情。区分立即生效、本场生效和保存后生效；重置/恢复说明具体影响。OCR 接入继续遵守已记录的版本前提，此次不因原型展示提前开发或默认启用。

## 9. 状态与按钮一致性

| 状态 | 页面反馈 | 按钮与恢复要求 |
|---|---|---|
| 加载 | 接近真实结构的静态/短时骨架，说明当前任务 | 禁止重复加载；允许安全取消或返回 |
| 空库 | 解释没有卡片；给示例和创建入口 | 不用“0%”代替学习状态 |
| 无到期 | 说明今天没有到期卡；可练习或查看卡库 | 不误禁用卡库和手工制卡 |
| 筛选无结果 | 展示当前筛选原因 | 清除筛选；不显示空库引导 |
| 未配置/不可用 | 缺什么、可先做什么、如何配置 | 仅阻止依赖该能力的动作；邻近说明原因 |
| 部分成功 | 已确认/失败/待核对逐项分开 | 只重试失败且安全的项；成功项不重复写 |
| 失败 | 发生了什么、保留了什么、下一步 | 保留输入；重试、改手工、回来源可达 |
| 提交中 | 保存中/评分中与 `aria-busy` | 锁定相关动作；结束恢复此前 disabled 状态 |
| 未知/待核对 | 不把未知显示为成功、失败或零 | 未核对前禁止重复评分；进入待处理 |
| 草稿脏/跨窗口更新 | 本地修改与新事实分开呈现 | 保存并离开/放弃/取消；冲突不静默覆盖 |

每个动作必须核对入口、前置条件、范围、处理中状态、成功回执、失败恢复和返回点。没有真实动作的原型按钮必须明示“预览”，模拟回执使用“仅预览，未写入”；禁止灰按钮无解释、点击无反馈和示例保存冒充落盘。

## 10. 跨页面联动与上下文

| 数据变化 | 受影响视图 | 刷新规则 |
|---|---|---|
| 已确认评分/撤销 | 今日、卡库、学习、角标、当前会话 | 复用现有事件与缓存失效；正式确认后更新，不乐观伪造计数 |
| 卡片创建/编辑/删除 | 卡库、今日、来源详情、候选入库计数 | 按对象刷新；分页、搜索、选中和滚动尽量保留 |
| 材料筛选/候选审核 | 制卡、待处理、今日下一步 | 同一材料/批次身份，不复制多份草稿 |
| 目标/计划/偏好修改 | 今日建议、学习、下一场配置 | 显示生效范围；不得静默改进行中的正式会话 |
| 外部窗口更新 | 所有订阅页面与详情 | 去重合并通知；保留脏草稿，提示核对，不全页重载 |

页面上下文建议统一为 page、returnTo、deckId/cardId、query、filters、selectedIds、scrollAnchor、focusId、draftId、requestEpoch。视图态归挂载表面，数据态归原存储；关闭释放订阅和任务。跨页返回恢复现场，迟到事件先验证生命周期和对象身份。

## 11. 分阶段实施与验收

| 阶段 | 交付范围 | 放行条件 |
|---|---|---|
| A 原型评审 | 五导航、上下文面、两主题、宽窄布局、主要状态 | 用户能完成体验示例→复习→结果、材料→候选→入库、卡库→详情→返回三条路径；明确模拟边界 |
| B UI 基座 | scoped tokens、主题提供器、基础控件、状态、壳与路由适配 | 旧入口兼容；原 FSRS/API/存储不改义；亮暗、窄 Dock、字体放大可读 |
| C 今日与卡库 | 下一步首屏、搜索筛选、Peek、多选、首用 | 现有键盘操作、空态分型、返回恢复、跨窗口脏草稿验证 |
| D 制卡 | 三工作面、手工路径、AI 配置/外发/预算/错误 | 无 AI 可闭环；取消与旧请求无写入；部分成功不重写；输入与审核状态正确保留 |
| E 复习与学习 | 沉浸卡面、评分、等待循环、结果、计划/统计 | 正式/旁路证据分开；未知评分不可重提；降级题型诚实；源数据同步与口径一致 |
| F 设置与收口 | 健康总览、数据恢复、全局命令、入口和文案 | 全任务面无遗漏；危险操作影响预览；反馈、主题和生命周期一致 |

每阶段只运行相关有效检查；领域或 API 改动才增加对应业务测试。正式迁移完成需经过 `pnpm check`、既有测试、i18n/文档事实检查、构建 smoke，并对本轮变化做真实宿主验证。原型检查用于确认唯一 UI 规范自身可操作且覆盖指定状态/断点；它不代表思源落盘、移动客户端、模型异常或多窗口已通过。

视觉验收覆盖桌面、窄 Dock、320/390/760/1024/1440px、浅深主题、200% 字体、低高度、reduced-motion；交互验收覆盖键盘、焦点进出、Esc/返回、主动作可见性、加载/空/错/部分/未知/草稿状态。最终逐项核对 R54 原型的全部任务面、中文文案和来源回路，并将生产差异登记到台账。
