## 1. 定位

**官方 V2 之上的学习体验层。**

内核（含 3.9.0 闪卡 V2）负责"数据与调度"——卡是什么、何时复习；小驴闪卡负责"怎么学"——制卡有多快、复习有多顺、坚持有多容易、考前有多从容。

> 一句话：**让思源闪卡拥有 Quizlet 的好学、墨墨的坚持、Anki 的深度。**

边界（不做什么）：
- 不替换调度算法、不自建卡片数据层（永远以内核 riff/V2 为唯一数据源）
- 官方已内置的能力不自建（统计引擎、撤销、apkg 解析、坏卡清理……见 05 对照表），只做更高级的消费与编排
- 不做多端云服务/付费牌组市场/多人对战

## 2. 用户画像与场景

| 画像 | 核心诉求 | 主用模块 | 关键旅程 |
|---|---|---|---|
| P1 备考学生（考研/考证/医考） | 别让我积压；考前必须过完一遍 | 考试模式、复习面板、AI 制卡、cram | 导入讲义→AI 成卡→按倒排进度学→考前 cram→考后复盘 |
| P2 卡片笔记党（知识工作者） | 制卡要快；数据要看得见 | 制卡工作流、统计中心、管理器 | 日常笔记→选中即卡→每周看统计→烂卡重写 |
| P3 语言学习者 | 大量重复但要不无聊 | 听写/打字题型、滑卡、TTS、激励 | 词句入库→听写刷→连胜保持 |

**画像预设包**（设置的第一个控件）：备考模式 / 笔记模式 / 语言模式 / 自定义。一个预设 = 一组模块开关 + 参数默认值。开关永远可微调——预设只改默认，不锁行为。

## 3. 设计原则（十条）

1. **内核优先**：调度、数据、官方已做的一律调内核；插件是增值层。
2. **数据不锁**：卡片本体永远是思源块 + 内核 riff/V2 库；插件私有数据（revlog/计划/AI 批次）全部可导出。
3. **默认轻，按需长**：新装只开核心三件（复习/统计/管理），其余模块按画像或手动点亮。
4. **渐进披露**：新手 5 分钟内能完成"制卡→复习 3 张→看到第一格热力图"；高级能力（AST 搜索、预设组、考试计划）藏在二级。
5. **双轨可降级**：每个 V2 能力都有 riff 兜底；能力检测驱动 UI 显隐，绝不因内核版本白屏。
6. **键鼠优先，触屏不缺**：桌面全快捷键（评分/撤销/跳过/回看），移动端手势+大按钮等价。
7. **原生观感**：全 b3 变量与内置组件类；入口长在思源体内（块菜单/面包屑/命令面板），不强加新世界观。
8. **宽容解析**：对外部数据（内核响应、V2 契约、打卡插件数据）宽容读取，缺字段静默降级，统计旁路永不阻塞主流程。
9. **生态互通**：向 eventBus 广播标准事件（复习完成/连击/制卡），供打卡、复盘、拾遗消费；能读别人的数据就不自建。
10. **本地隐私**：AI 制卡默认走思源 AI 配置；自带 key 仅高级项；不上传任何学习数据。

## 4. 系统分层（自上而下）

```
L4 生态联动    打卡 · 复盘 · 拾遗 · eventBus 事件契约
L3 呈现层      UI Kit（src/ui/kit/，docs/16）· 复习面板 · 闪卡中心 · 向导与对话框 · 移动端
L2 领域模块    制卡工作流 · 会话引擎 · 题型系统 · 统计消费端 · 考试规划 · 激励 · Anki桥
L1 网关层      FlashcardGateway 统一接口
               ├─ RiffGateway（3.8.x，17 个 /api/riff/*）
               └─ V2Gateway（3.9.0+，/api/flashcard/* + getRenderModel）
L0 内核能力    内核 riff / 闪卡 V2 / FSRS / AnkiConnect / 思源 AI / Protyle 渲染
```

- **L1 是扩展性的核心**：上层永远只面对 `FlashcardGateway` 接口（见 14），内核怎么变都只改适配器。
- **L2 模块互相独立**，只依赖 L1 与事件总线；模块间禁止直接调用，走事件或显式服务注入。

## 6. 信息架构

### 6.1 入口矩阵

| 入口 | 行为 | 平台 |
|---|---|---|
| 顶栏图标 **左键** | 直接开始复习（最高频动作零层级） | 桌面+移动 |
| 顶栏图标 **右键** | 菜单：闪卡中心/开始复习/设置 + V2 状态徽章 + 今日到期摘要 | 桌面 |
| 顶栏图标 **角标** | 今日到期数（心跳刷新，移动端降级为菜单项文字） | 桌面 |
| 命令面板 | 打开闪卡中心 / 开始复习（默认热键）/ 制卡 | 全平台 |
| 块右键菜单 | 添加到卡组 / 快速制卡 / 卡片信息 / 移除卡片 | 桌面+移动 |
| 块图标菜单 | 卡片信息（reps/lapses/到期/所属） | 桌面 |
| 编辑器面包屑按钮 | 复习本文档（对齐 ZY 验证的交互） | 桌面 |
| 移动端悬浮球 | 复习（可拖动/置顶，与胶囊启动器拼合） | 移动 |

### 6.2 一级界面（3 个）

1. **复习面板**（Tab，桌面可停靠/移动全屏）——学习的发生地
2. **闪卡中心**（Tab，内置二级导航）——总览 / 管理 / 考试 / 数据，四个子页
3. **对话框族**——设置、AI 制卡向导、卡片详情、改期、批量确认

### 6.3 状态可见性

顶栏角标（到期数）→ 闪卡中心顶部常驻条（V2 状态 + 今日目标进度）→ 各子页空态引导。三层信息各管一件事，不互相重复。

## 7. 与官方 V2 的跟随策略

| 触发器 | 动作 |
|---|---|
| 3.9.0 beta 发布 | v0.9 冻结 riff 功能面；V2Gateway 按 beta 契约实现并打开内部开关 |
| 3.9.0 stable 发布 | v1.0：统计/管理/撤销切 V2Gateway；riff 保留兜底；发布"V2 兼容公告" |
| 官方新增端点 | 评估进 Gateway 能力矩阵；能用官方的不自建 |

## 9. 扩展预留（设计期就锁定的口子）

1. **Gateway 接口**（14）：内核变更只改适配器；新端点=能力矩阵加一行。
2. **卡型注册契约**（14）：`registerCardType` 双实现（3.8 内部渲染 / 3.9 官方 V2 桥接），题型永远可插拔。
3. **模块注册契约**（14）：新功能=新模块（id/依赖/画像/阶段），注册即被设置面板、画像预设、事件系统自动纳管。
4. **事件契约**（14）：`lv-cards:*` 主题命名空间，生态模块只听事件不互相 import。
5. **存储版本化**（14）：所有私有 JSON 带 `version` 字段 + 迁移函数表，字段只增不删。
6. **画像系统开放**：预设包是纯数据（模块开关+参数快照），用户可导出分享，未来可做"社区画像"。
