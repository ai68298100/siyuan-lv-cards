## 真机截图比对轮（2026-10-07，v0.206.1）

> 方法修正：此前比对用 design/preview.html shim，其 `.b3-button` shim 是白底，而思源宿主 `.b3-button` 基类是**实心主色**——上一轮"已收敛"结论在真机上失真（复习工具栏 9 个、考试页 6 个、完成页收工原因 5 个实心蓝按钮全数漏网）。本轮改用隔离靶场内核 + 浏览器自动化直截真机渲染，亮暗主题都过一遍。

- **管理页崩溃修复（T05）**：同一块同属内置+自定义卡组时 `getRiffCards` 返回重复块 ID → Svelte 5 `each_key_duplicate` 整页被错误边界隔离。manager 按块 ID 去重后恢复正常（真机可复现的潜在 bug，非样式）。
- **T04 复习工具栏重排**：`.lv-head` 20+ 元素单行无 wrap、按钮被压到 32×20px 中文竖排断行 → 三行结构（REVIEW/范围 eyebrow + 状态 chip + 进度 / 进度条 / 控制 + ghost 工具钮）；deckID 原文不再露出（eyebrow 显示卡组名）；底部「显示答案」按原型升级为 48px primary 宽钮（带 Space 提示）。
- **T07 完成页面板化**：裸文字堆 + 渐变徽章失效成白圈 + 表情串（💪🎉📦🔥💡）→ R52 results 面单面板（软绿 check 徽 / 三列 29px 大数字统计 / notice / ghost 收工原因 / NEXT 软面板 / 右对齐动作）。
- **按钮语义基线（全局）**：`.lv-page/.lv-hub/.lv-dialog/.lv-peek-body` 作用域内裸 `.b3-button` 一律回白面中性（思源基类是实心主色）；新增 `.lv-btn-ghost`（R52 button.ghost）；主动作显式挂 `.lv-btn-primary`；svelteDialog 统一挂 `.lv-dialog` 作用域。
