## 闪卡显示与质量复核（2026-10-16，v0.210.0）

- **入组**：共享 `addRiffCards` 已成为结构门禁；按普通挖空与图片遮挡分流，纯 `==答案==`、损坏标记、缺失块和无效遮挡不会再进入内核。
- **旁路收口**：牌组确认、编辑保存、重复 block ID 和导入失败提示均与共享门禁对齐；合法遮挡不能掩盖损坏的 `==` 标记。
- **问题态显示**：存量队列在呈现前复核来源块；结构无效卡不再直接把完整答案当问题态展示，隔离只影响本场列表，不写 due。
- **仍需真机确认**：图片晚加载/窄屏重排后的遮挡定位、真实 Anki/Obsidian 落块、维护页打开来源，以及旧坏卡被隔离后的提示和恢复链。Chrome 是本工作区的指定走查浏览器。
- **本轮补强**：维护扫描已携带本地媒体引用、调用宿主 `statAsset` 做明确缺失探测并展示完整 Markdown 卡面预览；维护行可定点打开现有管理器详情编辑，保存仍复用结构门禁，保存完成自动返回维护页并重新扫描；近似重复候选按题面包含关系/字符片段相似度提示，支持并排卡面和按卡片 ID 持久化人工保留/忽略决定，仍不自动合并或改调度。权限、超时或未知响应会展示为“未判定”，不会误报媒体损坏。
- **批量修复**：维护页可加入修复草稿、查看逐卡前后差异，再确认写入；失败时恢复精确旧快照，旧无效卡不会被正常编辑门禁阻断补偿，正常编辑仍须校验。成功批次写入 `maintenance-repair-journal.json`，页面提供上次批量修复记录和冲突保护撤销；卡片发生二次编辑时撤销会阻断。日志用于恢复与审计，不是长期备份；真实存储失败、重启和跨窗口仍需宿主验证。补偿路径已通过生产 IIFE 产物 smoke。
- **来源健康历史（2026-10-16）**：独立折叠区按卡片聚合全部持久化问题记录，展示原因、待处理/已解决或已确认状态、发现与处理时间；每卡最近 20 条，支持展开更早记录。确认当前来源后历史仍可查，移出当前卡组的来源也保留历史；未在本次扫描内的卡片明确提示历史状态不代表当前验证。旧记录无有效时间时显示未记录或时间无效。
- **来源健康修正**：同卡多个来源问题合并一条维护债务并分别展示原因，避免重复键导致页面崩溃。人工确认来源会更新指纹基线并重扫，媒体明确缺失或恢复状态未知的问题继续保留；扫描不因来源删除、媒体或许可状态未知而虚假解决旧问题，处理不改变 due。
- **范围与待办**：来源健康历史记录问题发现与处理事件，不逐次保存来源编辑；无历史或无基线不等于已验证健康。维护扫描现已复用入组/复习入口的结构门禁，纯答案存量卡会以缺少可见题面的原因进入卡面无效分组；可打开对应卡片编辑，修正题面后重新扫描消除债务。合法图片遮挡不误报，扫描不写调度。共享门禁对部分占位题面及无效媒体标记的判断仍需后续收紧。
- **真机验收状态**：普通/挖空/遮挡/导入/旧坏卡五路径仍未通过真实思源 Chrome 验收；此前环境没有可连接的 Chrome 实例，IAB 笔记本 API 探测返回锁屏验证，自动化检查不替代这五条宿主走查。
- **质量边界**：重复、答案泄漏、过长和待审核仍是维护页的审阅候选；静态门禁不能证明事实准确，最终接受仍需人工。
